## 契约与影响

- 成本读取中的目录缺项或未确认映射，最多自动复核一次，只刷新涉及的 SKC/仓库映射；已完成缓存复用，采购列表、分页及总请求并发上限不扩大。持续缺项仍保留不完整证据，不提升为正式成本。
- ERP 明确维护响应、HTTP/网络故障有限重试后仍不可用时暂停排队，保存任务的可选 `pauseReason`（固定代码、简短说明与发生时间）；恢复后由用户继续原任务，沿用工作区/月/店铺/SKU/SKC/导入版本校验。登录失效、用户暂停/取消分别处理，不自动恢复真实采集。
- 扩展目录返回各目标的失败细项；成本封装 `sourceMeta` 可选保存 `scopeDirectoryComplete` 与扁平 `scopeDirectoryFailures`，经本机接收器和前端契约过滤、限长后保留，仅用于诊断，不改变证据或正式成本判定。
- 继续原任务保留本地已有预览；重试失败成本批次分配新尝试，解除旧尝试的任务投递引用，原回传记录与正式成本保留。新结果替换该批范围内的旧预览，其他批次预览保持；不沿用旧回执跳过核验。
- 助手按整批显示成本证据缺项与采用状态，不能用最后一批的正常元数据宣称整批校验通过。无本地预览但已有持久回执时说明已送达及查看/重试路径。工作台跨页状态显示服务不可用的暂停原因。
- 不新增业务表迁移，不改写历史证据、真实工作区、收件队列或定稿报告。ERP 正式成本、真实零值、价格异常、人工优先、同月及以前最近三笔数量加权保持。图片和链接仍不阻塞正常利润成本。
