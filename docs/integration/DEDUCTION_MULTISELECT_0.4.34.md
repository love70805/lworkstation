# 0.4.34 扣款货号多选

目标：扣款来源按完整货号复选；输入搜索时自动选中所有匹配货号，可逐项取消、全选搜索结果或采用全部货号。清空搜索保留已选范围，预览与采用覆盖同一范围。

基线：2026-10-17 联网核对远端 main `801b970f52184e3065184c53c963f4f1a8c0de36`；独立分支 `codex/deduction-multiselect-0.4.34`，接续 0.4.33 已公开稳定版。

契约：`inspectSupplementSource` 增加仅扣款使用的可选 `supplierNumbers` 数组。逐个完整匹配、归一化去重排序；每来源仅解析一次，源行去重与源金额正负保持。来源审计记录所选完整货号，旧单货号及包含标记契约兼容；解析器追加版本。搜索只展开成明确货号集合，不采用空搜索为全部记录。

影响：扣款来源选择组件、候选组装、来源解析与对应测试；无数据库迁移，不改历史来源、定稿数据、代发金额或单号恢复逻辑。

完成信号：同一来源/跨工作表多选、自动全选搜索结果、逐项取消与清空搜索、全部货号、未匹配与未映射拒绝、异步旧预览失效、源行不重复、精确有符号合计及持久化审计通过；中文浅深色与窄窗口实际路径、发布门禁、候选与公开资产核对完成后记录结果。
