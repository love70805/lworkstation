# 0.3.9 采集、导入与双面板筛选验收

## 更新内容

- ERP Assistant 8.0.29 保留当前采购表单的 27 个已验证查询字段及空值，修正 `ERP_CHECKPOINT_QUERY_UNSUPPORTED`；恢复仍绑定原请求和范围，未知条件仍明确拒绝。
- 台账完整入库。利润明细和成本核对共用店铺、供方货号、SKC/SKU 范围筛选；选品页先缩小范围再搜索，复用当前行的搜索文本。筛选只影响展示和本次 ERP 目标，整月事实与定稿不被改写。
- ERP 只登记当前范围内的 SKC/SKU 对；切换立即取消旧登记，短暂停顿后登记最终目标。空范围不发请求，旧收件保留原范围，不自动重绑定。
- 映射区分自动匹配、数量×单价计算、默认店铺与源表无可选列；核心字段不再被大量备用列的空映射掩盖。业务单号可用于订单标识，添加时间不冒充订单日期。
- 大台账审计快照使用可逆字段/字符串字典，保留完整原始字段、精度、缺失/空值和单事务回滚，避免十万行单记录超过浏览器存储上限。
- 包含原 0.3.8 的鲜明图表配色和 Windows 图标逐尺寸生成改动。

不新增数据库迁移；ERP 正式成本、人工更正优先和已定稿保护延续。旧小审计数组兼容；新大快照的同步恢复须使用 0.3.9 或更高版本。测试台账和本机数据库不内置、不提交。
