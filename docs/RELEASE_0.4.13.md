# 0.4.13 ERP 后台采集状态提示

2026-10-09：实现完成，候选验收和公开发布待核对；当前公开稳定版仍为 0.4.12。本机不自动安装，不操作真实 ERP 账号或改写真实业务数据。

后台补商品资料时，工作台各页面显示当前阶段、对应月份和成本送达进度，可直接返回原月份的成本核对。运行中不再同时提供“继续补充资料”；全部资料检查结束后不再残留暂停按钮。刚准备的任务显示等待 ERP 助手，暂停、真实缺项、断联与完成分别显示，断联时保留已收到数量并明确状态暂无法确认。

图片和链接用于商品建档，不阻塞已采用成本的利润核算；成本送达与实际采用继续分别计数，成本证据、原价格异常约束、人工优先和定稿保护保持。跨页面提示复用现有任务/采用同步，没有额外轮询、业务字段或数据库迁移。
