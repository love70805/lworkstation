# 0.3.7 连续建档契约

基线：454b74f；批准范围见 RELEASE_0_3_7_UPGRADE_PLAN.md。

- 参考页“未建档”当前全量筛选结果按现有列表顺序组成临时队列，SKC 优先、缺 SKC 时以稳定 SKU 去重。只保存商品身份，不缓存草稿或财务明细；队列仅在当前页面进程存活。
- 路由携带队列标识和位置；逐项重新读取定向快照。已经建档的目标跳过；来源身份变化或工作区不一致拒绝写入，保留编辑内容供核对。
- 保存并下一个复用正式商品事务；只有提交成功且保存期间无新修改才推进。普通保存保持原行为；跳过/返回沿用未保存离开保护。每次写入传 expectedWorkspaceId，仓库在事务前验证。
- 列表查询、筛选、全量顺序和分页由既有视图快照恢复；增加入口焦点恢复，滚动由真实 DataTable 容器恢复。下一商品将焦点放在名称字段。
- 人工字段、主动清空、引流恢复、可选资料晚到、财务来源默认已上架均沿用现有契约。不新增数据库版本，不改正式成本策略。

验收：跨分页、同 SKC 多 SKU、失败不推进、保存期间新修改保留、其他操作已建档跳过、来源变化和跨工作区阻断、跳过离开保护、返回页码/真实滚动/焦点；已有人工字段与会计预填回归；headless 浅深色窄窗口。

## 实施及验证

- ProductLibrary 使用按店铺隔离的紧凑参考读取，队列沿完整筛选后分组顺序创建；ProductEditor 根据当前 SKC/SKU 定向读取，没有身份时不启动全工作区读取。
- 保存前重新读取来源，事务传递 expectedWorkspaceId；其他操作已建档的未编辑目标自动跳过，正在编辑的目标保留输入并提示核对。来源移除、身份移动、工作区改变或页面重载导致临时队列失效均阻断队列写入。
- 保存自身触发的 liveQuery 回读在提交判断期间延后合并，避免把回读派生变化误判为新的编辑；真正保存期间输入的修改继续保留，第二次保存可更新同一商品后推进。
- 2026-10-02 定向回归 33 项通过：ProductEditor、ProductLibrary.recovery、continuousCatalogQueue。含 23 商品跨分页全量顺序、同 SKC 多 SKU 去重、冲突字段焦点、来源失效、跨工作区、其他操作已建档、保存期间输入和离开保护；既有标题/图片/售价/主动清空/引流恢复及晚到资料回归通过。
- Headless Edge 隔离合成库验收：23 商品队列从第 2 页启动仍始于全量第 1 项；键盘 Enter 启动，商品名称焦点可达；保存为已上架；完成后恢复第 2 页、查询、未建档筛选、入口焦点及实际窗口滚动 180px。1440/800/360/320 宽度的浅深色编辑器与参考页共 16 张截图，无文档横向溢出，已抽样人工审视。原入口因处理完所有目标而禁用时，焦点退回建档筛选。
- 单次 23 商品合成场景首档打开约 0.11 秒，仅代表此规模，不能替代百万行性能验收。脚本、完整测量、截图位于忽略目录 archive/release-0.3.7-continuous-catalog/。没有触及真实业务库或本机安装。
