# Lworkstation 2.0.0 使用指南

适用于 Windows 本机桌面版。配图 PDF 随 2.0.0 安装包提供，截图为实际客户端与示例数据。

## 日常操作

1. 从工作区首页或月度账本导入销售台账，核对店铺与货号范围后导入。
2. 在利润核算页开始成本核算；明细与成本核对在同一页，正常 ERP 成本自动采用。
3. 需要时忽略价格异常，或在成本详情中补齐确实缺少的成本。
4. 从利润核算页上方导出报表；代发、扣款与历史导出在可展开区域中。

工作区首页、商品资料、利润核算、系统与备份入口保留。成本详情固定在明细右侧，不必把表格拖到底；默认只显示常用列，可切换完整列。

## 导入与月份

支持 CSV、TSV、XLSX、XLS。优先从添加时间识别月份；从已有账本进入时使用该账本月份，正常情况显示文字而不要求手选。日期不足时才出现补选。跨月文件先按月拆分，同月多个店铺可一起导入。导入前查看识别月份、店铺、货号及勾选数量。

## 忽略与恢复异常

“忽略”表示让可计算的原价继续参与核算，并不表示价格已核实正确。明确的 0 元、1 元和历史偏离价格可以使用；空白、没有采购数据或缺少必要对应关系仍会提示，不把空白当零。

| 需要处理的范围 | 忽略 | 恢复提醒 |
| --- | --- | --- |
| 一项 | 选择忽略 → 忽略此项 | 已忽略异常 → 恢复提醒 |
| 多项 | 勾选需要的项 → 忽略选中 | 勾选需要的项 → 恢复选中 |
| 本月全部 | 利润核算页 → 一键忽略异常 | 已忽略异常 → 恢复本月全部提醒 |

提交前检查已选数量。空选不执行。按同一次回传的仓库商品处理，共用原始采购的 SKU 一同生效；范围显示为本月全部店铺。新回传不会自动继承忽略。原始证据保留，恢复后重新判断 ERP 成本，人工更正不受影响。

账本无需定稿或锁定，导出后也可随时调整台账、成本、仓储或补充来源，再导出新版。旧版曾标为定稿或锁定的账本同样可直接调整，不需要先重开。历史报表保留当时快照，不会因当前修改而变化。

点击异常商品名称或明细中的成本详情，可以直接修改成本；采购证据与原因可展开查看。

## 人工更正

输入非负单件成本后保存，支持真实零值与微小正数，系统记录更正。只对当前工作区、月份、店铺和平台 SKU 生效，人工有效值优先于后续 ERP 回传。保存后关闭详情，不再提供保存并下一项。需撤销时使用撤销当前更正，恢复最新可用 ERP 成本或缺失状态。

## 商品资料与商品档案

进入商品资料，展开补齐商品资料。已有任务时，可以复用采集阶段获得的完整 SKU 对应关系，继续补名称、图片和 1688 链接，资料进度也在这里查看。

也可以在 ERP 导出商品档案，点击导入商品档案，选择文件，查看匹配/未匹配数量，再导入资料。文件仅用于名称、图片、属性和链接等资料补齐，不替代 ERP 正式成本，不改变人工成本或已保存报告。已匹配内容用于商品资料和预存区；未匹配项保留待补齐，不能靠截断的 SKU/SKC 拼接片段猜测关系，可先完成采集或核对商品 ID。

当前没有承诺自动下载 ERP 的商品档案导出文件；自动资料采集仍可使用，文件导入为补充入口。

## 导出与进度

成本齐全后，页面上方可导出未扣款报告。需要代发、独立扣款或历史导出时，展开代发、扣款与导出记录。报告覆盖本月全部店铺，查看筛选不会缩小报告范围。按钮不可用时先看缺项提示，并处理无法计算的项目。

采集显示已完成数量和阶段，核算与导出显示处理中或当前步骤；未知总量不显示虚假的完成百分比。任务中断时查看原因，检查 ERP 登录和权限，使用继续或重试入口；已有回传保留。资料补齐失败不撤回已经生效的成本。

2.0.0 保留本机数据与现有自动更新方式。系统与备份仍在侧栏。页面计算与重复读取已优化，实际 ERP 速度仍取决于网络、权限和数据量。
