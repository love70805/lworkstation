# ERP 采购总价核算修复

2026-11-13。用户确认常规成本采用最近三笔有效采购的采购总价合计除以采购数量合计。稳定基线为已联网核对的 v2.0.6（385f9f54b55c9c74a593ecf121ddebc82e8f034a）；主线 ba30f37 的独立 Beta 界面不属于本批稳定交付范围。

## 契约与范围

- 批量导出按列名读取采购总价。逐单明细包含采购单价和服务单价时保留其合计对应的采购金额。不得只用采购单价反算金额而漏掉服务费，也不得把整单运费或其他商品金额加入当前 SKU。
- 采购证据标记金额口径，保存原始采购总价；预览、收件、正式复算、明细及导出使用同一金额。先累计金额和数量，再除法并截断单件成本四位，不先截断各笔单价。
- 最近三笔、账本月份截止、取消/作废排除、SKU 归属、异常处置和人工优先保持。共用采购证据的读取方同步使用按总价得到的单件成本。
- 旧版证据不能据已漏服务费的金额还原真实总价，保留历史值与报告快照，重新采集后采用新口径。不批量改写真实数据库，不执行安装。
- 旧待回传载荷重试保持原内容及原回执身份；继续旧任务不等于补出了缺失的服务费用。已采用 ERP 成本保持历史记录，显式重新获取采购历史后才取得新总价。原预览缓存键失效，检查点范围和已送达状态由同批采集修复保持。

## 完成信号

合成含服务费采购在批量及逐单路径得到相同总价；三笔不同数量、非整除金额、取消和未来采购、异常更正、人工优先与持久化重开通过。完成相关前端/桌面验证、候选验收、受保护集成和稳定发布。私有样例、工作目录、日志和依赖登记仅保留在忽略归档。

## 验证

- 三笔含服务费、不同数量、非整除金额、明确无效总价不回退、零价与缺失区分、月份/取消过滤、异常更正及人工优先通过。批量导出、逐单采集和完整分批回传/备用路径通过；HTTP 收件保留金额口径与原价字段，工作台独立复算、保存重开和利润金额通过。
- 前端完整回归覆盖 245 个文件。旧版扩展 fixture 继续使用原缓存键，修正该断言后对应 9 项端到端场景通过；最后一轮相关契约、持久化、人工成本及界面交互 7 文件 / 186 项通过。源码预览、CSV 与启动场景通过。
- 用户提供的单行导出仅在本机验证，其数量、服务费用与总价对照一致；此观察不代表原生 API 总有直接总价字段，也不代表已核对其他真实采购或执行真实重采。
- 新请求替换旧 ERP 成本的隔离路径通过：旧金额保留证据，新批次按采购总价生效，人工零值继续优先，撤销人工后恢复新 ERP 值，原报告与来源快照不变。该 repository 文件 47 项通过。桌面旧任务完成后按钮禁用，浏览器“重新采集全部”在桌面托管界面不可达；统一集成需提供显式重新获取入口和新请求身份，不能用继续旧任务代替重采。
