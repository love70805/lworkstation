# 里程碑 30：本地发布候选验收流水线

日期：2026-08-08  
状态：**已完成本机门禁；外部 ERP 登录态与云端资源仍待验收**

## 目标

把项目已有的测试、构建、ERP 收件、同步、种子、Schema 和部署检查串成一条可重复执行的本地发布候选验收命令，降低每次交给组内试用前的遗漏风险。

## 已完成

- 新增 `pnpm release:check`，由 `tools/local-release-check.mjs` 顺序执行八项门禁。
- 门禁失败立即停止，并保留失败命令和退出码；全部通过时明确标记为“本机组内试用候选版”。
- Windows 下使用显式 `cmd.exe` 调用，避免依赖 `shell: true` 产生弃用警告。
- 部署指南补充命令说明，并明确该流水线不会连接外部 Supabase、ERP 或生产数据库。

## 当前边界

- 尚未在用户自己的 Chrome 登录态完成“复制平台 SKC → ERP Assistant v8.0.1 → 自动收件 → 成本发布 → 利润定稿”的真实链路。
- 尚未创建或连接外部 Supabase/PostgreSQL/Auth/托管资源，也没有上传真实数据。
- 多设备字段级冲突合并仍未实现；当前恢复能力面向空白设备或管理员确认后的整工作区替换。

因此，本项目当前可以标记为：**本机真实数据 Beta，可供组内试用和业务验收；尚未达到云端生产发布条件。**
