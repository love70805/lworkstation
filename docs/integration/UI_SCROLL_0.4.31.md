# 0.4.31 UI 滚动与空间整理

2026-10-15 用户授权开始下一版统一整理，完成后直接公开稳定发布，本机不安装。

## 基线与契约

- 实际远端 `origin/main` 已 fetch 核对：`bc7ee55f89eba267bf876c3635318add7d057921`；已公开稳定版 0.4.30。
- 主页面只保留页面纵向滚动，宽表只横向滚动，分页限制当前渲染数量；商品、预存、利润、成本、导入及编辑器采用相同原则。
- 长列表不通过固定小框压缩显示；不设置虚假的最小内容高度撑出空白。弹窗正文只保留一个纵向滚动区域，下拉候选、日志和文本输入按用途保留有界控件。
- 筛选、翻页和详情返回需保持可预期的位置；可从任意表格位置访问分页和横向列。窗口缩短、缩窄或展开证据不能产生额外页面横向溢出。
- 只更改展示与导航位置，不改正式成本、人工优先、资料归属、定稿保护、数据库表结构或真实数据。

## 发现与实施

- 原版使用 9 组预存资料复现：1440×900 下表格被限制为 585px，内部内容 1471px；主内容高度 1178px，文档可滚动高度却为 1907px，多出约 729px 尾部空白。移除内层纵向限高后，当前页完整展开，文档和主内容高度一致，尾部仅保留正常页边距。
- 商品/预存、利润分组、销售明细、货号表格、首页最近活动及导入校验清单随页面展开。共享表格依靠分页限制渲染条数，不再使用内部虚拟滚动框；10000 条记录每次只挂载当前 100 条。
- 共享宽表使用双向同步的原生横向滚动条，在页面可见底部保持可达；支持键盘、鼠标及表格横向滑动，纵向滚轮继续滚动页面。商品/预存与利润/成本/货号表的容器保持裁剪而不创建额外纵向滚动上下文。
- 翻页将列表起点定位到顶部导航之下，商品详情返回保存页码、排序、页面及横向位置。利润分组返回保存页面位置；销售明细保留横向位置。构成图保留完整期间与占比，图例跟随当前明细页，消除重复的小框滚动与过长图例造成的空白。
- ERP 回传、报告预览和状态管理清单只使用弹窗正文滚动；底部操作保持可达。商品编辑器、账本卡片和备份页移除人为最小内容高度，嵌入页面的加载状态不再额外占满一个屏幕。
- 排查入口包括工作区首页、商品库/预存、账本、利润/成本、商品编辑、导入、系统检查与备份。文本输入、下拉候选及诊断日志保持有界控件；未改原生桌面窗口布局、可见性或业务数据。
