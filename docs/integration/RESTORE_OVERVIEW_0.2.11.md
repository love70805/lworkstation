# 恢复经营概览

用户指出 0.2.10 将“融合利润功能”误做成替换经营首页，并明确要求“恢复原经营概览”。本任务只纠正页面组合和跳转，不回退已交付成本业务规则。

- 基线：集成 `6ab4705`；原首页取 `3d364ac` 的 WorkspacePortal。根因 `cc11371` 替换首页及将 `/profit` 重定向 `/workspace`。
- `/workspace` 恢复销售趋势、最近活动、待办、商品成本观察、健康和快捷入口。首页不再直接呈现完整利润面板，也不因 ledger 参数自动改为利润页。
- `/profit` 独立承载现有核算页面；保留 0.2.10 月份选择、店铺筛选、有效账本验证、明细折叠和人工更正入口。一个页面只包含一个 AppShell。
- 侧栏包含首页、选品、利润、账本、成本核对及诊断；核算目的跳转统一 `/profit` 并保留适用账本/店铺筛选，正常首页链接到 `/workspace`。
- 保留人工成本优先、零/微小单价、撤销、定稿保护/显式重开、ERP 自动请求/收件修复、安装路径与紧凑版本弹窗。不迁移数据库，不修改本机业务数据，不安装。
- 原首页组合主责“桌面化”复用原 UI 文件边界，处理 App/AppShell/WorkspacePortal 及新利润页面包装、导航 tests/smoke；“利润与 ERP”仅处理 MonthlyLedger 和 profitFilter 的业务返回路径。主线审查、集成，不代改专职实现。
- 验收：空与有数据首页模块恢复；首页→指定月利润→成本/账本→利润流程；月份/店铺保持及跨工作区拒绝；1024×768、1280×800、390×780 单页壳和可达操作；frontend test/build，desktop verify及打包验收按实际交付范围执行。
- 数据读取补充：恢复验收复现原 getWorkspaceOperationalSummary 向摘要传入全部工作区账本/审计，导致当前首页和通知混入外工作区月份。利润与 ERP 专职追加 workspaceRepository 最小读取隔离修复，按当前成员工作区过滤；不改变返回字段、数据库结构、权限模型或核算规则。UI 直接读取的趋势/最近活动同样过滤。该跨模块修改仅用于遵守既有工作区隔离语义。
- 后续补丁版预定 0.2.11，不覆盖已公开 0.2.10 资产；当前文档不代表新版本已发布。
