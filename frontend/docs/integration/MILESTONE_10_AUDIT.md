# 里程碑 10：商品、ERP 成本、精确利润与选品参考闭环

状态：本机领域闭环已补齐证据链，真实 ERP 浏览器端到端与云端连接仍未执行  
审计日期：2026-08-07

## 本里程碑确认的业务链路

```text
1688 采集/手工登记
  → 待确认采集
  → 正式商品与平台 SKU
  → 月度台账导入（平台 SKC + 平台 SKU）
  → ERP v8.0 按平台 SKC 查询
  → ERP 成本批次发布
  → 精确利润计算与月度定稿
  → 选品参考读取 ERP 成本与定稿历史
```

## 已确认的数据边界

- 平台 SKU 是工作区内全局唯一通用标识。
- 平台 SKC 是 ERP v8.0 的查询单位，也是月度利润筛选和复制单位。
- 仓库 SKU 只作为 ERP 采购证据与平台 SKU 映射的桥梁。
- 默认币种固定为 CNY。
- ERP 成本是正式权威成本；1688 落地成本只作为选品参考。
- ERP 缺失时，1688 成本只有在当前账本、当前平台 SKU 上完成带原因和复核人的人工审批后，才可用于该账本定稿。

## 本次实现

- 选品参考行现在保留：
  - 参考成本事实 ID；
  - 参考来源账本 ID；
  - 参考成本审批 ID（如适用）；
  - 参考币种。
- 选品参考仍按成本优先级选择：ERP 历史 > 已定稿利润历史 > 1688 参考。
- 导出选品参考时同步导出上述溯源字段，方便人工复核和后续云端同步。
- 新增回归测试，验证 ERP 成本不会被更低或更高的 1688 报价、也不会被历史兜底定稿覆盖。
- 新增基于 `fake-indexeddb` 的持久化集成测试，真实调用数据库 API 验证采集确认、商品库、月度台账、ERP 成本发布、利润定稿和选品参考回读。
