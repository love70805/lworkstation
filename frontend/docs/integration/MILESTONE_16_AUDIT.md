# 里程碑 16：云端业务数据可重建性

状态：本地审计 Outbox 已能携带并重放核心业务事实  
审计日期：2026-08-07

## 本次目标

验证同步服务接收的不是只能查看的操作日志，而是足以恢复组内工作区核心数据的业务事件。

## 已补齐

- 采集草稿更新、忽略和确认事件保存完整采集记录。
- 销售导入事件保存实际导入批次、已持久化销售行和更新后的月度账本。
- ERP 成本发布事件保存完整成本批次、已持久化成本行和更新后的账本覆盖情况。
- 仓储费率更新事件保存完整月度账本。
- 利润定稿事件保存完整定稿账本和带本地记录 ID 的实际利润行。
- 1688 成本重新审批时，为被替换的旧审批生成完整撤销事件，避免云端保留多个有效审批。
- 删除事件被定义为完整操作，不再被错误报告为“缺少快照”。

## 重放验收

真实 IndexedDB 集成测试按以下路径运行：

```text
采集创建/编辑/忽略或确认
→ 商品与平台 SKU/供应商报价
→ 月度销售导入
→ 平台 SKC ERP 请求
→ ERP 成本发布
→ 精确利润定稿
→ auditEventToSyncEvent
→ shopeers-sync-envelope v1
→ createSyncEventStore 业务投影
```

重放后可以取回：

- 商品、平台 SKC、平台 SKU、1688 供应商报价。
- 完整采集状态和确认/忽略信息。
- 销售导入批次、销售明细和 CNY 月度账本。
- ERP 请求、仓库 SKU、正式单位成本和成本覆盖结果。
- 1688 审批、替换撤销和当前有效审批。
- 定稿利润汇总及逐平台 SKU 利润事实。

所有参与本次集成路径的业务事件均通过 `listBusinessProjectionGaps` 检查，没有缺少完整快照的事件。
