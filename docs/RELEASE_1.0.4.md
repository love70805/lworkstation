# 1.0.4 清空后扩展 SKC 残留修复

2026-11-02 已[公开稳定 Latest](https://github.com/love70805/lworkstation/releases/tag/v1.0.4)，非草稿、非预发布。内置 ERP Assistant 为 **8.0.51**。稳定通道可通过现有自动更新获取；外置 Chrome 扩展需要重新加载当前 ZIP 并刷新 ERP 页面。

## 修复结果

工作台「数据安全 → 清空数据」此前只删除本机业务与收件记录，ERP 页面仍保留旧查询、结果和检查点，任务列表变空后也未同步移除旧范围显示。本批增加不含业务标识的持久清空通知，清理扩展自己的查询、结果、任务、检查点和待投递缓存，并阻止迟到回复恢复已清空范围。

通知由既有鉴权心跳和任务查询传递，打开预览也会核对；离线扩展重新连接后同步应用。普通断网和服务重启保留有效任务，连接配置和 ERP 登录不属于清理范围。清空继续保留文字确认，不增加自动备份前置步骤。
