# 货号预选与工作台成本采集

日期：2026-11-02。实际联网核对基线：`0d86cd4dcce5fe999aa21d5e60137c1c4436d945`（1.0.5）。本批使用独立执行工作树，主目录和其他任务未提交内容保留。

## 目标与契约

- 导入先恢复逐店货号选择；模糊搜索、勾选只调整本批预选，不反复解析业务数据。已选清单默认折叠，完整清单同步勾选。点击匹配后统一校验，可直接导入。
- 未选货号的数据自动排除；整店无选择时明确显示跳过，其他店铺可以继续。错误文件、身份冲突和覆盖确认仍按现有契约处理；跳过店铺不得删除或替换已有台账数据。
- 工作台直接发起 ERP 成本读取，复用已登录会话；会话过期给出登录入口，不保存账号密码。固定工作区、账本、月份和 SKU/SKC 范围，复用完整证据、租约、暂停/停止及人工优先。独立隐藏采集页面不改变前台 ERP URL、表单、翻页或结果缓存；已有运行任务遇账号会话变化即停止，取消旧请求。
- 用户已指定最低价为全历史合格采购的最低正单价，不限月份。取最新完整证据快照，忽略月度截止限制，继续排除取消、无效、归属不符和未经确认的异常价格；缺证据不能按零计算。最低价计算不修改 ERP 原始记录，直接观察未采用的已验证完整回传，避免月度截止遗漏历史。
- 人工调整、仓储费率、补充来源和报告版本分别隔离，原有人工有效值优先并作为只读基线。旧页面草稿不得跨上下文写入。用户指定的非公开交互不写入公开操作说明。
- 用户取消日常定稿和显式重开：当前利润随数据变化重算，成本齐全即可直接导出，代发可空，扣款不全可导出未扣款报告。已保存文件和来源行保留为历史版本；旧版兼容重开/同步恢复仅留在后端，不作为用户操作步骤。普通报告保留最新选品参考投影，另一核算不覆盖该投影。不增加数据库结构版本，不执行真实数据迁移。
