用户于 2026-11-04 明确要求直接制作 2.0.0，并指定在当前对话完成。以实际 Windows 桌面客户端为实现与验收对象，保留工作区首页、商品资料、利润核算、系统与备份。聊天中的独立交互草案已被用户否决，不作为视觉实现模板。

## 已确认的使用流程

1. 导入台账时，可靠识别月份或已有账本月份改为文字显示，不常驻月份选择框；只有无法识别时出现必要补选，跨月不静默归入单月。
2. 利润明细与成本核对融合为一个工作页面与统一上下文。成本入口靠近商品且在窗口化布局中可见；证据与人工更正使用同一个详情入口，不要求横向拖动到底。
3. 删除“保存并下一项”连续更正操作。单项人工更正保留，仅需现有单件成本与说明，保存后的结果和待处理数量及时更新。
4. 按钮明确命名“一键忽略异常”。用户已明确：不逐条确认价格是否正确，可计算时按原值继续使用，包含明确的 0 元、1 元和历史偏离；缺采购记录、缺必要数值、不能确定商品归属等实际无法核算的项才阻断该项。空白不得变成零。
5. 忽略是一项显式、可追溯、可撤回的决定，不得记为“价格已核实正确”。用户于 11 月 5 日补充：忽略与恢复均支持单项、多选、全部操作。异常窗口提供勾选及已选数量；按回传与仓库商品限定范围，空选不触发全部，跨回传多选在同一事务中处理，失败整体回退。可进入成本修改，恢复不覆盖后续人工有效值、不重写历史导出文件。
6. 导入、核算和导出放在容易发现的位置。导出只受当前缺项等必要可计算条件约束，直接说明尚缺什么并定位，不把导出入口埋在长列表底部。
7. 商品采集、图片和链接补齐移到商品资料，资料进度不混在成本完成进度中。资料补齐失败不得使已生效成本退回缺失。
8. 移除面向使用者的旧分批入口、批次选择和逐批操作，以一次任务、连续进度和结果呈现。必要传输分片、历史证据兼容及仅重试未完成项仍可内部存在，不要求用户管理批次。
9. 优化启动、页面切换、切月/切店、展开明细、保存更正、核算和导出。复用现有后台计算及缓存，先量化再优化重复读取/计算/大列表展示。长任务提供真实阶段/数量/活动反馈，未完成时不假报完成，更新期间保留同范围已有结果。
10. 商品档案批量导出仅用于加速商品资料补齐，不替代采购证据和利润核算。优先复用此前成本采集已保存的完整 SKU/SKC/仓库关系，按稳定商品标识匹配档案，再批量补资料；不依赖截断的片段列重建已有关系。仅对新商品、未对应项或冲突补查。日常仍为一次补齐操作，自动批量获取优先，手动文件导入作为备用。
11. 最终提供依据实际成品界面编写、配图的使用说明，不以演示草案代替。
12. 用户于 11 月 5 日再次明确取消定稿、锁定操作，月份随时可调整。复用既有可编辑账本流程，取消异常处理残留状态限制和旧锁定提示；按当前数据导出新版，每次历史报告保持当时快照。旧状态无需先重开，也不在读取时批量迁移数据。旧数据可不作为必须保留的兼容目标，实际清理范围另行明确。

## 契约与保护

忽略异常需要独立决策语义，贯通原始采购证据、核价、采用、撤回和审计；原始采购金额不改写。人工有效值优先，币种 CNY、月份范围、作废/取消记录排除、SKU/SKC 身份、原有采购选取算法、台账收入及历史导出快照保护继续成立。账本可持续编辑，历史文件不随之重写。识别失败或必要证据不存在应明确报出，其他可用项继续处理。

UI 融合不合并领域职责；新增字段先补契约与相应测试。兼容性迁移如确需增加版本，仅在隔离数据验证，不直接操作真实数据库。历史链接和已交付记录保持可读取。

## 实施结果与验证

- 完成同页明细与成本详情、常用列和固定操作列、上方报告出口、日期自动识别及必要补选；首页保留，连续更正与日常分批入口移除。已忽略记录可以展开，支持单项、多选和全部恢复，选择窗口注明范围和数量。
- 忽略决策保留原始证据，与核实价格区分。实际零价可计算；空白、无采购数据与不完整证据不能变为零成本。多选跨回传共用事务，空选不执行，错误选择或校验失败不留下部分写入。人工优先、财务权限、工作区/月度范围通过回归；追加旧定稿/锁定状态仍可调整、重新导出且旧报告字节保持的检查。
- 商品资料增加档案导入，只保存资料字段与审计，使用已知完整关系匹配；原采集已取得完整关系时不因 1024 字符片段截断重复查映射。档案只读样本验证了错误工作表范围、长文本标识、图片公式及链接提取，原件哈希保持。尚无已验证的 ERP 商品档案自动导出接口，因此没有宣称实现自动获取该文件；日常自动资料采集保留，文件导入是补充入口。
- 复用计算 worker，取消账本读取时的历史最低价阻塞预热，复用已加载收件，增加采集真实数量/阶段和核算、导出等待状态。同一 Electron、12,000 行/500 SKU 的合成输入，重复计算中位数由 73.3 ms 降至 60.6 ms，首次由 94.1 ms 至 88.2 ms，结果摘要相同。该结果仅代表本地 worker，不代表应用启动或真实 ERP 网络速度。
- 最终前端 243 文件 / 1,920 项通过；生产构建、39 项本地发布门禁、桌面 verify、原生 ERP 采集和 bulk/legacy/fallback 结果对照通过。门禁中未改变的运行时行为复用同批通过证据，新增多选财务路径及持续编辑流程重新运行完整前端回归。公开资料检查发现新测试样例未使用保留编号，已改为专用虚拟编号并通过检查。
- 真实 2.0.0 客户端使用隔离合成数据完成全部忽略、单项恢复、多选忽略/恢复、缺项保留、单项更正、实际 Excel 导出、资料导入不改财务及 CSV 自动识别月份。浅深色 × 1440/980/390 的明细和详情共 12 组通过。截图时窗口置于屏幕外且无焦点；这不冒充隐藏窗口验收。
- 实际安装器解出的程序单独通过隐藏 smoke（可见窗口为 0）；241 个安装器文件、34 个 ASAR 源文件及生产资源逐字节核对一致。7 页 PDF 使用成品截图与合成数据，中文嵌入字体，逐页渲染与文本校验通过。没有安装软件或操作用户真实业务库。
