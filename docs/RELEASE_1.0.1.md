# 1.0.1 后台稳定性与重新打开

状态：已实施，候选验收与集成中，尚未公开发布。日期：2026-10-24。

数据量较大时，后台恢复和参考资料读取会反复复制相同采购证据，部分派生缓存只限制行数，无法限制长历史的实际占用。本批统一缓存字节上限，移除用于测量大小的整份序列化；恢复检查按块计算完整原行指纹，复用稳定输入，并在版本或身份变化时回到完整核验。权威采用保留全部证据字段，仅收敛到已验证批次的完整成本历史。

自动建档订阅只常驻候选状态和短指纹，保存仍在原事务重新核验完整资料。目录内部去重键不再重复保留长采购串，原始采购来源、供应商配对与用户资料保持。概览默认折叠的商品成本观察展开后读取，关闭后释放；读取失败可以重试。

新增两份各至多 256 KiB 的本地运行诊断，只记录时间、版本、页面类型、退出原因/退出码和资源数值，不含 URL、凭据或业务载荷，也不向外传输。原次 1.0.0 事故没有保留具体退出原因，不能据内存峰值断言必为 OOM。

相同离线副本、双方都无可重建派生缓存的测量：概览完整读取约 13.4→8.8 秒，整个客户端峰值约 2.0→1.4 GiB；后续正常重新打开约 2.6 秒。该结果是本机隔离测量，不代表所有数据规模、真实 ERP 网络或账号速度。隐藏源客户端记录强制页面崩溃 `crashed/2`，重试恢复通过。

实际核对基线 `c18f79203335dab9b3ff17e25c5d16be08bcb005`；软件版本保留 1.0 系列并统一递增为 1.0.1。最终完整前端 223 文件 / 1,759 项测试、生产构建、完整桌面 verify 和其余 30 项发布门禁通过。合成资料的中文浅深色 × 980/1440 四组布局、键盘展开/收起与无横向溢出通过。最终安装包哈希与实包验收、PR/主线 CI、公开资产核对在完成后补记。

本批不改业务库结构，不修改真实业务库、凭据或用户导出。CNY、ERP 正式成本、人工有效值优先、真实零值/微小正数和月度定稿保护保持。未安装或重启用户当前软件。私有数据副本、完整日志和 CPU 采样集中保存在本机忽略归档 `archive/background-stability-20261024/`，不随公开源码提交。
