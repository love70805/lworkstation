## 导出

- 利润明细10列：SKC、SKU、属性、件数、销售额、1688单号、单件平均成本、总件数成本、仓储成本、利润；店铺汇总为店铺/销量/利润。独立项目区明确代发数量（件）及金额（元），财务报告列出扣款及扣后合计。
- 所有金额先向零截断至2位，再写为Excel数值并采用`0.00`格式；总额以完整精度加总后截断，不把逐行展示值相加作为正式合计。内部十进制精度、公式版本、原定稿文件/哈希不变。
- 新模板`profit-zebra@4-two-decimal-columns`。旧@1/@2/@3下载只读取原OOXML数值文本及已保存report元数据，仓储成本使用冻结数量×冻结warehouseRateExact；不查询当前费率/成本/销售。原汇总明细与店铺页交叉核对，缺少冻结费率或文件异常拒绝生成。
- 代发表四列SKC/订单号/数量/1688订单号；右侧汇总数量/总价。数量为整数，订单文本保留。扣款四列补扣款单号/SKC/供方货号/扣款金额，金额红色，保留正负。

## 导入与采用

- 代发按登记人完整姓名匹配，仅规范化首尾空白；跨店铺保留实际店铺。CSV仅在相邻可靠人员/日期组内继承，空行/分隔/新日期重置归属；变更人员/店铺/SKC清除不可靠采购标识。XLSX保留明确纵向merge来源。继承行和标识来源位置保存在记录中。
- 有订单但数量空缺仍建立连续组，随后针对该登记人报告缺失数量，不把该行当分隔、0或排除行。特殊情况、分类和无标题尾列保留为备注，不参与数量增减。文件模式采用明细数量之和；手工总量保持独立模式。
- 扣款按供方货号/货号完整编码或明确选择的包含标记筛选，不推断人员。金额列优先分摊后运费、分摊金额、扣款金额、运费金额、金额；每个来源仅采用映射的一个金额列，预览保留原金额表头和分类。无/空表跳过。实际店铺列优先，否则使用准确同名工作表或唯一纯数字编号别名（680→680店）建议并可显式映射；不移除sh等前缀猜店铺。
- 同文件/工作表/物理行重复拦截，文件内容哈希识别重名重导。同单同SKC同货号且等额的不同源行可以是合法分摊，全部保留。跨文件相似业务记录在预览列出，未经核对不能采用；用户确认保留后重新预览，签名及事务再次校验。不会按金额自动去重。
- 沿用本月工作区/账本/角色/定稿保护及修订替换、历史保留；不新增表结构迁移，不写真实数据库。
