1. 新增采集记录后，记录进入待确认队列；补齐平台 SKC 和平台 SKU 后确认入库，正式商品库显示商品和 SKU，采集状态变为已确认。
2. 使用内置示例台账完成导入，生成 `2026-07` 月度账本，利润页显示 3 条 SKU 明细和待补 ERP 成本状态。
3. 在成本核对页复制 3 个平台 SKC，记录 ERP 请求；导入 CSV/TSV 兼容成本文本后，3 个平台 SKU 全部匹配并生成 v8.0 兼容批次。
4. 发布成本后利润页显示 ERP 正式成本、采购成本、仓储成本和精确利润；执行月度定稿后账本状态变为 `已定稿`。
5. 进入选品参考页可回读同一批 ERP 历史成本和月度利润，未修改已定稿账本。
6. 工作区环境、外观、通知、账户、设置和帮助入口均有实际弹层或对话框行为，不再是无响应按钮。
