# 0.4.40 ERP 统一继续与成本优先

## 行为

暂停后在工作台点击“继续原任务”，ERP 采购管理页会自动领取同一任务，无需再点一次。两端共享任务标识与进度，多页面只允许一个执行者；页面失联或收件服务重启后暂停，等待显式继续。

默认先完成利润所需成本，成本完成即结束读取，图片、链接等商品资料按需补齐。每批最多 5 个 SKC，旧未送达大批次继续时细分，已送达结果保持；采购列表最多四路，沿用全局八请求上限、限流退避和完整采购历史校验。助手突出“继续原任务”，另列“重新采集全部”，内置与下载扩展同步为 8.0.44。
