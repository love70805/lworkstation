# 1.0.1 后台稳定性与重新打开

状态：已验收、集成并公开稳定 Latest。日期：2026-10-24。

修复数据量较大时后台重复读取证据、缓存内存峰值偏高与重新进入等待较长的问题。派生缓存限制单项约 16 MiB、总计约 64 MiB，完整证据分块计算指纹并复用稳定输入；成本采用仍保留全部字段，仅收敛到已验证回传范围。后台自动建档只常驻候选状态，概览成本观察展开后加载，关闭后释放。

新增至多两份、各 256 KiB 的本地运行诊断，只记录时间、版本、页面、标准退出原因/退出码和资源数值，不含 URL、凭据或业务载荷，无网络上报。更新 Electron、Zod、Happy DOM、Undici 与 fast-uri 必要安全补丁，修复主题动画预期取消的未处理异常，审计门槛保持 low。

同一离线副本、双方均无派生缓存的源客户端对比：概览完整加载约 13.4→8.8 秒，JS 堆峰值约 1,088→588 MiB，客户端峰值约 2.0→1.4 GiB。该公平对照使用安全升级前 Electron 44.5。最终 Electron 44.9.1 实包另行验证，正常重新打开完整概览约 3.4 秒、强制页面崩溃后重试完整恢复约 2.3 秒；持续 103 秒、五轮后台通知刷新未见自然退出，稳定采样 JS 堆约 135 MiB。计时为本机隔离副本测量，不代表全部数据规模与真实 ERP 网络。
