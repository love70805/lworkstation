# 台账变动类型自主筛选

用户于 2026-10-08 确认“客单签收（POP）”纳入台账，并要求恢复自主筛选。最新公开版为 0.4.7，本次基线 main `fa7971c`；旧 codex/selection-profit-erp-sync 落后于已发布主线，采用最新 main 保全已发布修复。

同批用户补充：导入完成优先引导利润核算，不能突出预存区跳转。完成页在前显示“下一步：取得正式成本”，携带新账本 ID 进入 `/profit?view=cost`；进度标记导入已完成、正式成本为当前步骤，商品预存资料收起为次要入口。

## 契约与影响

- 标准台账默认选择平台客单发货、客单发货、客单签收（POP），只选择文件中实际存在的值；沿用 NFKC 全半角归一化，POP 括号按半角匹配。
- 每文件直接显示变动类型、原始行数与勾选状态，可全选、清空和恢复默认。非标准模板有映射的变动类型时默认全选，无该列时保持原行为。
- 已映射列的空白类型显示“未填写变动类型”，纳入实际类型/行数统计，防止全选漏掉空白来源；取消该字段映射时解除类型筛选，改映射保留仍存在的选择。
- 复用 `filterOptions.movementTypes: string[]`，改变选择使旧封存行、覆盖确认与预览失效，再检查日期并自动重建。空数组是明确清空，禁止导入，不解释为全选。
- 标准台账缺少任一实际存在的默认销售类型时按部分来源/分组导入；恢复完整默认范围后可按完整月替换。非标准模板以实际类型全范围判断，避免自选后仍误认完整月。
- 数量、精确金额与成本口径保持：销售原额按数量 × 单价；盘亏继续排除，扣款/罚款/违约仍隔离为扣款。选择盘亏时说明原有规则，不暗示会计入销量。
- 不新增业务字段、数据库迁移或偏好格式；不补写历史来源、已定稿快照或真实业务数据。以前排除的 POP 记录需用户按新范围重新导入并核对替换预览。

## 验收信号

- 默认范围正确匹配原文件全角 POP 与半角 POP；原两种发货及盘亏/扣款规则回归通过。
- 实际勾选、全选、清空、恢复默认触发最新范围校验；清空后按钮禁用，恢复后可导入；更改后覆盖确认失效，另一个文件保持自己的选择。
- 缩小销售范围为部分来源，不执行整店整月替换；非标准模板与无变动列模板继续可用。
- 用户提供的 27 店台账只读分析应有 90,520 行，其中两种发货 90,063、POP 签收 3、盘亏 454；隔离用户路径核对新默认与自选结果，原表不修改。
- 窗口化浅深色及窄屏、键盘可达；前端测试/构建、桌面 verify/隐藏 smoke、候选、PR/main CI 与公开资产回读通过后发布。
