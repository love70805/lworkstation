## 契约与影响

- 本机采集任务为两端共同状态；继续请求先持久排队，由唯一 ERP 执行者领取，工作台无需第二次点击。等待、读取、暂停、成本完成和资料补齐分别展示。
- 继续原任务保留已送达批次及采用结果，仅恢复未完成范围；显式重新采集另列。较小成本批次及时持久送达，旧未完成大批次在继续时细分，旧回传与历史证据保持。
- 成本完成后结束本次读取；商品资料使用独立显式补齐动作。保持完整采购历史、账本月份、精确平台范围、异常核价、人工优先和定稿保护。
- 领取与心跳防止重复执行；执行者失联后显示暂停并等待用户继续。继续不复用无法核实账号连续性的未送达证据。
- 无业务表迁移；仅隔离合成数据验收，不操作真实 ERP、收件队列、业务库或本机安装。
