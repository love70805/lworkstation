# ERP 采购成本月末截止

> 以下记录为 Beta.1 历史契约。2026-09-21 用户临时改为严格早于核算月份、按时间最近三笔且不优先 1688。新 Beta 实施见 [历史三笔临时规则](ERP_PRIOR_MONTH_BETA.md)。

2026-09-20 用户最终确认：所有月份统一使用截至账本月末的采购记录，包含该月及以前月份，禁止使用后续月份；不是仅使用当月采购。

## 契约与范围

- 采集保留有效原始采购证据，包括采集当月；不再根据电脑当前月份删除采购记录。扩展无账本上下文时仅提供未按账期筛选的预览。
- 成本核对使用已读取账本的 `period`，仓储层采用时独立从数据库账本读取同一月份，不能信任采集时间、页面价格或传入成本行声明的月份。
- 截止日期先于最近三条、1688 单号偏好、数量加权和异常检测筛选。其他计算口径保持不变。
- 无截止前合格记录时成本缺失，不回退到未来采购预览价；人工更正优先级不变。
- 已采用成本保留原始金额与证据。活跃核算遇到无法验证采购日期、或所用采购晚于账本月份的旧成本时，要求重新采用或人工更正，不静默重算旧成本。
- 已定稿／锁定报告继续使用存储快照，不迁移真实数据、不重写历史报告。
- 持久化成本决策记录 `costPeriod` 与新版决策版本；旧草稿重新按当前账本筛选，活跃利润缓存更换版本。
- 旧采集器 `current_month` 排除曾遗漏账期内采购时，批次要求重采或人工更正，不能把剩余旧证据视为完整。内置扩展升级 8.0.18，结果缓存 v5 不迁移旧 v4。
- 核对页保留旧采用金额并标为待复核；“只看缺成本”与利润计算共同使用账本月份、店铺和人工更正策略，不把候选复算值显示成已采用成本。

## 验收信号

全部十二个月、跨年、月末最后一秒、次月第一秒、跨时区时间、无有效日期、只有未来记录、先筛选再取三条、采购单号与明细一致、伪造页面成本被仓储层拒绝、人工更正与冻结报告保持不变。
