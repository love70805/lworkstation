# 0.2.19 销售趋势与期间明细计划

状态：已确认范围，待实施  
基线：`main` / `0.2.18`  
交付形态：纯本机 Windows 桌面版；本轮不执行云端迁移，不改真实业务数据。

## 目标

保持首页作为销售与经营入口，利润页作为商品、成本、利润与报告工作区。改造首页销售趋势的日/月阅读方式，使用户能从期间总览进入店铺构成和对应 SKC 明细，而不扩大原有首页主体布局。

## 已确认交互

### 范围与入口

- 首页保留销售趋势；利润核算页移除销售柱状图，继续以 SKC 商品明细、成本核对、利润与报告为主。
- 趋势区保留“销售额 / 销量”指标切换、店铺筛选和浅深色主题。
- 新增“每日 / 月度”视图切换；这不是跨月对比功能。
- 同一店铺在每日、月度、扇形构成和 Top 5 SKC 中使用稳定且易区分的配色。

### 每日视图

- 当前月份内每天一根堆叠柱，柱内按店铺分色，展示当天总量与店铺构成。
- 悬停显示日期、销售额、销量和各店铺数值；浮层不参与页面布局，也不能造成鼠标闪烁、卡片抖动或图表尺寸变化。
- 点击日期进入当天明细，不改变首页右侧信息区的既有位置与主页面宽度。

### 月度视图

- 横轴为可用账本月份；每个月为一组，组内按店铺展示簇状柱。
- 月度柱不使用堆叠，以便直接比较同一月份内各店表现。
- 点击月份进入该月明细，不跳转到每日趋势，也不把月度点击误解为跨月对比。

### 期间明细

- 选择日期或月份后，左侧为该期间的店铺构成扇形图，右侧为商品明细。
- 点击扇形图中的店铺后，右侧筛选为该店；再次点击同一店铺可取消筛选。
- 店铺筛选时展示该店在所选期间的销量 Top 5 SKC；全部店铺状态展示期间完整商品明细。
- 明细支持原有搜索、排序、分页；返回总览时恢复原有筛选、排序、页码和滚动位置。
- 支持在明细内切换相邻日期或相邻月份；切换后沿用已选店铺，若该店在新期间无数据则明确显示空状态。

## 数据与业务约束

- 销售原额仍为收入输入，不把它当作已扣平台佣金、退款或其他费用后的结算金额。
- 趋势与明细均复用当前工作区、账本、月份和店铺作用域；无效日期、未定位来源、未来日期、未知数据与真实零值必须继续区分。
- 月度与每日汇总均从现有台账来源计算；图表交互不修改台账、成本、定稿状态或利润公式。
- 店铺图例和扇形选择只改变可视范围，不改变期间总额、正式成本口径、百分比分母或利润定稿口径。
- 平台 SKC 是商品父级标识；Top 5 按 SKC 聚合，不能以平台 SKU 冒充 SKC。缺失 SKC 必须显式标记为待补充。
- 已定稿或锁定账本继续使用已保存的利润快照；销售趋势只读展示不能触发成本或利润重算。

## 布局与动效

- 保持现有首页信息层级和右侧区域位置，不通过挪动右栏或加宽明细来容纳图表。
- 期间明细采用左窄右宽：扇形图和期间摘要约占可用宽度四分之一，商品明细占其余区域。
- 每日趋势保持紧凑可读，单日扇形图与明细区域可提高可用高度，避免粗短柱和大块无意义留白。
- 动效仅用于悬停高亮、日期/月度选中、扇形筛选、展开与返回；短时、可打断，并遵循减少动态效果偏好。
- 不通过截断纵轴、伪造比例或参考线人为放大销量差异。销售额和销量分别按各自数据尺度呈现，图表画布、零基线和顶部留白规则保持一致。

## 实施拆分

1. 扩展销售分析读模型：提供按月店铺聚合、期间明细、店铺构成与 SKC Top 5 的纯数据合同，并补充领域测试。
2. 重构销售趋势组件：新增日/月切换，分别实现每日堆叠柱与月度簇状柱；抽离稳定的颜色、比例、悬停与可访问性行为。
3. 新增期间明细组件：实现扇形构成、店铺选择、相邻期间切换、Top 5 SKC 及状态恢复。
4. 调整利润页：移除销售趋势入口与图表渲染，保留既有商品、成本、利润、报告与定稿操作。
5. 补齐样式和回归：覆盖桌面窗口、窄屏、浅深色、减少动态效果、图例筛选和悬停稳定性。

## 验收标准

- 每日堆叠柱、月度簇状柱、扇形占比、店铺选择和 Top 5 SKC 与同一只读台账范围的销售额/销量可对账。
- 点击日期显示该日明细；点击月份显示该月明细；两类明细均可按店铺筛选并恢复状态。
- 图例、悬停和扇形点击不改变业务总额、百分比分母、成本或利润数据。
- 未知、未定位、未来与已确认零值状态准确显示，不能把缺失数据画成零。
- 首页与利润页不发生横向溢出、遮挡或布局跳变；鼠标扫过图表不闪烁。
- 既有成本核对、人工更正、月度导入、报告导出、定稿/重开与数据隔离回归通过。
- 发布前至少运行 `pnpm --dir frontend test`、`pnpm --dir frontend build`、`pnpm --dir desktop verify`，并完成 Windows 候选、桌面与窄屏视觉验收。

## 非目标

- 不恢复跨月对比视图，不新增折线或参考线。
- 不新增每日利润、退款归属、费用分类或云端协作。
- 不改变 ERP 正式成本优先、人工更正作用域、金额精度、历史定稿保护或数据库结构，除非实施中发现现有合同无法承载已确认的只读分析字段。
