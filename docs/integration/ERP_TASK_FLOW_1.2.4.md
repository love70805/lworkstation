# 整项成本核算与插件适配

用户于 2026-11-04 授权取消固定小批次主流程，同步 ERP 插件并检查软件整体缺陷。实际联网核对基线 `5e5fd354e6e9c4f3f8308b211be16c6c3084a653`（1.2.3），本批集中交付 1.2.4，助手 8.0.58。

## 契约与影响

- 新建协调任务显式声明 `costFlow: task`，整项范围取得一份批量采购源、一次正常成本回传，沿用现行成本策略和本机正式采用。任务状态、来源证据、核算上下文和人工优先保持。
- 已知异常只将受影响的 SKC 转为原读取方式，其余范围复用同一源；整个源无法验证时按原方式保留恢复边界。较大载荷按需分块，完整采购历史不裁剪。内部回执不再作为用户必须理解的固定核算步骤。
- 内部划分只能发生在当前执行者、当前尝试、尚未持久收件的范围；所有子范围精确覆盖原范围且互不重复。已送达结果保持，过期尝试和原范围迟到回传拒绝。旧任务和旧回执兼容，不读取即迁移真实数据。
- 工作台、桌面启动器、ERP 任务浮窗与插件操作同步；默认资料仍按需补齐。内置扩展、版本标识和公开下载 ZIP 逐文件校验一致。
- 修复交叉检查复现的插件目录替换回滚、当前工作区默认账本读取、切换核算上下文时汇总来源暂时不一致三类缺陷。保持原核算算法，不变更真实业务数据或既有报告文件。

## 完成信号

正常多 SKC 范围只回传一次；局部异常仅补查受影响范围；损坏来源回退、暂停/恢复、丢回执、旧任务、大载荷与非法划分保持保护。前后单件成本、所选采购、完整历史与利润一致；中文浅深色和窗口布局通过。软件完整测试、发布门禁、隐藏原生及实际候选、必需 CI、标签/稳定通道/资产哈希分别记录，不把合成网络计时当作真实 ERP 提速。

本批使用隔离合成数据，未安装、未修改真实业务库、凭据或用户表格。验收原始记录与必要失败证据集中于本机忽略归档。

- 前端完整测试 240 文件 / 1,905 项通过，生产构建、39 项本地发布门禁、桌面 verify 和两端依赖审计通过。
- 新整项任务、局部缺项、读取器缺失和损坏来源回退、暂停恢复、丢回执、旧检查点、身份隔离及非法范围划分通过。400 个 SKU 共用仓库的实际发送体积超过 25 MiB 时自动拆为两份合格回执，仍只导出一次，完整采购历史和成本保持；单个 SKC 自身超过限制时明确报错，不截断历史或采用不完整成本。
