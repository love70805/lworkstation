# ERP 回传总览与待处理 SKU（0.4.21）

基线 origin/main `8b34ce0` / 0.4.20。本批仅修复成本核对的显示与返回路径，不调整价格检测、月份选样、自动采用、人工优先或定稿保护。

- 所选月份/工作区的全部回传在一个总览中显示，待处理和已处理批次同时可见；从批次详情有明确“返回全部批次”入口，关闭后可重新进入。
- 待处理 SKU在工作台直接列出店铺、平台 SKU/SKC、候选成本、具体拦截原因与所属批次，涵盖一元/零元、历史降价/上涨、证据缺失及归属/定稿保护。
- 展示投影从已保存回传和完整本月有效成本计算。当前有效人工或 ERP成本覆盖后退出待补列表，历史原始异常仍可追溯；撤销人工后再次出现。重复回传按店铺 SKU去重，其他工作区/月份不串入。
- 返回或浏览批次不丢失未保存更正/手动草稿，不触发采用、撤回、删除或重新采集。主动载入采购证据仍走既有校验、草稿保护与单一弹窗所有者。
- 不新增业务数据库迁移，不改写真实数据/收件队列，不自动安装。按既有授权统一验收并稳定发布。

验收：六批中1+2+4异常共7个，正常兄弟不进入待补；总览↔批次↔SKU详情连续返回；两条历史降价直接可见；人工真实零/微小值更正与撤销、已定稿只读；中文浅深色与窗口/窄屏；前端测试/build、桌面verify、隐藏候选smoke、CI和公开资产回读。
