# v0.4.5 预存区分阶段建档

2026-10-07。状态：候选验收通过，等待 PR / 主线 CI 与稳定发布、公开资产回读。本机不自动安装，真实业务数据未改写。

导入资料先进入预存区，逐步保存和补齐，资料齐全后自动进入选品库。成本与利润参考改为预存区，并继续提供经营参考和来源历史。上一版自动建立的基础草稿自然显示在预存区，无需迁移；正式档案、人工字段和业务销售状态保留。

按用户确认的完整标准检查有效名称、图片、SKC/SKU、店铺、所有保留 SKU 的属性、非负售价与可用参考成本，以及供应商来源链接。空值不当作零；资料来源、名称选择、SKU/SKC 归属或旧状态冲突阻止自动流转。部分资料可分次保存并显示缺项，连续补齐可包含已有预存草稿。

自动检查在任意页面工作，ERP 资料或参考成本回传后重新检查。最多 20 份为一组，在写入事务中重读来源和权限、完整性及归属；整组失败回滚、可重试，重复检查只产生一次自动流转审计。旧人工草稿在用户使用新流程保存前不自动发布。金融核算与正式成本口径保持，1688 只作参考。契约见 [实施记录](integration/PRESTORAGE_0.4.5.md)。
