# 0.4.21 ERP 回传总览与待处理 SKU（候选准备）

成本核对直接列出当前缺有效成本的店铺 SKU、平台 SKC、候选价格、具体异常原因和来源批次，包括一元采购及历史价格下降。六批回传统一展示；进入批次或 SKU 详情后可明确返回，关闭后重新打开总览。正常同 SKC 兄弟已采用的成本保持有效。

当前待补数按本月有效 ERP 或人工成本计算；人工补齐后退出待补列表，原异常证据留在批次历史，撤销后恢复缺失状态。重复回传按店铺 SKU去重，来源按请求/生成时间选取。跨批次连续更正绑定各自证据；价格处置与人工表单互斥显示并保留已填写金额/说明。

基线 origin/main `8b34ce0` / 0.4.20；[展示契约](integration/ERP_INBOX_REVIEW_0.4.21.md)。不改变价格拦截、最近三笔数量加权、月份范围、自动采用、人工优先及定稿保护。无数据库迁移，本机不安装，真实数据库和收件队列不改写。

184 个文件 / 1462 项前端测试、生产构建、完整 ERP/同步/部署门禁和 17 组 desktop verify通过。实际用户路径使用已校验的本机数据库副本，在全新隔离浏览器和候选资源中验收，原始证据仅本机保存。候选 smoke、包内资源一致性、PR/main CI和四公开资产回读完成后才标记公开发布。
