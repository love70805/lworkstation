# 导入与内置 ERP 可用性修复

2026-10-07，基线 bfe175e（公开稳定版 v0.4.5 后的仓库维护）。用户要求修复整批货号后缀应用后导入按钮无法点击，以及内置 ERP 反复超时、断联和不可用；完整目标包含实际运行和采集路径验收，不能只用模拟结果宣称可用。

## 契约与影响范围

- 导入：再次应用相同选择仍能自动重建预览；覆盖确认绑定最新预览，校验、零命中或确认缺失必须显示具体原因。工作簿与分块暂存生命周期、整批原子提交和工作区隔离保持。
- ERP：本机通道的心跳/状态响应不被历史证据的大文件读写阻塞。保留所有历史与收件证据、请求绑定、显式任务恢复、权限和月度核算口径；任何持久化优化须验证原子性、故障回退和重启恢复。
- 影响选品导入页面、收件服务、桌面通道控制和按实际原因需要适配的扩展通信；不改变 ERP 正式成本、人工优先或定稿保护，不清空队列、检查点及用户数据。

## 验收信号

1. 实际 CSV / XLSX 导入：首次与重复后缀应用、已保存相同选择、逐店修改、零命中、替换确认及实际写入。
2. 真实用户运行状态只读诊断；隔离真实 Electron/Chromium 扩展验证初始化、登录状态、采购查询、成本采集/回传、跨页面、长时运行、慢服务及重连。
3. 大队列与并发状态/心跳/任务操作保持响应，证据完整无丢失，写入失败原件保持、重启安全恢复。
4. 相关窄回归、完整前端测试/构建、ERP 门禁、desktop verify、候选用户路径/安装包核验、PR/main CI 和公开资产及更新入口回读。

## 当前证据

- 当前用户桌面进程为 v0.4.5，收件文件约 66 MB；现场握手超过 45 秒，落入连接失效判定。
- 旧服务所有 GET/POST 排队后重新读/解析整个文件，扩展心跳写整个文件；现场只读解析约 0.5 秒，序列化约 0.5 秒，尚未包含队列等待和磁盘同步。
- 导入 update 清空预览及源暂存；相同配置重新完成检查后，attemptedRef 仍记为已尝试，自动预览不再运行。两项新增回归在修复前失败；显式应用选择时重置尝试标记后恢复，不跳过校验与最新覆盖确认。
- 旧服务 68,757,271 字节隔离队列的 12 并发请求中，7 次达到 4 秒超时。修复后热查询不反复解析，重写和 fsync 在 worker 执行，状态及握手读取最后提交快照；32 次并发状态/握手与业务写入共存时最慢 162 毫秒，冷读取 1012 毫秒，所有历史证据哈希一致。
- 扩展握手只描述当前服务实例，不逐次改写历史证据；任务心跳写独立小型原子租约文件，校验实例、工作区、请求、范围与状态，重启仍必须明确恢复。后续任务写入优先于更早心跳，损坏及写入失败不发布未提交状态。
- 桌面重复刷新合并成一次探测，停止后不发布旧响应；远程视图延续工作区的后台运行设置。隐藏原生基线的 100 秒心跳未单独复现节流故障，不把后台设置当作已证实主因；大文件串行阻塞是已复现主因。
- 1326 项前端测试、生产构建、完整 ERP 门禁与 desktop verify 通过。源代码及生产版实际 CSV/XLSX、隔离 IndexedDB、重复后缀、记忆选择、零命中、逐店修改、最新覆盖批准、16 SKU/8 预存资料与浅深色/窄屏通过。
- 真实 Electron 44.2.0 Chrome 扩展 API（含两项实际 alarms）运行；冷启动、3 次真实页面刷新、36 并发连接刷新、采购列表/明细/SKU 映射、成本 4.0000、完整 v2 证据、后台心跳与中断自动重连已验证。候选资源的完整原生验收单独记录，接口 fixture 与真实运行证据分别标记。
- 现有 ERP 会话的隔离副本通过真实站点只读路径：实际查询按钮、一个 SKC/5 SKU、采购读取、有效成本、原生回传与完整 v2 收件证据。仅隔离队列接收，用户工作区、原队列及正式成本没有写入；验收报告只保留状态和数量。临时会话副本位于本机 Temp，工具自动审批拒绝清理（blocked by policy，未提供具体原因），不进入源码、候选或公开资产。
