## 实施契约

- 导入：Worker块经消费释放，临时来源与正式业务数据隔离；完整校验、物理源行及原值、整批原子生效、取消回滚、定稿和覆盖保护不变。以相同五文件、环境与采样口径复测0.3.6再比较，不使用旧数字冒充新实测。
- 选品：原始快照接口保持兼容；生产页面显式请求紧凑派生快照，缓存绑定工作区、成员可见性及来源版本。任何业务写入使最终投影失效；独立台账事实按保守财务来源版本复用，商品档案写入后重新套用当前人工字段和身份。编辑器按商品身份截取，整店完整来源先行验证，不把商品子集冒充整店。持久原始明细不裁剪。
- 页面外壳：百万行实测重复经营摘要读取约4.1秒，来自索引计数。摘要按工作区/成员/角色及全局来源版本缓存，销售行计数沿财务来源版本复用；台账、财务或上下文写入强制失效，商品保存后仍重算可见商品与审计计数。仅取最新审计时间，不把全量审计恢复载荷留在页面外壳。跨工作区竞态、缓存重开与同数量更新的liveQuery回归覆盖此契约。
- 连续建档：临时全量筛选队列按SKC/稳定身份去重；编辑器快照返回工作区，保存事务重核预期工作区。只有成功保存且无新增修改才推进；来源变化重新读取，已有档案跳过，返回恢复上下文。
- ERP：扩展受控本机检查点绑定请求范围与版本，未知账号/历史一致性必须重新核验；成本与可选资料分阶段，持久ACK及正式成本完整性保持。真实现场和生产回放分别记载。
