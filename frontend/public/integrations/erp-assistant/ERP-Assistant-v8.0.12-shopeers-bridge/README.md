# ERP Assistant Chrome 扩展

## 安装

1. 打开 Chrome 扩展管理页 `chrome://extensions/`。
2. 开启右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择项目内的 `8.0\Chrome扩展` 文件夹。
5. 刷新已打开的卓麟 ERP 页面。

## 运行准则

- 扩展只在采购管理 iframe 中运行，不读取其他网站。
- 用户先在采购管理页执行查询，扩展使用该次查询的完整参数进行核算。
- 有真实 1688 单号时，只使用最近最多 3 个 1688 采购记录计算数量加权成本。
- 1688 记录不足 3 个时不使用普通采购单补足。
- 全部历史都没有 1688 单号时，才使用最近最多 3 个普通采购记录。
- 当月明细、付款状态或 1688 订单状态为“已取消”的订单、已作废订单、无效日期和非正数量不参与核算。
- 采购单价为 0 或 1 时仅显示疑似异常提示，扩展不修改价格、不确认正式成本。
- 疑似异常不会阻止预览、复制、CSV 导出或自动回传；修正、确认和正式发布由 Shopeers 利润核算页负责。
- 回传数据包含同仓库 SKU 的全部有效历史采购记录、最近三次预览依据、作废/当月/无效排除证据与来源元数据。
- 任一分页、明细或平台映射请求失败时，本次核算立即停止，不会导出不完整数据。
