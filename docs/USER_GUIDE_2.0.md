# Lworkstation 2.0 使用指南（更新至 2.0.6）

适用于 Windows 本机桌面版。配图 PDF 随 2.0.0 安装包提供，截图为实际客户端与示例数据。

## 日常操作

1. 从工作区首页或月度账本导入销售台账，核对店铺与货号范围后导入。
2. 在利润核算页开始成本核算；明细与成本核对在同一页，正常 ERP 成本自动采用。
3. 在利润明细旁点“只看缺成本”核对待补项目，点“全部”回到原来的店铺和搜索范围。核对价格异常后可按项或按本月全部店铺忽略。缺少采购数据的项目可在行内补录。
4. 从利润核算页上方导出报表；代发、扣款与历史导出在可展开区域中。

月度利润明细默认按店铺和 SKC 显示分组汇总。点分组行可查看或收起该组 SKU，属性和已有的采购单号列在 SKU 下方。“展开全部明细”和“收起全部明细”对所有分页生效，仍可单独开合一组。整页向下滚动时，表头固定在顶栏下方。行右侧可查看成本详情或补录成本。

首页销售趋势可直接选择“按日”或“按月”，当前周期高亮显示。

## 导入与月份

支持 CSV、TSV、XLSX、XLS。优先从添加时间识别月份；从已有账本进入时使用该账本月份，正常情况显示文字而不要求手选。日期不足时才出现补选。跨月文件先按月拆分，同月多个店铺可一起导入。导入前查看识别月份、店铺、货号及勾选数量。

导入时，身份明确的新 SKU 会自动建立最小商品草稿。当前版本遇到身份相同而属性冲突的多行，会保留销售明细并跳过该 SKU 的草稿。台账自带且一致的 SKU 属性可以保留，缺少的商品名、属性和图片可在需要时补齐。可以直接继续本月的成本与利润核算。

## 忽略与恢复异常

“忽略”表示让可计算的原价继续参与核算，并不表示价格已核实正确。明确的 0 元、1 元和历史偏离价格可以使用；空白、没有采购数据或缺少必要对应关系仍会提示，不把空白当零。

| 需要处理的范围 | 忽略 | 恢复提醒 |
| --- | --- | --- |
| 一项 | 核对价格异常 → 忽略此项 | 已忽略异常 → 恢复提醒 |
| 多项 | 勾选需要的项 → 忽略选中 | 勾选需要的项 → 恢复选中 |
| 本月全部店铺 | 核对价格异常 → 忽略全部店铺异常（项数） | 已忽略异常 → 恢复本月全部提醒 |

提交前检查已选数量。空选不执行。按同一次回传的仓库商品处理，共用原始采购的 SKU 一同生效；范围显示为本月全部店铺。新回传不会自动继承忽略。原始证据保留，恢复后重新判断 ERP 成本，人工更正不受影响。

账本无需定稿或锁定，导出后也可随时调整台账、成本、仓储或补充来源，再导出新版。旧版曾标为定稿或锁定的账本同样可直接调整，不需要先重开。历史报表保留当时快照，不会因当前修改而变化。

明细旁的筛选同时控制商品小计和 ERP 采集范围。月度报告区的“补齐成本”会定位到全月所有店铺的待补明细。跨店查看时，同一平台 SKC 只计一次，同一 SKU 在两家店各计一条。行内显示待补原因；点“核对采购价”查看该店铺 SKU 的原始采购记录，缺少采购记录可点“补录成本”直接输入金额。

## 人工更正

已有成本时，点“成本详情”查看采用来源、单件金额和采购依据。要修改时再点“人工更正”，输入后可按回车保存。

输入非负单件成本后保存，支持真实零值与微小正数，系统记录更正。更正的范围限于当前工作区、月份、店铺和平台 SKU。常规核算中，人工有效值优先于后续 ERP 回传。保存后关闭详情，不再提供保存并下一项。需撤销时使用撤销当前更正，恢复最新可用 ERP 成本或缺失状态。新确认的共用费用和最低价规则仍待软件调整。[当前实现与项目约束的差异](CODEX_TASK_BOARD.md#软件实现与项目约束的差异)

## 商品资料与商品档案

进入商品资料，选择已有成本采集记录对应的商品范围，点击“一键获取商品档案”。后台按已取得的仓库 SKU 对应关系获取 ERP 表格档案，自动匹配并补齐名称、图片、属性和 1688 链接。可以继续使用工作台；登录过期时按提示登录后自动接续，暂停后点击“继续获取商品档案”。商品编辑页也进入同一获取入口。

取得对应关系需先完成该范围的成本采集；无需先忽略异常或确认全部价格。档案中的采购单价不作为月度正式成本，已有人工资料保持优先。资料缺项会显示待补齐，已完成结果保留，重新获取不会重新采集成本。

## 导出与进度

成本齐全后，页面上方可导出未扣款报告。需要代发、独立扣款或历史导出时，展开代发、扣款与导出记录。报告覆盖本月全部店铺，查看筛选不会缩小报告范围。按钮不可用时先看缺项提示，并处理无法计算的项目。新导出的表格用蓝灰色区分表头与合计，亏损金额以暗红字显示。

采集使用一条随真实阶段进度增长的进度条，运行时显示向右脉冲，暂停后停止。采集显示已完成数量和阶段，核算与导出显示处理中或当前步骤；未知总量不显示虚假的完成百分比。若提示等待登录，请在软件顶部的「ERP」标签页登录；后台核验后会自动接续原任务。若已经登录，可回到采集入口点「核验登录并继续」。外部浏览器的登录不能代替桌面版登录。权限不足或手动暂停时，请按具体提示处理；已送达的结果保留。资料补齐失败不撤回已生效的成本。

2.0.0 保留本机数据与现有自动更新方式。系统与备份仍在侧栏。页面计算与重复读取已优化，实际 ERP 速度仍取决于网络、权限和数据量。
