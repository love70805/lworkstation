# 大数据量响应与采集异常定位（0.4.41）

目标：修复 0.4.40 数据增长后全局切页卡顿；核对已完成任务持续增长的历时展示，提供映射缺项的具体定位。实际联网核对基线 `76f6936f0ae135d3c146fa5aeeb86ec460a38d85`。

## 影响与契约

- 限定读取模型、全局后台预存检查、ERP 状态和异常展示；复用现有 IndexedDB 和收件证据，不新增业务迁移。
- 已发布成本的目录来源沿用同一已校验批次，未采用回传仍校验请求与精确 SKU/SKC 身份。身份查找使用等价索引，保持冲突拒绝、人工优先与定稿保护。
- 无自动晋升候选时，不为全局后台自动建档加载整月销售和采购历史；有候选时仍执行原有完整核验。
- 已结束的成本采集以送达时间为终点，后台采用同步不延长采集时长；部分批次映射缺项保留原始异常，不猜测映射或提升为正式成本。
- 真实现场只读核对时间、存储体积及对应异常；私有标识和详细记录仅放在忽略归档。无清理业务库、收件队列、检查点或真实数据改写。
