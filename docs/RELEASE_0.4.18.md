# 0.4.18 货号组与 ERP 异常原因（已公开稳定 Latest）

货号后缀独立匹配时，LBYY 会漏掉同组的 LBY。新增按工作区保存的命名货号组，把多个明确别名共同筛选；支持货号末尾、包含和完整匹配，忽略大小写与全半角，保持原始货号、SKC 和 SKU 标识。成功导入后记住所用组和逐店增选/排除，下次按新文件重新匹配并加入新成员。逐店“未选”视图用于核对漏选；编辑或删除组需重新应用才改变本批选择，零命中保持未选。

ERP Assistant 8.0.41 的结果行说明缺失或无效单价、数量/日期、取消采购、台账月末前无采购、档案/映射或采购历史未读齐等原因。预览成本列固定在右侧，窄窗口也能看到成本和提示；支持“需核对”筛选、原因搜索与展开采购证据，CSV 提示原因一致。缺失金额仍为 null，真实 0 元和微小正数保持；疑似异常的候选金额保留供工作台核对，正常采用、人工优先、审计撤销和定稿保护沿用。

全自动独立后台采集仅保留为 Beta 开发目标；稳定版继续使用现有采集流程。无需数据库迁移，不改写真实库或队列，本机不自动安装。实施契约见 [记录](integration/SUPPLIER_GROUPS_ERP_FEEDBACK_0.4.18.md)。
