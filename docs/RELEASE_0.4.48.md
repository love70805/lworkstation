# 0.4.48 折叠/展开融入品牌行 + 账户头像居中

[v0.4.48](https://github.com/love70805/lworkstation/releases/tag/v0.4.48)：把折叠/展开操作融入侧栏品牌行，并修正账户下拉头像的垂直居中。

- 展开态：品牌行显示 L7 图标 + Lworkstation 文字标，右侧显示折叠提示图标；整块品牌行可点击，悬停高亮。
- 折叠态：只显示 L7 标记，悬停或键盘聚焦时标记右下角浮出展开提示；点击标记即可展开。
- 删除原先独立的折叠按钮和 0.4.47 的底部“展开导航”按钮；移动端抽屉里点击品牌行直接关闭抽屉。
- 账户下拉头像：此前 `.account-summary span` 的 flex 列规则覆盖了头像容器，圆内字母顶到上沿；现在头像恢复 grid 居中，尺寸 44px 与两行文字块同高，上下留白都是 16px，字母与两行文字同时垂直居中。

仅前端表现层（`AppShell.jsx` + `base.css`），未改业务口径、数据模型、成本/利润计算、定稿保护或桌面壳。验收按桌面窗口 980/1100/1280/1440。
