# v0.3.0 Beta

状态：候选准备，尚未公开发布或安装。

包版本使用 `0.3.0-beta`，标签应使用 `v0.3.0-beta`，与现有更新器的 SemVer 校验一致。仅交付 Windows 桌面版，不发布独立浏览器版本，不将 Beta 推入稳定更新通道。

## 变更

- 人工确认后允许删除任意状态月度账本，包括已采用 ERP 成本、已定稿、已锁定和含报告历史的账本；同步删除该月关联数据，保留操作审计，其他月份不受影响。
- 备份中心提升到一级导航，删除确认可直接进入备份；备份可选，不作为删除审批。
- ERP 页面使用候选、采用、撤回等业务文案；撤回不自动恢复更早 ERP 成本，也不改动有效人工成本。
- 已有冻结报告时，一次确认完成重开和撤回，原报告文件与明细保留；任何写入失败整体回滚。
- 利润页可从缺成本提示展开人工填写入口；移除不再使用且与人工成本含义冲突的旧 1688 参考审批弹窗。
- 首页、导入和核算页梳理步骤、状态和操作入口。
- 修复 Node 测试存储环境冲突、Beta 校验硬编码、Windows 原生 pnpm 启动和图标离屏导出。

## 验证

- 完整前端回归：110 文件，717 测试通过。
- 前端生产构建通过；既有 SheetJS 分包和 chunk 体积警告保留。
- 桌面 12 组验证脚本通过（图标导出修订后需再复验）。
- 新增冻结报告撤回、原子回滚、权限边界、直接删除已定稿/锁定报告、删除回滚和人工入口测试。
- 原始品牌 SVG 哈希未变；图标导出增加非空彩色像素检查。
- Windows 候选与实际桌面交互验收进行中；不能将构建通过视为已发布。

## 边界

- 不迁移或删除真实数据，不执行云端数据库迁移，不自动安装。
- `0010_manual_ledger_deletion.sql` 仅为已有云端兼容代码准备；桌面版使用本地数据库。
- 冻结报告只在人工确认删除整月账本时一起删除，撤回成本不会删除旧报告。
- 已锁定账本仍不可直接修改成本，但可以人工确认后删除。真实 ERP 账号采集、多机云端和签名安装升级不在本次合成数据验收范围。
- 公开发布前须完成候选验收、GitHub CI/集成和 Beta 资产校验；不使用 `v0.3.0beta` 作为更新器标签。
