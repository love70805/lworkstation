## 真实业务浏览器链路

使用临时台账 `shopeers-qa-20260807.csv` 验证：

```text
上传台账
→ 自动字段映射
→ 校验 3 行有效数据
→ 写入 2026-07 月度账本
→ 从利润面板复制平台 SKC
→ 自动保存 ERP 查询请求
→ 进入 ERP 成本核对
→ 导入 2 行 ERP 成本
→ 发布正式成本
→ 计算精确利润 ¥266.50
→ 月度定稿
→ 选品工作台回读 2 个 SKU 的 ERP 历史成本与利润
```

其中“利润面板复制筛选 SKC”现在会同时持久化当前工作区/账本的 ERP 请求，避免进入成本核对页后再次复制。
