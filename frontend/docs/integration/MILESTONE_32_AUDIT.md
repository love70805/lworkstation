# 里程碑 32：标准台账报表识别与供方货号多选

日期：2026-08-08  
状态：**已完成本机实现与验收**

## 目标

让利润核算直接适配组内真实的月度台账报表，不再要求用户在 A:T 的所有杂项列中手工寻找字段。

## 业务规则落地

- 自动识别标准报表核心列：A 变动类型、C 供方货号、D SKC、E 平台 SKU、G 属性集、H 数量、I 单价。
- 默认筛选“平台客单发货”和“客单发货”。
- 从整张明细表提取供方货号，并提供多选、全选和清空操作。
- 标准模式金额固定按 H 列数量乘 I 列单价计算，支持同一平台 SKU 在活动价和普通价之间存在多种单价。
- B 列结算类型、F 列商家 SKU、J 列及之后的扩展字段不进入利润明细。
- 导入批次保存筛选条件和金额计算方式，便于审计和重复导入追踪。
- 非标准 CSV/XLSX 仍使用原有通用字段映射和回退规则。
