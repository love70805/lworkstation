# v0.3.0 Beta.1

状态：候选验收中，尚未公开发布或安装。

## 变更

- 所有月份统一使用账本当月及以前的有效采购记录，禁止后续月份。采集时间不再决定核算月份。
- 月末截止筛选先于最近三条、1688 单号优先、数量加权和异常基线计算，其余口径不变。
- 采用成本时从本机账本独立读取月份并复算，拒绝页面未来预览价和被旧规则遗漏采购的批次。
- 旧已采用成本不静默重算：原金额保留，未来月份或日期证据不足时显示待复核，重新采集或人工填写。
- 缺成本筛选与利润计算统一；人工更正仍优先，已定稿报告不改写。
- 内置 ERP 扩展 8.0.18 保留原始采购证据，旧 v4 结果缓存失效。

## 验证

- 112 个测试文件、743 项测试通过，含十二个月、跨年、月末边界、仅未来记录、历史遗漏、独立采用校验和人工撤销。
- 完整本地发布检查通过；最终元数据/旧金额保留修订另补验 89 项测试。
- 12 组桌面验证通过；扩展 bridge、CSV、真实采集函数模拟和目录/ZIP 一致性通过。
- 既有 SheetJS 分包和大 chunk 警告保留。
- Windows 候选与隔离 Electron 交互验收进行中，尚未完成 GitHub 集成/公开资产回读。

## 边界

仅 Windows 桌面版，保持 Beta 通道，不替代稳定 Latest。不安装、不修改真实账本、不迁移云端数据库、不访问真实 ERP 账号。本次不包含台账自动月份推断。
