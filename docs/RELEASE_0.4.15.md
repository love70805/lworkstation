# 0.4.15 启动后空闲内存增长修复（已公开稳定 Latest）

用户安装 0.4.14 后无操作，工作台 renderer 私有内存达到约 2.5–3.0 GiB，CPU 持续忙。三个包含价格异常的 partial 成本批次在后台每五秒被重新处理；即使结果未变，仍更新批次并使财务派生缓存失效，反复校验证据与重建商品资料。

现在只有采用结果变化才同步批次元数据；无变化的成功检查复用内存结果，来源变化和失败仍重试。后台进度只读取小型采用状态投影，主页与预存检查共用既有 compact 参考计算。保持价格异常约束、人工更正优先、定稿与锁定保护；不增加迁移，不重置数据。

隔离回归先复现三个无变化检查仍三次写入，修复后不写入、不变更来源版本，也不再次读取采购证据；人工更正、锁定/解锁、旧元数据补齐、撤销和工作区切换仍刷新。174 文件 / 1367 前端测试通过。

同一份只读一致数据库副本含 8657 台账行、110 商品、367 正式 ERP 成本和 7 异常。原版与修复版相同入口、Electron 44.2、隐藏窗口、冷派生缓存，不强制 GC。Electron 进程私有内存在约 40 秒时由 1548.4 MiB 降至 425.1 MiB（约 72.5%），最终 181 秒空闲观察在 414.9–428.3 MiB，结束 422.6 MiB。此组不含独立 Node 收件服务，候选另记录完整进程树；不是任意登录页或任意规模资料的绝对占用承诺。诊断未重启/关闭或改写原应用，未安装。

最终安装包同副本隐藏运行约 189 秒，完整进程树包含独立收件服务在 530.6–541.2 MiB，结束 541.2 MiB；空闲期间财务来源版本未变。189 秒后再检查经营概览、利润、预存区的 1000/1440 浅深色窗口布局，无页面错误或整体溢出。所有业务表计数、采用状态与原始证据大小和启动前完全一致，7 条异常保留。

前端生产构建、完整 ERP/同步门禁、desktop verify、最终候选隐藏 packaged smoke、包内原生扩展启动/刷新/100 秒后台心跳/断联重连通过。原生 ERP HTTP 数据为隔离 fixture，扩展 API、渲染、存储、消息、收件进程和磁盘为真实；隐藏验收不作为最小化/托盘/焦点交互通过，本次不改变这些桌面行为。
