# 0.4.53 成本确认与利润界面响应

状态：候选验证中，尚未公开发布。

修复已采用正式成本较多时，采购历史排序反复解析日期和构造排序规则的问题；账本覆盖率与成本列表的重计算放到独立计算线程，切页或新输入会取消旧列表计算。界面在更新期间保留当前列表和分页，并明确显示更新状态。

利润读取只观察实际财务来源，回传状态与审计更新不再反复触发整月历史重读；业务表主键计数提供独立变更观察，旁库通知失败仍可接续实际数据更新。后台同一轮恢复最多临时共享一个账本的来源，解决超出缓存上限后逐批反复读取整月大证据的问题。

旧任务仅因成本已送达且未登记商品资料状态，不再显示“正在准备后台补充商品资料”。成本按原登记范围优先分批采集和采用，商品图片、链接等资料按需补齐；是否仍有成本异常以采用明细为准。

不改变成本、人工优先、月度定稿和原始证据复验规则，无数据库迁移。本机不安装、不重启用户工作台，不读取或改写真实业务库；验证使用隔离合成数据。大数据首次完整加载仍需等待，隐藏/headless 测试不代替真实 ERP 登录采集或可见窗口行为验证。

基线、契约和候选结果见[本批契约](integration/COST_PROFIT_RESPONSIVENESS_0.4.53.md)。原始私有证据留在忽略目录 `archive/cost-profit-responsiveness-20261021/`。
