# 0.3.7 发布与验收记录

## 发布内容

- 多店大台账导入减少内存副本，保留完整原始字段、校验、重复识别、整批生效与取消回滚。
- 选品按工作区及来源版本复用台账事实，减少反复打开档案、返回列表与筛选的等待。
- 连续建档提供“保存并下一个”，按当前完整筛选队列推进，保存失败或有新修改时留在当前商品，返回时保留列表上下文。
- ERP Assistant 8.0.28增加有界本机任务检查点，支持固定账号下刷新/重开后继续操作；采购证据重新读取，待投递结果沿原身份重试，读取、送达与采用分别显示。
- 采集期间改变工作台工作区、月份或登记范围时，旧结果停止回传；已保留的结果只重试原载荷，已送达的重复结果使用原回执。

## 实际限制

不改变ERP正式成本、人工更正优先、定稿保护及现有导出口径。真实台账只用于本机只读验证，没有内置安装包或上传仓库。
