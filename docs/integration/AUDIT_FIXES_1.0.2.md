## 范围与契约

- 导航范围：同账本保留并验证逐店/长列表 `supplier_scope`；切月按已读取的新账本范围求交集并重新绑定，失效或不匹配不得扩大为全部。覆盖侧栏、首页、导入返回及切月；缺失/空来源账本的范围引用保持空选，普通无范围入口仍默认首账本全部数据。
- 本机收件：全部携带能力令牌的工作台请求经过服务控制器，仅允许在线且自有子进程；冲突/停止/启动中阻止业务发送，在途归属失效拒绝响应。先发送无凭据随机挑战，校验 HMAC 后只在同一 TCP 连接发送令牌和正文，禁止验证后重新连接。内置 ERP session 在加载扩展前接管本机 HTTP 收件请求，统一经过相同验证；保留扩展原有 Bearer、25 MiB 上限、业务响应码和正文。保持离线工作台可用。
- 旧备份：恢复前在隔离暂存数据库复用既有迁移，验证升级后的数据再原子替换；迁移定义继续仅在 `clientDatabase.js`，不修改旧迁移。失败不清空当前业务库。
- 人工优先、零和微小值、月/店铺/SKU 归属、冻结报告和直接清空不自动备份口径保持。手动采用旧 ERP 来源的提醒仅为改进建议，不在本批扩大实施。
