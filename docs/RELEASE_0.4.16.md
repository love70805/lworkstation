# 0.4.16 ERP 维护恢复与整批采集反馈（已公开稳定 Latest）

ERP 维护期间，已送达成本仍可能缺少完整目录与平台映射。旧助手继续任务时会清空本地预览；重试失败批次可能沿用旧投递引用，未重新读取；状态栏只看最后一批元数据，可能掩盖前面批次的缺项。

现在明确维护页面/提示会暂停后续读取；HTTP 或网络故障有限重试后仍不可用也暂停，并持久保存原因。服务恢复后点击“继续未完成采集”，保留已有结果并核验原范围。一般目录或映射缺项最多自动复核一次，只刷新相关目标，继续保持原并发和分页上限；持续缺项仍需核对。
