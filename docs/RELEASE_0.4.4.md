# v0.4.4 整批后缀选择与自动基础建档

2026-10-07。状态：已公开为 GitHub 稳定 Latest，四资产与生产更新入口匿名回读通过。本机不自动安装，真实业务数据未改写。

导入页输入共同货号后缀即可一次选择整批店铺，支持多个后缀、全半角/大小写匹配与逐店例外；只匹配货号末尾，零命中保持空选择。新增文件沿用已应用规则，修改输入后须显式应用。导入按钮位于文件列表前方并随滚动保持可用，SKC 影响明细折叠保留；完整月替换及覆盖签名保护保留。

本批有效台账自动建立 SKC 父级和全工作区唯一 SKU 基础草稿，与台账、批次、审计一同提交或回滚。已有资料、人工售价和业务状态保留，不推测供应商、名称、图片或正式成本；冲突列为待核对，其他档案正常建立。重复导入不重复建档，无历史回填和业务表迁移。商品库标识基础档案待补全，编辑时沿用 ERP 补充资料投影。

成本与利润参考默认只显示未建档分支，部分建档保留其他 SKU；参考历史仍可通过“已建档 / 全部建档情况”筛选查看。旧版自动保存的默认“全部”首次升级为未建档，之后明确选择会记忆。

ERP Assistant 沿用 8.0.35 的每批 20 SKC、列表两路与请求最多八路、成本优先、任务持久化、暂停/停止/重试及显式重启恢复。多开页面未作为本轮方案，原因与契约见 [实施记录](integration/IMPORT_CATALOG_0.4.4.md)。正式成本、人工更正及定稿保护保持。
