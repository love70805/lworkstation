# 0.4.34 扣款货号多选

目标：扣款来源按完整货号复选；输入搜索时自动选中所有匹配货号，可逐项取消、全选搜索结果或采用全部货号。清空搜索保留已选范围，预览与采用覆盖同一范围。

基线：2026-10-17 联网核对远端 main `801b970f52184e3065184c53c963f4f1a8c0de36`；独立分支 `codex/deduction-multiselect-0.4.34`，接续 0.4.33 已公开稳定版。
