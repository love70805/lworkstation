# 货号筛选工作台契约

2026-10-13，实施基线 `a6a1506` / 0.4.19。本批只改进导入范围与利润/ERP 货号选择，不改变正式成本、人工更正或定稿口径，无业务数据库迁移。

- `supplierFilterPreview` 是只读投影：按工作区、月份、确认店铺与完整货号确定行标识；同货号跨店分别计数。来源行数来自映射后的实际来源，SKC/SKU 采用符合业务过滤及月份的标识集合并集，不从行数估算。
- Worker 建立独立于货号选择的紧凑候选索引，附带请求及修订号；完整成员仅在临时分块中保存并按需分页读取。搜索、分页与勾选复用索引，不重读文件。映射、来源、变动类型或店铺改变使索引失效；月份切换复用索引的月份证据。
- 规则编辑只改规则草稿；重新匹配或点击常用组生成选择草稿；手工勾选只改选择草稿。应用才替换待导入文件的筛选并重建校验和替换签名。撤销恢复本批最近应用的文件选择，不撤销正式导入。
- 同规则重新匹配保留逐店例外；其它组只使用该组兼容例外。搜索、查看店铺和零命中不静默修改选择。取消、失败不保存成功使用偏好，只有原子导入成功后记忆。
- 利润与 ERP 保留 `null = 全部`、`[] = 空选`，常用组只展开当前工作区/账本/查看店铺中的完整货号；缺失项可见。大范围导航使用限定账本的本机会话引用，小范围和旧 `supplier` 链接继续兼容；引用缺失时阻断为空选，不扩大范围。已启动 ERP 任务范围固定。

验收覆盖按店货号与去重统计、完整货号/前导零、规则与选择/应用边界、零命中和例外、过期异步结果、原子导入与替换确认、备份兼容、固定 ERP 范围；正式资源浅深色及 1600/1280/1024/390 宽度。规模为 1 万店铺货号 / 10 万来源行，测量 Worker 首次读取、已加载搜索/勾选、按需成员与返回。
