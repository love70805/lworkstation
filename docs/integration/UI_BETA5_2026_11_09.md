# 2.0.7-beta.5 · 导入顺序与控件对齐修复

2026-11-09。本批从已核实主线 `e1249cbbdbc4a03652de4cded2746d47250891c5` 接续，根据用户对 Beta4 的实际使用反馈，以 v2.0.6 的既有操作顺序为依据纠正界面退步。沿用独立 Beta 安装、数据目录及 `beta-sidecar` 通道。

## 已修复范围

- 导入：货号筛选恢复到文件明细列表之前，常用组、关键词及“匹配货号”直接显示。原匹配动作仍会触发自动校验；删除重复的“应用选择并校验”按钮及误导文案。手工勾选暂存，点击匹配或按 Enter 后统一校验，未校验选择不能导入。
- 货号清单：删除粘贴与导出清单入口；已选项通过原有“已选”页签核对，继续保留分页、搜索、逐店例外及失败回退。
- 利润：月份、店铺和月度账本按钮底边对齐；搜索、货号、成本状态与重置筛选统一为 36px。报告来源展开入口与导出按钮对齐。异常解释直接放在待办提示内，移除额外“核对说明”折叠层。
- 桌面：工作台 / ERP 页签恢复 v2.0.6 外观。

保留 Beta4 分批读取、后台来源指纹和分页等性能改进。本批没有新增组件依赖、重排其他页面、改变金额口径、迁移真实库或执行本机安装。仍待处理的业务差异见[看板](../CODEX_TASK_BOARD.md#软件实现与项目约束的差异)。

## 验收方法与边界

针对外框 1336×862（工作区约 1336×782），以七文件、十万来源行、127 个 SKC / 355 个已选 SKU 的隔离合成数据检查首屏位置、匹配后校验、手工选择失效和重新匹配、导入、采集任务、七项成本异常与报告导出。补验浅深色、1024 宽和 720px 等效缩放视口、键盘及展开状态；测量控件实际高度和底边，不以 CSS 数值代替渲染结果。

实际公司配置按 i5-11400、16GB 内存、无独立显卡考虑；这里是开发机功能与布局检查，不是公司电脑实测。公开记录不包含用户截图、公司名称或真实业务值。

本地证据目录为 `archive/ui-beta5-corrections-20261109/`。

## 已完成验证

- 完整原始发布门禁 40 项通过，含前端 246 文件 / 1,957 项用例及生产构建。新增回归固定七文件时筛选先于文件明细、只需一次匹配即可统一校验，并检查 Enter 和原有手工选择行为。
- 完整桌面验证通过。发布计划与两个包版本均为 `2.0.7-beta.5`，集成分支与基线同步更新。
- 七文件 / 100,000 来源行：匹配 TEAM 组后直接校验，得到 127 个 SKC / 355 个 SKU；7,000 有效行实际写入隔离库。手工取消会禁用导入，恢复后按 Enter 可继续。未选和业务排除行不写入。
- 模拟正在采集、已送达、七项成本异常、筛选缺成本、重置、展开来源和异常窗口；经界面处理合成异常后完成 XLSX 导出，来源指纹显示与当前一致。没有未捕获页面错误。
- 10 份渲染截图覆盖工作区 1336×782、1024×688、720×450、浅深色及展开状态。桌面月份/店铺/账本、搜索/货号/状态/重置、导出/来源入口实测均为 36px 且底边一致；720px 下月份/店铺/账本均为 44px。没有整页横向溢出。布局扫描结果为空，仍以截图和实际操作作为主要证据。

桌面验证最初发现发布计划仍为 Beta4，已同步版本及分支后完整重跑通过。浏览器检查曾发现搜索框实际比同排控件高 2px，已修复后重跑全部合成流程；已选视图取消会即时移除行，验收脚本改用固定身份检查，避免重新定位到下一行。
