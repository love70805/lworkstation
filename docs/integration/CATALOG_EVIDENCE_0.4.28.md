# 0.4.28 ERP 档案来源核对

目标：修复商品编辑器中相同 SKU 来源重复展示、采购证据长列表、属性已确认仍提示待核对，以及供应商多链接缺少明确选择入口。

实际基线：2026-10-15 已通过 GitHub API 核对并 fetch 远端 `main`，提交 `76692669e8eacbe3cfa5ae5d5456f5a5ff6fc4d1`（公开稳定版 0.4.27 之后的发布记录）。执行分支 `codex/catalog-evidence-0.4.28`。

契约与影响：

- 新增只读展示投影，将同一 SKU 的相同资料及相同采购记录合并展示，保留全部批次和订单来源；真实属性、仓库、供应商、采购规格、比例或图片差异不得合并消失。
- 采购证据按供应商、仓库、SKU 与采购规格归组，订单明细按需展开；采购规格保持独立于平台属性。
- 已确认属性及排除分支不再提示需要重复核对。供应商来源链接由用户在现有卡片中明确选择，使用已有字段编辑标记和保存审计；不自动覆盖人工资料、报价或成本。
- 无表结构迁移，不改 ERP 采集、真实数据库、月度正式成本、人工优先和定稿逻辑。

完成信号：重复回传只显示一个 SKU 卡片；真实差异和原始来源可查看；多链接可预览、明确采用并保存重开；已确认属性不重复警告；中文浅深色及窄屏可用。完成定向与必要回归、候选验收、受保护 PR、稳定发布和公开资产回读。本机不安装。

验证：194 文件 / 1541 项前端测试、生产构建、完整本地发布门禁和 17 组 desktop verify 通过；最终状态与组件调整的 44 项定向补验通过。无头页面使用两次相同回传、18 条采购和多链接供应商，24 组中文浅深色 × 375/768/1024/1440 布局无页面横向溢出、无页面错误；键盘展开订单、逐次选择商品/店铺链接、保存重开及属性确认通过。保存前后报价、ERP 成本及利润记录逐项一致，新增保存审计。审查补齐缺失标识不合并采购、稳定供应商身份边界、店铺链接清空商品 ID、已保存提示及连续选择不收起。

候选验收、PR 集成和公开发布：待最终候选完成后分别记录。全部业务验证仅使用隔离合成数据，尚未安装本机或操作真实账号。
