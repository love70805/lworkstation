# 0.4.24 正式使用可靠性优化

## 目标与实际基线

用户要求深度优化并达到正式使用要求。本批先收敛已核实的日常可靠性缺口，基线为 2026-10-14 实际 fetch 核对的 origin/main `404fe642e8f3b94b8824a082fbd90380db291878`（0.4.23）。

## 契约与影响

- 台账导入：选择文件后，返回、站内跳转和刷新需要保护本次准备；原子写入期间阻止直接放弃，原有取消与回滚保持。成功后可直接进入本月成本核对。
- 备份：文件已保存和操作记录已登记分别反馈；恢复提交完成后立即结束恢复确认，附加记录失败不能提示恢复失败或诱导重复恢复。普通保存失败及取消仍不得登记成功；恢复前回滚备份要求保持。
- 页面恢复：导航辅助范围读取失败不得使系统检查和备份页面整体崩溃；账本来源加载、失败、空结果各自明确，切换月份不展示旧来源，允许就地重试。
- 不调整成本公式、数据库结构或业务范围。默认 CNY、正式 ERP 成本、人工优先、零/微小值、定稿保护及 SKU 归属沿用；暂停的云端和后台自动采集范围不恢复。

## 完成信号与验证

1. 复现并验证返回/刷新、写入中离开、取消回滚、成功进入下一步。
2. 注入文件保存后登记失败、恢复提交后登记失败，状态和提示准确；取消和文件保存失败继续阻断恢复。
3. 注入导航与来源查询失败，页面保留，重试可恢复；延迟旧月份响应不能显示为当前月份。
4. 完整前端 test/build、桌面 verify、隐藏候选及包内真实路径、中文浅深色与窗口/窄屏检查。候选、合并、发布和公开资产回读分别记录。

## 验收结果

192 文件 / 1510 项前端测试、完整发布门禁和生产构建、17 组 desktop verify 通过；最终候选隐藏 smoke 通过。包内实际 CSV 导入、返回/刷新保护、人工零值/微小值、零代发、报告定稿下载、导航/来源查询故障重试、真实文件保存和取消/成功恢复路径通过，销售明细和定稿报告恢复前后相同。30 组中文浅深色 × 1280/900/390 布局无页面横向溢出，新增持续提示正文对比度最低 14.84:1，无页面运行时错误。704 安装文件 / 658 生产输入逐字节一致，构建源码 `0fa23cabcb5c87643b8c85bff338b38e2691984c`，安装包 119578311 字节，SHA256 `7D6BAA3A1EC5B6232B962F3F902BF7F6938B8E7B11466D7733DE600DA0AAD138`。

## 交付边界

无数据库迁移，不安装本机，不改写真实业务数据或收件队列。原生窗口、登录和 ERP 扩展实现未改；隐藏 smoke 不作为真实可见窗口、托盘或焦点验收。真实 ERP 登录/远端站点行为不由本批合成样本证明。暂停的账号云端及后台自动采集仍不推进。
