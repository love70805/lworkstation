# ERP 采购核价与自动采用（0.4.27）

目标：修复助手和工作台的异常提示差异、确认采购真价后仍需人工成本，以及详情中的手动载入步骤。实际联网核对主线基线 `cf401a24ef0c9b1b596e6ac415334f063a145b9a`（0.4.26）。

## 契约与影响

- ERP 助手对当月及以前的有效采购按工作台相同阈值检查 0/1 元、近期整体涨跌和极端偏离。明确助手为当前采购预览、按仓库 SKU 计数；工作台为全部回传的当前待补项、按店铺 SKU 计数。助手不写正式成本。
- `erpCostInbox.costResolutions` 保存经原始证据独立校验的采购核价记录，限定工作区、账本、原批次、仓库 SKU 和采购记录。确认逐笔持久化；所有异常解决后自动复算并采用 ERP 正式成本，不再额外要求人工更正或点击重试。原始采购封装不改写。
- 成本详情直接使用所选回传的证据核价，不切换或覆盖另一批草稿。状态区分“采购价已确认”“仍有其他采购待确认”“ERP 成本已采用”。已有核价草稿在归属校验后恢复同批确认。
- 使用现有事务、成本精度、人工优先、新来源顺序和定稿保护。无表结构迁移；不操作真实数据库或本机安装。
