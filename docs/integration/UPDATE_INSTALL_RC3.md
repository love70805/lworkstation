# RC3 自动更新安装契约

基线：2026-10-22 联网核对的 `8eb6075169768a6818d8d8f5958ce6b9ae91d0bf`。目标版本 `1.0.0-rc.3`，独立 RC 候选通道；稳定 Latest 保持 0.4.54。

- 安装权限以当前程序对应的 Windows 安装注册范围为准，匹配实际安装目录；全机安装请求正常 UAC 提权，当前用户安装保持当前用户范围，不根据发布包的全局 `isAdminRightsRequired` 误判本机范围。
- RC3 安装器兼容旧 RC2 的 `--updated --force-run` 调用。提权取消或失败必须显示中文原因，不无提示退出、不切换安装目录、不新建另一份安装。
- 新客户端先验证已下载文件及 SHA512，再启动安装器。安装器完成权限核对后，通过本机随机命名管道报告就绪；客户端收到确认才停止收件并退出，安装器等待该进程正常退出后接续安装。失败或超时保留窗口与已下载包，允许重试，记录不含业务数据的阶段/错误码。
- 不更改业务库、成本政策、定稿保护、账号、系统 UAC 或 Windows 全局权限。验收优先使用隔离合成环境；真实旧版点击安装的最小必要交互集中进行。
