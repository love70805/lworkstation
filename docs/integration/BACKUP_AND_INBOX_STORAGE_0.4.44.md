## 契约和验收信号

- 清空入口先停止工作区后台写入，保存并校验覆盖全部删除范围的回滚备份：IndexedDB、业务筛选、成本草稿、桌面收件和任务。备份保存失败、取消或接口不支持时不清空。重复点击只执行一次；保留备份位置并如实区分保存、清理与刷新失败。恢复必须验证新增范围并完成隔离往返。
- 原始采购证据作为不可变文件保存，状态变更写小型增量日志；日志达到阈值只压缩元数据。已确认大证据退出常驻热数据，重复投递需要时按引用读取，完整证据继续保留。未确认收件、请求身份、去重、继续任务、心跳、人工有效成本及定稿保护保持。
- 旧数组文件只读保全后兼容导入新格式；新格式校验引用、顺序和增量校验和。截断尾部、损坏、外部替换、存储失败和进程重启有明确结果，不静默当空库。不得以限制历史增长为由直接删除原始采购证据。
- 对照相同合成大数据的状态写盘字节、延迟与内存/热证据驻留；不能据合成结果承诺真实任务的具体分钟数。真实数据库、队列和已定稿数据不用于破坏性验收。
