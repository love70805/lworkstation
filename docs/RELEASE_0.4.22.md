# 0.4.22 商品资料与主流程实用性（候选准备）

同一平台 SKU 的明确颜色/尺码与代码组合仅顺序不同时，不再误报资料冲突；保留原始属性、来源及人工字段。真实属性差异在编辑器内直接选择来源，既有身份冲突和财务校验保持。

商品库分别显示 ERP 采购、参考利润、定稿历史和仓库映射；有售价及参考成本即可显示参考利润，无月度报告显示“尚无定稿”。缺项筛选不再将单纯未定稿视作商品资料缺失；筛选与导出采用对应状态。

商品读取失败提供重试与返回，已输入内容及未保存保护保持；预存属性缺项可直接定位。首页提供按所选月份/店铺状态的主要下一步，定稿月份直达报告。账号云端方案暂停取消，既有 Beta 不进入本批。

基线 3b30daf / 0.4.21；[实现契约](integration/CATALOG_USABILITY_0.4.22.md)。无业务迁移、不改真实数据或队列，不自动安装。测试、候选、CI及公开资产回读通过后才标记发布。
