# 里程碑 11：开发同步合同与 ERP 发布不变量

状态：本机开发同步服务可自检，ERP 发布追溯门槛已下沉到数据层；外部云资源仍未创建  
审计日期：2026-08-07

## 已完成

- 新增 `pnpm sync:check`，自动启动本机同步服务并验证：
  - 健康检查；
  - 审计事件上传；
  - 重复事件幂等；
  - 错误令牌拒绝；
  - 云端种子预检；
  - 云端种子导入；
  - 重复种子导入幂等。
- 新增 [DEPLOYMENT_GUIDE.md](../DEPLOYMENT_GUIDE.md)，固化本地开发、同步服务、环境变量、发布前门禁和上云顺序。
- ERP 成本批次发布现在必须满足：
  - 存在当前工作区和当前账本的已记录 ERP 请求；
  - 账本未定稿或锁定；
  - 发布工作区与账本工作区一致。
- 新增数据库级回归，证明直接绕过页面调用发布 API 时，缺少 ERP 请求关联会被拒绝。

## 验证

- `pnpm sync:check`：7 项开发合同检查通过。
- 集成测试：商品、台账、ERP 成本、利润定稿、选品参考闭环及未绑定请求拒绝均通过。
