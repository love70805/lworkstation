# 里程碑 6：本地备份到云端种子包

状态：已完成本地生成与校验，尚未连接真实云端
审计日期：2026-08-07

## 已实现

- 新增 `shopeers-cloud-seed` v1 格式，目标标记为 `shopeers-postgres-v1`。
- 云端种子包只包含业务表：工作区、商品、平台 SKU、供应商、采集、账本、销售导入、ERP 成本、1688 审批、利润和审计记录。
- 明确排除 `settings`，不携带浏览器端设置、最近备份路径等设备状态。
- 清理审计 outbox 字段：`syncState`、重试次数、领取时间、失败信息和本机同步回执不会进入种子包。
- 生成和校验阶段都检查：工作区 ID、CNY 币种、未知表、非法记录、跨工作区记录及平台 SKU 全局唯一性。
- 数据安全页新增“导出云端种子包”按钮。该按钮只下载本地 JSON，并明确提示尚未上传。
- 导出行为写入本地审计记录 `cloud_seed_exported`，与完整本机备份分开标识。

## 尚未实现

- 云端种子包的服务端导入事务和冲突预览。
- 真实 PostgreSQL/Supabase 连接、成员权限和 RLS 验证。
- 对象存储中的原始台账、图片和备份包托管。
- 从 ERP Assistant v8.0.0 到 Shopeers 的正式在线桥接。

- Vitest：24 个测试文件，74 项测试通过。
- Vite production build：1758 个模块转换成功。
