# 0.2.17 分组销售图

## 范围与兼容
- 每日按日期分组，每店一根柱；新增每月视图，用当前月份和可选对比月份的店铺完整月总额并排比较。
- 固定店铺颜色和槽位；图例开关仅影响图形，悬停或键盘聚焦读取数据。月柱点击定位该月每日图。
- 恢复图表/明细 1:1.15 比例，窗口足够时并排；经营概览右侧信息在 1024px 及以上保留右栏。窄屏正常折叠。
- 月度金额包含缺少有效日期的来源；负数/真实零值/无来源分开表示。派生缓存公式升级为 daily-sales@4-grouped，业务数据库仍为 v15。

## 发布前验证
- 完整前端 108 文件、688 测试通过；生产构建通过（现存大包提示）。桌面 verify 全部通过。
- 隔离 Edge 合成 10 万行主月、1 万行对比月、5 店：每日/每月、图例、月份悬停、明细翻页、连续输入通过；390/768/1024/1280/1440 浅深色无页面横向溢出；明细滚动区 420px。
- 1280px：明细 329px、图表 286px（1.15），左右顶部一致，经营概览主栏与右栏顶部一致。
- 本机不安装；真实数据未改。Windows候选与公开资产回读结果发布后补记。
