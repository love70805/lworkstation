# v0.4.0 本地运营负责范围

基线：origin/main 0106372（v0.3.13 / ERP Assistant 8.0.33）。用户确认 SKC 对象查询修复。本版仅引入本机具名运营方案，不新增账号、云端或权限隔离。

## 契约与边界

- 方案按工作区保存到独立 localStorage 配置：version、profiles（id/name/pairs）、activeProfileId、mode（all/mine）。pair 是真实的 {store, supplierNumber}，不可把两个独立数组做笛卡尔积。货号保持字符串与前导零。
- 首次使用为全部商品；我的商品未选方案、空方案、损坏配置均不能回退为全部。保存失败向用户报错。切换及重启保留选择。
- 从有效台账身份构建店铺＋SKU 对应关系，选中货号后纳入该店铺同 SKU 的完整历史。选品父级用所属 SKU 身份判断，不能凭同名货号跨店铺纳入。
- 利润始终使用完整 snapshot/正式成本/人工更正/定稿快照计算，然后筛选展示与导出。ERP 目标从相同展示范围生成，保留正式 SKC/SKU 对象契约。自动回传及整月定稿仍使用原有全量链路。
- 台账范围摘要是只读投影；整月状态、定稿和来源确认仍属于完整账本。我的商品下禁止整月删除、定稿和整月报表生成等容易误认为局部操作的入口，切至全部商品后操作。
- 不执行真实业务迁移，不改数据库结构，不清空收件队列/检查点，不安装候选。

## 影响与验收

新增 domain 范围契约、本机配置 hook 与头像管理弹窗；接入选品、利润、台账和 ERP 目标。测试覆盖方案切换/重启/工作区隔离/空范围/同货号不同店铺/完整历史/对象请求/全量与定稿保护。发布门禁包含前端全量测试与构建、desktop verify、隐藏候选 smoke、浅深色和窄屏验收、PR/main CI、稳定版上传及匿名完整资产哈希回读。
