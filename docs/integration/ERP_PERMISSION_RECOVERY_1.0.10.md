# ERP 店铺权限异常暂停与恢复

用户于 2026-11-03 要求完善已登录 ERP 仍出现采集权限错误的处理。实际联网核对主线与 `v1.0.9` 均为 `4a28474dd294f97c7a6f6d9e15053d23539f1936`，在独立执行树集中交付一个 1.0 系列补丁。

## 契约与范围

- 将业务错误 `-40102`，以及非成功响应中明确的店铺权限校验失败或数据库地址缺失提示，识别为 `ERP_PERMISSION_REQUIRED`；不把通用 `-50001` 或这些提示中的成功响应一概判为权限异常，也不据此声称用户未登录。
- 采购列表、明细、目录、SKU 映射及补资料共用该判断。发现后中止本批并暂停任务，未完成成本批次保持待处理；不继续消耗其他批次，不回传不完整的本批结果。
- 收件任务允许持久化该暂停原因，沿用原有字段白名单和长度限制。继续原任务时清除旧原因，重新核验未完成批次；已送达成本、人工有效值、月度定稿及完整采购证据保护沿用原契约。
- 工作台及 ERP 助手明确提示检查采购查询后继续原任务，保留停止入口。桌面继续沿用隐藏采购页和共享 ERP 会话，无需用户一直停留采购页。
- 本批不推断 ERP 权限错误的最初来源，不修改账号权限、真实业务库或现有任务，不安装或重启用户软件。
