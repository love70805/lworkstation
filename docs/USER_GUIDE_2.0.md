# Lworkstation 2.1 使用指南

适用于 Windows 本机桌面版 2.1.2。

## 日常操作

1. 从工作区首页或月度账本导入销售台账，核对店铺与货号范围后导入。
2. 在利润核算页开始成本核算；明细与成本核对在同一页，正常 ERP 成本自动采用。
3. 在利润明细旁点“只看缺成本”核对待补项目，点“全部”回到原来的店铺和搜索范围。核对价格异常后可按项或按本月全部店铺忽略。缺少采购数据的项目可在行内补录。
4. 在「代发与扣款」登记已取得的来源，再点击页面上方的导出按钮保存 Excel。

月度利润明细默认按店铺和 SKC 显示分组汇总。点分组行可查看或收起该组 SKU，属性和已有的采购单号列在 SKU 下方。“展开全部明细”和“收起全部明细”对所有分页生效，仍可单独开合一组。整页向下滚动时，表头固定在顶栏下方。行右侧可查看成本详情或补录成本。

首页“销售与利润趋势”可按日或按月查看。当前范围成本核齐后，默认显示商品利润，也可以切换销售额和销量。商品利润等于销售原额减采购成本和仓储费，仓储费按销量和本月费率计算。整月的代发和扣款在“利润核算”页查看。缺少正式成本的商品及其所在的汇总显示“待核”。

按日图中只显示一家店铺时，点日期柱即可查看该店当天的商品。显示多家店铺时，先查看当天的店铺列表，再点一家店铺。商品利润视图可点“亏损最多”或“利润最高”定位明细，也可以点“只看亏损”查看所有已核亏损项。点商品行可查看每件利润，销售额和销量视图中可点饼图或表格查看占比。点左上角的返回按钮或按 Esc 回到上一步。

## 导入与月份

支持 CSV、TSV、XLSX、XLS。优先从添加时间识别月份；从已有账本进入时使用该账本月份，正常情况显示文字而不要求手选。日期不足时才出现补选。跨月文件先按月拆分，同月多个店铺可一起导入。导入前查看识别月份、店铺、货号及勾选数量。

导入时，身份明确的新 SKU 会自动建立商品草稿。台账自带且一致的属性会带入草稿。属性有冲突时该字段留空，可稍后补齐，销售明细照常核算。

## 忽略与恢复异常

“忽略”表示让可计算的原价继续参与核算，并不表示价格已核实正确。明确的 0 元、1 元和历史偏离价格可以使用；空白、没有采购数据或缺少必要对应关系仍会提示，不把空白当零。

| 需要处理的范围 | 忽略 | 恢复提醒 |
| --- | --- | --- |
| 一项 | 核对价格异常 → 忽略此项 | 已忽略异常 → 恢复提醒 |
| 多项 | 勾选需要的项 → 忽略选中 | 勾选需要的项 → 恢复选中 |
| 本月全部店铺 | 核对价格异常 → 忽略全部店铺异常（项数） | 已忽略异常 → 恢复本月全部提醒 |

操作前请核对店铺、仓库商品和勾选数量。同一月份、同一仓库商品复用同一组采购证据时，忽略决定可以沿用。采购证据或异常原因发生变化时，系统会再次提示核对。

打开「采购详情」或利润行的「成本详情」，可看核算月及以前的历史价格区间、中位数和最近三笔合格采购，每笔旁显示单价和触发原因。展开排除订单可查看回执中的单号、日期及原因。历史正单价少于六笔时会显示样本数。

成本采集结束后可直接补录。需再次从 ERP 采集时，点击「重新获取 ERP 成本」后选择范围。导出后仍可更新同月账本并生成新文件。

明细旁的筛选同时控制商品小计和 ERP 采集范围。月度报告区的“补齐成本”会定位到全月所有店铺的待补明细。跨店查看时，同一平台 SKC 只计一次，同一 SKU 在两家店各计一条。行内显示待补原因；点“核对采购价”查看该店铺 SKU 的原始采购记录，缺少采购记录可点“补录成本”直接输入金额。

## 人工更正

已有成本时，点“成本详情”查看采用来源、单件金额和采购依据。要修改时再点“人工更正”，输入后可按回车保存。

输入非负单件成本后保存，支持真实零值与微小正数。当前工作区、月份、店铺和平台 SKU 共用一笔有效人工价。常规核算优先用人工价，最低模式在人工价和合格 ERP 历史最低价中取低。撤销后两边分别重算。仓储费率与已采用的代发、扣款在两种模式间共享。

常规 ERP 单价用最近至多三笔合格采购的总金额除以总件数。常规模式将所选采购总价乘销量再除以采购总件数，人工价按录入值乘销量。例如采购总价为 3.7778 元，共 3 件，卖出 3 件的采购成本就是 3.7778 元。常规单价在工作台和 Excel 中最多显示八位小数，加权单价单元格可查看公式。最低成本模式先比较人工价与合格 ERP 历史最低价，选定后向零截到两位再乘销量。金额合计后按分展示。采购详情保留原始金额。成本齐全后，可在当前范围右侧重新获取 ERP 成本。首页显示「查看本月利润」。

## 商品资料与商品档案

进入商品资料，选择已有成本采集记录对应的商品范围，点击“一键获取商品档案”。后台按已取得的仓库 SKU 对应关系获取 ERP 表格档案，自动匹配并补齐名称、图片、属性和 1688 链接。可以继续使用工作台；登录过期时按提示登录后自动接续，暂停后点击“继续获取商品档案”。商品编辑页也进入同一获取入口。

取得对应关系需先完成该范围的成本采集；无需先忽略异常或确认全部价格。档案中的采购单价不作为月度正式成本，已有人工资料保持优先。资料缺项会显示待补齐，已完成结果保留，重新获取不会重新采集成本。

## 导出与进度

扣款后报表在「汇总表」每家店的小计下列出本店扣款和扣后利润，与该店工作表末尾一致。独立扣款保留来源正负，负扣款会增加利润。代发单列在整月汇总中。扣款金额和负利润使用红色字体。

成本齐全后可导出本月全部店铺的报告。导入代发表时默认只勾选核算月，遇到跨月来源可自行展开选择。代发未录时金额显示「未录入」，导出的利润只计入已取得的来源。扣款未齐时可导出未扣款报告，各店扣款齐全后可导出利润表。文件由用户自行保存。

采集使用一条随真实阶段进度增长的进度条，运行时显示向右脉冲，暂停后停止。采集显示已完成数量和阶段，核算与导出显示处理中或当前步骤；未知总量不显示虚假的完成百分比。若提示等待登录，请在软件顶部的「ERP」标签页登录；后台核验后会自动接续原任务。若已经登录，可回到采集入口点「核验登录并继续」。外部浏览器的登录不能代替桌面版登录。权限不足或手动暂停时，请按具体提示处理；已送达的结果保留。资料补齐失败不撤回已生效的成本。

工作区备份、恢复和应用内更新位于「系统与备份」。
