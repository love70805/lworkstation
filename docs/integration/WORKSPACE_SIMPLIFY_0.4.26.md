### 通道契约与退役兼容

- `POST /erp/v1/workspace-context` 仅由可信工作台经桌面 IPC 同步 workspaceId/memberId/visibility，配置 ERP 会话后直接回复，不作为 HTTP 采集写入。原有失败回滚和成员/工作区校验保留。
- `GET /selection/v1/captures`、`POST /selection/v1/captures/ack` 仅用于恢复历史收件。空队列恢复后停止该身份的轮询；失败不删除，保留后续重试。
- 旧 context/extension-status 及 captures 新写入返回 HTTP 410，桌面受控 IPC 不开放这些写入；status 只读响应标记 retired。测试确认退役请求不改写历史证据，并覆盖跨工作区和私人记录隔离。
- 删除模块专属构建/安装代码和测试，以退役响应、资源缺席及真实升级恢复验收替代；保留旧数据契约用于备份和历史读取。
