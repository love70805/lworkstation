# 本地 Beta.15：完成采集后的异常解锁

2026-11-13。基线为本地 Beta.14 提交 `8b920a7`，继续当前执行树与分支。用户反馈任务已送达全部成本，仍显示“成本已送达，正在完成本机核算”，异常不能更正或忽略；成本详情的“确认采购价正确”点击没有反应。

## 根因与修复

- `listErpCostAdoptionStates` 的缓存命中分支没有注册回执变更依赖。后台报告或另一个组件先预热缓存后，新订阅者可能一直保留旧回执列表或 `adoptionPending`，即使其他界面已经显示成本更新完毕。两个新增隔离用例在 Beta.14 源码上均失败，复现最后回执到达、等数量状态更新后不解锁。
- 每个消费者先订阅来源修订信号，再读取缓存；可重建缓存不可用时直接读取并监听业务回执。保留轻量投影和缓存复用，不加载采购证据到组件。
- 成本明细和原地编辑使用父页面的同一份防误改状态；确认原价不再因旧父状态静默返回。写入时仍检查真实任务和回执；状态变化、只读或证据变化会显示具体错误。
- 已完成核算且剩一条价格异常时允许正常处理。真正采集中、本机尚待采用和采用失败仍保持保护；不靠全部异常清零判断完成。
