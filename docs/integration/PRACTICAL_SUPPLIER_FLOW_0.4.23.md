## 本批范围与契约

- 简化常用货号组：组名默认由关键词生成，可自定义；名称不重复附加相同别名。选组用于生成本次选择，保存、重命名及删除不改变本批筛选。管理按需展开，已有组 ID、名称、匹配方式、成功使用的逐店例外和工作区隔离保持。
- 货号规则编辑、生成匹配选择、应用到待导入文件和正式原子导入保持分步。修改关键词尚未匹配时，明确显示并阻止应用旧选择；已应用且未变化时不重复应用，正式预览提供独立“重新校验”，主动刷新后重新确认覆盖范围。撤销、清除匹配条件及手工勾选的行为明确，失败或取消不记录成功偏好。
- 检查相邻成员读取与利润/ERP 共享货号选择器，补齐可复现的失败恢复和陈旧提示。`null = 全部`、`[] = 空选`、月份/店铺/工作区范围、已启动 ERP 任务及正式成本、人工优先、定稿保护保持。
- 使用现有 React 组件和模块样式，无新业务模块或数据库迁移，不修改已保存真实组、台账、队列或检查点。

## 完成信号

1. 单关键词 HHHX 无需再填写相同组名，显示不重复；多关键词和自定义组名可保存、重开、修改，失败保留输入并明确反馈。选组、保存、取消和删除的范围经过隔离验证。
2. 关键词变化后不能误用旧选择；匹配、手工例外、应用与撤销往返正确，清除条件不悄悄清空已选。相邻读取失败有恢复入口；共享筛选状态及零命中行为准确。

## 已验证交付

常用组直接点名称，保存时默认取货号关键词，不再重复拼接相同别名。名称及匹配条件放进管理窗口，查看或修改其他组不会改掉本次关键词及勾选；取消和保存失败保留本批选择，删除组需确认。

关键词或匹配方式修改后先匹配再应用，阻止误用旧选择和旧导入预览。清除匹配条件保留勾选，空关键词时可正常手工选择。已应用且未变化时不重复应用；主动刷新预览使用独立“重新校验”，重新确认替换范围。

成员明细失败可原处重试，过期响应继续忽略；利润/ERP 共享选择器清理陈旧的组提示，保持全部与空选的区别。已有组 ID、名称、成功使用的逐店例外及工作区隔离保持，持久化格式不变。
