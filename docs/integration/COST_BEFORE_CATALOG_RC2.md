## 契约与影响

- 成本阶段保留必要的目标身份、平台 SKU 映射与完整采购历史读取。它们用于限定核算范围，阶段文案明确其成本用途。
- 新协调任务采用 `after_costs` 资料策略。只有全部成本批次完整送达，且本机逐批处理与核算回执已持久报告，才允许资料阶段。人工有效值、缺失、异常和定稿保护等处理结果不被伪装成成功成本。
- 顺带取得的资料与原始采购证据随成本收件持久暂存；资料阶段从同一任务、批次和尝试的持久收件恢复种子，复用已完成目录、映射和采购证据。只为缺失信息请求 ERP。
- 本机商品投影与后台自动建档也遵守屏障。尚无放行记录、暂停、失败、重启或状态读取失败不能提前释放。旧版本历史与独立手动资料请求兼容。
- 不迁移真实业务库，不改人工成本优先、CNY、SKU 唯一规则及定稿保护，不改清空不自动备份的口径。
