# Beta.3 核算月及以前最近三笔

2026-09-21 用户纠正 Beta.2：采购范围包含核算当月及以前月份，排除后续月份。本合同取代 Beta.2“排除核算当月”的临时规则；继续使用 Beta 通道。

## 计算与界面

- 数据库账本 `period` 是唯一可信核算月份。按中国业务时区判断采购月份，含月末最后一刻；无时区日期按中国时间解析，显式时间戳字段不能覆盖采购日期。
- 先过滤后续月份、取消关闭和无效证据，再按采购业务时间降序取最近三笔。不优先 1688，b,a,b,b,a,a 仍选 b,a,b；不足三笔使用实际笔数，无记录保持缺失。
- 数量加权，Decimal 单件成本向零截断四位。异常基线只使用合格范围内证据，人工更正仍优先，允许真实零与微小正数。
- 仓储层按账本月份独立复算，保存完整证据、采用 ID 与决策版本。成本核对与 ERP 助手预览文案明确含当月、排除后续月份。助手预览仍不假设账本月份。

## 历史采用与缓存

- 新决策版本为 `shopeers-cost-resolution@5-unit-4dp-beta-current-month-latest-three`，成本策略升级至 `formal-cost-policy@10-beta-current-month-latest-three`，活跃利润产品缓存键升级至 `products@5-beta-current-month-latest-three`。
- Beta.2 保存的 `on_or_after_ledger_period` 和旧月末截止 `after_ledger_period` 是派生标签。只读复算按当前账本重判；仅由这些标签导致的 `eligible:false` 可以重新判定，取消、关闭、无效或其他独立排除原因继续生效。存储证据不改写。
- 新选样与原采用不同，或旧采集 `current_month` / 仅保存在排除区的月份证据遗漏了本月及以前采购，均转待复核。保留原金额，暂不计入活跃利润；兼容且证据充分的原采用继续可用。不会只因版本号不同就改价或使所有历史采用失效。
- 人工有效值覆盖待复核 ERP；撤销后只有符合当前范围与选样的 ERP 才恢复，否则保持缺失。冻结报告、已存 Excel、原审计及原金额不改；禁止向已定稿或已锁定账本直接写入新 ERP 成本。
- 无数据库迁移或真实数据修改。本合同不表示已经打包、安装或发布，交付状态由主线记录。
