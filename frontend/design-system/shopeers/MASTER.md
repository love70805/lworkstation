# Shopeers Design System

状态：当前设计实现的唯一主规范  
更新日期：2026-08-06  
产品类型：内部电商运营、商品资料与月度利润核算工具

> 页面若存在 `pages/<page-name>.md`，页面文件只覆盖明确列出的规则，其余继续遵循本文件。

## 1. 设计目标

Shopeers 不是营销站，也不是展示型数据大屏。用户会长时间查看表格、核对编码、处理异常和批量操作，因此界面应当：

- 浅色默认，安静、清楚、可扫描。
- 信息密度高，但通过列对齐、分组和层级保持秩序。
- 优先展示数据来源、状态、异常和下一步动作。
- 同一个动作只保留一个主入口；重复入口必须有不同上下文或不同范围。
- 每个可点击控件都有真实行为、禁用原因或明确的开发状态，不允许“看起来能点但无响应”。
- 精确利润和参考利润使用文字、状态和来源共同区分，不能只靠颜色。

UI/UX Pro Max 的自动匹配结果偏向深色营销落地页和夸张极简风格，不适用于本产品。本文件采用其无障碍、键盘、批量操作、表格响应式和加载反馈规则，并由产品场景进行人工校准。

## 2. 视觉语言

- 风格：Operational Minimalism / Dense Enterprise Tool。
- 默认主题：浅色。
- 圆角：控件 `4px`，面板和弹窗最大 `8px`。
- 阴影：仅用于弹窗、下拉菜单和确需浮层层级的元素；页面区块主要用边框和留白分隔。
- 禁止：超大标题、渐变背景、装饰光球、玻璃拟态、卡片套卡片、营销 Hero、无意义滚动动画。
- 图标：统一使用 Lucide。图标按钮必须有 `aria-label` 和悬停提示。

## 3. 色彩令牌

颜色服务于操作状态，而不是装饰。组件中使用语义变量，不直接散落十六进制颜色。

```css
:root {
  color-scheme: light;

  --color-canvas: #f6f8fb;
  --color-surface: #ffffff;
  --color-surface-subtle: #f1f4f8;
  --color-surface-hover: #eaf0f7;
  --color-border: #d8e0ea;
  --color-border-strong: #b8c4d2;

  --color-text: #17202b;
  --color-text-muted: #536273;
  --color-text-subtle: #758395;
  --color-text-inverse: #ffffff;

  --color-action: #0759c7;
  --color-action-hover: #064aa6;
  --color-action-soft: #e8f1ff;
  --color-focus: #0b69e3;

  --color-success: #087a55;
  --color-success-soft: #e7f6ef;
  --color-warning: #a95c00;
  --color-warning-soft: #fff3dc;
  --color-danger: #bd2c2c;
  --color-danger-soft: #fdecec;
  --color-info: #386b8f;
  --color-info-soft: #e9f3f8;
}
```

### 使用规则

- 主操作用 `action`，同一区域只出现一个视觉最强的主操作。
- 正利润和成功状态用绿色；负利润和阻断错误用红色；人工审批和待处理用琥珀色。
- 1688 参考成本使用中性或信息色，不能使用与 ERP 正式成本相同的成功色。
- 表格斑马纹应非常轻，优先用悬停和选中态帮助定位。
- 正文与背景对比度至少 `4.5:1`，大号文本至少 `3:1`。

## 4. 字体与数字

- 界面字体：Inter，系统中文回退为 `Microsoft YaHei UI`, `PingFang SC`, sans-serif。
- 编码和数字：JetBrains Mono。
- 字号不随视口连续缩放，不使用 `vw` 计算字体。
- 字符间距统一为 `0`。

| 用途 | 字号 | 行高 | 字重 |
| --- | ---: | ---: | ---: |
| 页面标题 | 24px | 32px | 650 |
| 区块标题 | 16px | 24px | 650 |
| 表格/正文 | 14px | 20px | 400 |
| 辅助说明 | 13px | 18px | 400 |
| 标签/状态 | 12px | 16px | 600 |
| 金额与编码 | 13-14px | 20px | 500 |

金额右对齐并使用等宽数字。默认货币格式为 `¥1,234.56`，明细中同时保留币种语义 `CNY`。

## 5. 间距与尺寸

```css
--space-1: 4px;
--space-2: 8px;
--space-3: 12px;
--space-4: 16px;
--space-5: 20px;
--space-6: 24px;
--space-8: 32px;
```

- 桌面页面内容区内边距：`20-24px`。
- 表格单元格：垂直 `10-12px`，水平 `12-16px`。
- 标准控件高度：桌面 `36px`；主要触摸目标在移动端至少 `44px`。
- 图标按钮保持稳定的正方形尺寸，不因加载态或标签变化位移。
- 导航、工具栏、筛选栏和表格表头可粘性定位，但不得遮挡内容。

## 6. 页面结构

```text
应用外壳
  ├─ 侧边主导航
  ├─ 顶部工作区与全局状态
  └─ 主内容
       ├─ 页面标题、上下文和主操作
       ├─ 紧凑指标/状态带（仅在帮助决策时）
       ├─ 筛选与批量操作栏
       └─ 主表格、编辑器或核对工作区
```

- 工作区首页显示业务总览、待办、最近账本和数据健康；不再重复放置多个同目标的大按钮。
- 商品库以表格/列表为主，商品详情使用抽屉或独立编辑页。
- 利润面板的第一视口优先展示账本状态、成本完整度、筛选和利润明细。
- 成本核对使用左右或主从布局，但在窄屏下变为顺序流程。
- 页面区块不做漂浮卡片；重复的单条任务、导入批次或商品可以使用有边框的行/卡片。

## 7. 导航与动作

- 侧栏一级入口按业务域组织：工作区、商品与供应商、采集待确认、ERP 成本、月度利润、数据与诊断。
- 导航项跳到唯一主页面。页面内的次级按钮应执行具体动作，如“新建账本”“导入台账”，而不是再次跳到同一首页。
- 右上角图标按钮必须实现行为；未实现时从生产界面移除，不保留空壳。
- 破坏性操作使用文字按钮并二次确认；撤销优于频繁确认。
- 批量选择后显示稳定的批量操作栏，离开选择态后恢复筛选工具栏。

## 8. 表格

- 表头清晰说明口径；必要时使用帮助提示解释“来源行数”和“真实订单数”等差异。
- 编码列左对齐，数量和金额右对齐，状态居中或左对齐但全表一致。
- 平台 SKC、平台 SKU、仓库 SKU 使用等宽字体且允许一键复制。
- 固定关键列时必须保留阴影或边框提示滚动边界。
- 表格支持排序、筛选、搜索、列显示管理和批量选择；列配置按用户保存。
- 超过约 200 行使用虚拟滚动或分页，动态内容不得改变列宽。
- 窄屏允许表格横向滚动，并固定首列；不能把复杂利润行强行改成丢失字段的简化卡片。
- 空状态显示原因与唯一下一步动作，不填充假数据。

## 9. 表单与核对

- 所有字段有可见标签；占位符只展示示例，不能代替标签。
- 常规校验在失焦时触发，跨字段规则在提交前再次校验。
- 错误紧邻字段，并在顶部提供可聚焦的问题摘要。
- 金额输入使用 `inputmode="decimal"`，数量使用 `inputmode="numeric"`。
- 成本来源、批次、审批人和计算口径放在字段附近，避免藏入单独帮助页。
- 精确成本、参考成本和人工兜底使用明确标签：`ERP 正式`、`1688 参考`、`人工审批兜底`。

## 10. 状态与反馈

- 超过 `300ms` 的操作显示加载反馈；长任务展示阶段、处理数、错误数和是否可取消。
- 成功提示说明写入了什么；失败提示说明哪些内容没有写入。
- 禁用按钮提供原因提示，不能只降低透明度。
- 保存草稿、同步中、待审批、可定稿、已定稿和已锁定使用一致的状态词。
- 不用颜色单独表达状态，必须同时有文字或图标。

## 11. 弹窗、抽屉与菜单

- 弹窗只用于短确认、小表单和不可忽略的决策。
- 商品编辑、成本证据和利润行详情优先使用可保留上下文的抽屉或独立页面。
- 弹窗最大圆角 `8px`，最大宽度由内容决定；复杂表格不塞入窄弹窗。
- 打开后焦点进入标题或首个字段，关闭后回到触发控件；支持 Escape，避免键盘陷阱。

## 12. 动效

- 标准过渡 `150-200ms`，只用于悬停、聚焦、弹层和状态变化。
- 不使用滚动揭示、视差或装饰性循环动画。
- 加载旋转保持低调，并配合可读状态文本。
- `prefers-reduced-motion: reduce` 时关闭非必要位移和旋转。

## 13. 响应式

验收宽度：`375px`、`768px`、`1024px`、`1440px`。

- `>= 1200px`：完整侧栏、主表格和辅助核对面板。
- `768-1199px`：可收起侧栏，筛选栏允许换行，详情面板按需覆盖或下移。
- `< 768px`：抽屉式导航，操作栏固定主操作，表格横向滚动，控件高度至少 `44px`。
- 所有宽度不得出现页面级横向溢出；只有明确的表格滚动容器可以横向滚动。
- 文本必须在容器内换行或省略，并提供完整值提示，不得覆盖相邻控件。

## 14. 可访问性

- 提供“跳到主内容”链接。
- Tab 顺序与视觉顺序一致，所有功能均可键盘操作。
- 焦点环使用 `2px` 高对比轮廓，不能移除后无替代。
- 图标按钮有可访问名称；装饰图片使用空 `alt`，商品图片使用商品名。
- 状态更新使用适当的 live region，但避免频繁播报表格滚动。
- 模态框和菜单正确管理焦点与 ARIA 关系。

## 15. 图表

- 只有在已定稿数据足够时显示趋势图；没有数据时展示下一步动作。
- 销售、利润、成本使用不同语义色，不依赖同一蓝色系的深浅。
- 图表提供单位、时间范围、图例、悬停值和可访问的数据表替代。
- 点击指标或图表点应回到对应账本和筛选后的明细。
