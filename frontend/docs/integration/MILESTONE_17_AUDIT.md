# 里程碑 17：新设备工作区恢复

状态：本地 Beta 已具备受控的云端恢复合同、空库恢复器和页面入口  
审计日期：2026-08-07

## 本次目标

把“云端可以保存业务事件”推进为“新设备可以下载、校验并恢复成可继续工作的 Shopeers 工作区”。

## 全局事件身份

- IndexedDB 升级为 v7。
- 新审计事件使用全局 UUID `eventId`。
- 本机自增 `id` 仅用于 IndexedDB 排序和本地更新，不再作为跨设备幂等身份。
- 旧数值事件 ID 继续兼容读取；升级时现有事件会补齐 UUID。
- 同步成功和失败回写按 `eventId` 查找本机记录，UUID 回执不会破坏 outbox 状态。

## 恢复合同

`shopeers-sync-recovery v1` 采用：

```text
完整云端种子基线
+ 基线之后的完整增量事件
→ 引用与唯一性校验
→ 事务性恢复 IndexedDB
```

种子基线解决旧版本摘要型事件无法独立重放的问题。已包含在基线审计表中的事件不会再次执行。

恢复器覆盖：

- 商品、平台 SKC/SKU、供应商报价和采集记录。
- 月度销售导入批次及重复分组替换。
- ERP 请求、成本批次、仓库 SKU 和正式成本行。
- 1688 审批及撤销状态。
- 定稿账本、利润明细和选品参考回流。
- 月度账本删除及其销售、请求、成本、审批和利润关联数据。

## 页面入口

“数据安全与备份”页面新增“从云端恢复”：

- 未配置云端 API 时保持禁用。
- 先下载并校验恢复包，不立即覆盖。
- 展示工作区、同步版本、增量事件数和待写入记录数。
- 必须输入“从云端恢复”才能继续。
- 覆盖前强制下载当前完整回滚备份。
- 完成后写入云端恢复审计记录。
