# v0.4.2 ERP 核算时限应急修复

基于已发布 0.4.1，按用户要求仅延长大批量采集等待时间。ERP Assistant 8.0.34：成本阶段 5 → 60 分钟，资料阶段 1 → 30 分钟，单次 ERP 请求 20 → 120 秒。慢请求、重试和资料进度提示同步更新。

请求范围、分页、并发数、2 次重试、资料 500 次请求上限、成本计算与正式证据要求保持。随时取消及登录失效停止保留；超时不提交未完成成本，资料异常不撤销已完成成本。8.0.29–8.0.33 有效检查点继续兼容，不清理待送达证据或真实业务数据。

前端 163 文件 / 1281 测试、desktop verify、桥接与 ZIP 一致性、慢路径/规模/恢复回归通过。新增虚拟长时钟验证 80 秒单请求、超过旧 5 分钟的成本任务、超过旧 1 分钟的资料任务及延长期间取消；生产时限不被测试改写。真实 headless Chromium 使用隔离合成 ERP 响应验证成本先送达、后台补资料、实际取消及 1440/1000/390 六种浅深背景窗口布局。不是在真实账号上持续等待 60 分钟的采集。

候选登记 releases/candidates/0.4.2/，证据 archive/release-0.4.2/；打包、隐藏 smoke、候选资源一致性、CI 与公开资产回读完成后公开稳定版。本机不自动安装。外部 Chrome 手动加载的扩展需用户加载新版目录并刷新 ERP 页面；桌面版内置助手随安装包升级。
