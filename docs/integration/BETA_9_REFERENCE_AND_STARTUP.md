# Beta.9 台账身份投影、成本行与 ERP 启动契约

基线：main `cf89dcc`，Beta.8。范围为成本核对对齐、参考页台账身份、桌面 ERP 小灯与新利润表导出简化；不迁移真实数据库、不改变成本口径、不安装本机。

## 台账身份只读投影

`getSelectionReferenceSnapshot` 只提供当前工作区、有效账本及完成导入批次下仍存在的台账行。SKU 以现有规范化平台 SKU 关联；台账不会单独新增参考成本行。父级标识仅取显式平台 SKC，禁止用供方货号、仓库 SKU 或 `groupSkc` 的回退值冒充。

`buildSelectionReferenceRows` 保留商品档案非空人工身份；缺失字段可从唯一一致的可信台账或明确利润平台 SKC 投影。冲突不随机取值，字段保持缺失，提供候选值及工作区内账本、月份、店铺、批次、工作表、行号来源。属性冲突同样不自动决定。只改变显示，不写入商品档案或正式利润，不更改参考成本选择优先级。

验收：同工作区已有台账、多个 SKU 同 SKC 分组、无定稿历史但已有 ERP 成本、空档案字段、人工身份优先、同 SKU 多店多月份冲突、无平台 SKC 的供方回退、跨工作区/孤立/无效批次隔离，以及快照读取前后存储一致。

原表只读核验：`680店.xlsx` 的“台账变动明细”191 行，42 个平台 SKU、14 个显式 SKC；所有添加时间属于 2026-06，190 行发货与 1 行盘亏。属性集存在且同 SKU 身份无冲突。其 SHA-256 为 `3de8e37ffb62afc9ab43aa06b60f6e56c0fa9a43d2cc2fb38f8489b797c750cd`，读取前后相同。不能假设为先前 8 月原表或与截图 59 个 ERP SKU 完全相同。验证使用现有工作区投影与合成数据，不把原表/数据库写入仓库。

## 成本共同子行

保留 SKC 分组与分页、筛选、未映射展开及原成本对话框。每个 SKU 使用共同语义行；多店使用共同店铺子行，SKU 与候选覆盖其店铺行。正常有效值提供紧凑详情与明确可选人工更正；锁定仅查看。长属性、来源展开和中文换行不得引起跨列错位。

## ERP 小灯状态与权限（最新用户修正）

桌面左上角现有小灯融合 ERP 检测。启动后台自动同步真实助手通信，用户停留工作台且未开采购页即可获知；扩展加载/桥接服务在线不足以代表助手就绪。常态仅小灯，无常驻文案、大卡片或持续闪烁；悬停和聚焦一行中文说明，点击紧凑详情与必要恢复动作。首次真实就绪轻提示一次，心跳/握手不重复；断连/失效撤销绿色，恢复自动同步。登录/采购条件另行说明，未登录不可用不得误报。

移除成本页正常态及空态的桌面重复扩展检查按钮与专用弹窗触发，浏览器安装流程与 1688 保留。仅扩展现有卓麟 HTTPS 站点内状态权限；采购业务权限保持采购上下文限制。页面路由及重复初始化不得叠加 UI 或监听，导航采购由用户明确操作，不自动提交业务单据。

验收：停留工作台、不打开采购页的冷启动/等待/就绪；未登录不可用、断连/恢复、重复事件无重复提示、两处面板入口移除、浅深色/窗口/键盘，以及采购进入/离开、SPA、刷新/返回和收件恢复。保留 Beta.8 正式成本证据字段与旧行只读投影回归、人工优先、定稿及撤回墓碑保护。

## 新利润 Excel 导出（用户追加第 4 项）

新生成的未扣款、财务对账月度利润表完全移除“核算采购”工作表。汇总/店铺每行关联单号仅显示实际参与核算采购中按既有由近到远顺序首个有效单号；该笔有 1688 号优先，否则采购单号/ID，不为 1688 号跳过更近有效采购。无号留空。旧兼容汇总字符串仅按已知 ` / ` 分隔取首项，不误拆单号自身斜线。单号保留文本类型、前导零和长整数。

仅导出呈现改变，三笔数量加权成本、完整内部证据、人工优先、正式成本及金额不变。已有定稿报告文件保持快照原样，不重写真实数据。更新模板版本，公式版本保持。验收两种表无采购sheet、汇总/店铺一致、混合来源/空/旧兼容/前导零/长号，金额与输入证据不变，并对隔离生成的 XLSX 读回。
