# 0.4.10 ERP 实际进度与批次原因

2026-10-08：候选验收通过，等待 PR、主线 CI 和公开发布；当前稳定 Latest 仍为 0.4.9。本机未安装、真实业务数据未改写。

## 改动

采集按实际响应处理结束统计完成量。采购列表分别显示同时读取的两路 SKC 及分页进度；明细最多八路、映射最多五路，仍共用八路 ERP 请求限额，429 时降至两路。当前阶段的完成量与任务成本总回传分别展示，未知总页数保持等待确认；取消、重试和慢请求不伪造百分比。资料目录和仓库资料分阶段，成本回传后继续补充。

工作台分别显示成本已送达、资料检查已结束和资料齐全。请求失败、已送达但证据未齐、资料缺项分开列出；后两者不再统一标为“失败批次/采集未完成”。新批次保留平台映射/空映射、采购明细或列表缺项原因，资料回传保留图片、供应商/1688 链接、目录、映射和采购证据缺项摘要。旧批次可从原回传证据补充说明，没有具体证据时明确提示核对，不猜测原因。

每批 20 SKC、采集范围、重试时限、成本计算与自动采用保护保持。ERP Assistant 8.0.37 保留 8.0.29–36 有效检查点，无数据库迁移，不清理历史任务或数据。
