## 复现与定位

正式 0.2.7 同时启动两个进程时，第二个在 MemberContextGate 的成员设置读写处报 IndexedDB UnknownError。desktop/main.cjs 缺少单实例锁。用户单独启动一个实例正常，说明当前问题与同数据目录重复进程争用一致，不应通过清库或重装处理。

主线只读确认磁盘空间充足、LevelDB日志未报告明确损坏；应用关闭时冷备 IndexedDB/WebStorage，15文件SHA256一致。在备份的独立副本中用同版本Electron原生IndexedDB打开与settings读写通过。原数据未改；备份含业务数据，仅保存在本机忽略的archive目录，禁止提交和上传。

- 正式与独立QA的不同userData仍可并行；不修改数据库、业务、权限、扩展协议或更新规则。
