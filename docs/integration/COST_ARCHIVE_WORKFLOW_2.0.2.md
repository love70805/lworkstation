## 基线与范围

2026-11-05 实际联网核对 `origin/main` 为 `dff4791b8812f29f797a66abc6016f2eb6994fe9`（稳定版 2.0.1）。本批按用户截图和追加要求，统一利润页、商品页、商品编辑入口、全局通知及桌面 ERP 面板的工作流；助手升级至 8.0.60。

- 采集只保留一条阶段进度，按实际完成数量增长，运行时向右脉冲；未知总量不伪造百分比，暂停与减少动画设置停止脉冲。
- 待补成本、价格异常核对和忽略操作集中到采集按钮下方、采集记录及金额汇总上方。待补入口筛选、展开并定位明细；确实无采购证据的成本继续提示，忽略记录仍可恢复。
- 商品档案以“一键获取”为主入口，选择已送达成本任务的商品范围后，后台读取 ERP 导出多行表格并自动匹配写入资料。手动导入文件保留为备用，商品编辑页进入同一获取流程。
- 商品资料进度使用资料检查计数；登录后续接保留商品任务类型，暂停、缺项与恢复不再误显示成本成功。

## 跨模块契约

复用现有 catalog 任务、精确 companion 请求和本机收件，不新增数据库迁移。显式商品任务可读取当前工作区、当前任务范围、当前批次尝试及执行者对应的持久成本收件；不要求先忽略价格异常。自动与手动获取共用表格解析器，先补查并核实平台与仓库 SKU 的对应关系，只对范围内已确认的仓库 SKU 分批获取，每批最多 50 个。档案属性只补空值，保留更精确的平台 SKU 属性。

表格只提供名称、图片、属性和 1688 链接。平台身份来自已验证对应关系，表格采购单价与截断的平台 SKU/SKC 拼接片段不作为成本或身份依据。已有人工资料优先，正式成本、人工成本和历史报告保持原规则。重新获取只重置资料状态，保留成本回执和证据。

缺行、冲突、范围外商品及不可解析文件不能宣告资料齐全；登录失效、权限和暂停沿用中止契约，停止后续读取。旧任务与手动导入保持兼容，入口与说明同步更新。
