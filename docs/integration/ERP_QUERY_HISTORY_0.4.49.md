- 原有批次合同保留无平台映射的仓库证据；允许的仓库须绑定已登记请求，不能扩大平台范围。此类行不参与 ERP 自动采用，原“人工更正”入口展示重算建议，点击保存时再次核对原始收件、当前来源、账本范围和有效成本。
- 独立悬浮按钮及成本页独立历史入口移除；明确仓库的高级证据导出仍在原 ERP 助手内，旧文件经原“手动导入”入口继续使用。
- 本批不扩展至审阅中的 R1/R2/R3 备份缺陷，不操作真实成本、任务、队列或业务数据库；本机安装依用户授权执行。
