# 0.4.22 商品资料与使用流程修复

基线：`3b30daf` / 稳定版 0.4.21。2026-10-14 用户要求先修复属性顺序误冲突和商品库利润状态，并优化简单、可靠的使用流程。账号云端方案暂停并取消；ERP 独立后台、多标签和移除 1688 的 Beta 规划不进入本批。

## 契约与范围

- 属性比较只用于同一可信平台 SKU 的商品资料。明确的颜色/尺码等属性片段在仅顺序变化时视为等价，保留原始展示、来源及人工字段。数值区间、比例、不同属性内容、重复片段和 SKC/仓库关系冲突不能被忽略；正式成本身份校验不变。
- 商品经营状态分别展示采购参考、参考利润、定稿历史和仓库映射。参考利润覆盖来自现有售价和参考成本计算；定稿历史来自已有利润明细，不能用建档或参考成本替代。缺项筛选不将单纯未定稿当作商品资料缺失。
- 真实来源差异在 SKU 属性处就近展示，可显式采用来源或保留当前值。分次预存、人工优先、审计、原子保存、自动流转与定稿保护沿用。加载失败应明确显示原因及重试/返回入口。
- 改善现有导入、ERP、利润、商品主流程的状态说明、下一步与恢复操作，复用现有导航和布局。不新增业务模块、不迁移或批量改写真实数据库、不自动安装。

## 验收信号

1. 台账“粉色-B”与 ERP“B-粉色”及五种颜色/均码组合不再误报；不同颜色、数值范围、重复值及身份冲突继续拦截。原始来源可查看，人工选择可保存和恢复。
2. 已建档且参考售价/成本齐全、无定稿记录时显示可用参考利润及尚无定稿；零成本/零售价/负参考利润、部分覆盖、筛选和导出准确；正式利润和报告不变。
3. 从预存缺项直接处理、保存并流转，商品库返回位置、成本核对和利润定稿入口可用。加载失败能够重试；工作区隔离及过期结果保护保持。
4. 必要回归、前端完整 test/build、ERP/桌面门禁、无头中文浅深色窗口检查、最终 Windows 候选及包内路径通过后统一稳定发布，核验标签、CI和四资产公开回读。
