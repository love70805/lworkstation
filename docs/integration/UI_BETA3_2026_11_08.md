# 2.0.7-beta.3 界面优化

用户指定基线：v2.0.6（385f9f54b55c9c74a593ecf121ddebc82e8f034a）。目标：2.0.7-beta.3，独立 Beta 安装及数据目录。用户已选择五项优化和菜单键盘修复一起实施，并允许引入 BoardUI 及 react-aria-components。

## 界面方案

这是中文 Windows 本机核算工具的精修。保留现有身份与业务计算；重点放在月度核算范围、待办和结果。工作模式：Operate。

- 颜色沿用：画布 #f6f7f9、表面 #ffffff、正文 #17212d、操作 #2563eb、完成 #087a55、待处理 #a95c00。
- 字体沿用 Inter / Microsoft YaHei，数字使用现有 JetBrains Mono；字号 12/13/14/16/20/24。
- 左对齐。首页先选月份/店铺，再显示对应范围指标；工作区商品总数另列。导入先确认文件、月份、店铺，再勾选货号，规则为可展开的辅助工具。利润页区分整月报告与当前明细筛选。

    首页：月份 + 店铺 → 当前销售/商品利润 → 下一步 → 趋势
          工作区总览：已登记商品 / 待核算账本
    导入：文件 + 月份 + 店铺 → 货号选择 → 应用并校验 → 导入
    利润：月份 + 明细店铺 → 整月导出状态 → 成本工具 → 汇总 + 明细

对照评审：不重新设计装饰或增加统计卡；本批强调范围、选择是否生效、成本缺失与报告是否需要重新导出。BoardUI 用于按钮、状态和范围选择器，React Aria 承担选择器键盘交互。

## 交付范围

1. 首页指标跟随当前月份与店铺，明确整月报告范围。
2. 导入状态区分未选、已选待应用、已校验；文件范围优先，规则折叠。
3. 商品草稿语义及补资料入口一致。
4. 利润页减少重复说明，已完成成本信息收起，明细前移。
5. 最近导出显示类型、时间、版本及来源状态；保留历史快照。
6. 顶栏菜单支持方向键、Esc 和焦点返回。

输入与边界：读取现有账本及成本投影；仅新报告增加可选来源状态指纹，不迁移或改写历史报告。费用与成本公式、真实工作区数据均不改变。历史报告缺少指纹时显示状态未记录。仅使用合成数据验收，不安装软件。
