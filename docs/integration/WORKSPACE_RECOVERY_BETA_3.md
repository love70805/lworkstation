# Beta.3 工作站返回恢复

用户场景：顶部切到 ERP／1688，同时最小化；放置一段时间后回工作站出现白屏。本轮按该组合补充防护，不把故障注入通过等同于已确定用户设备上的唯一根因。

## 契约与行为

- 主进程管理 WebContentsView：移出时隐藏，重新挂载时设置边界并显示；恢复、显示、聚焦和返回工作站时请求重绘。
- 仅可见、未最小化且选中工作站时探测。8 秒没有响应则显示等待／重试提示；每次探测使用随机 token，并验证当前 WebContents 与主 frame。
- 独立 preload 回复根节点是否仍有页面内容，不向远程 ERP／1688 提供该 IPC 能力。
- 正常页面不自动刷新、不重建 React，不清空表单。迟到回复或再次进入前台后的健康回复均恢复原页面。
- 页面进程退出、WebContents 被销毁、空根节点、持续无响应有明确重试入口。只有用户点击重试／刷新才重新加载，提示可能丢失未保存输入；销毁时重建视图，保留最近合法站内路由。
- 被阻止的外部导航不启动加载遮罩；恢复提示仅覆盖工作站，不遮挡其他标签。退出时清除探测，后台和最小化时不误判超时。

不增加数据库迁移，不触碰业务数据或真实 ERP 会话。探测可发现空根节点与渲染线程无响应，不能证明所有 GPU／驱动层白屏均已覆盖；重绘与显式重试提供恢复路径。

## 验收

`desktop/workspace-recovery.test.mjs` 覆盖 8 秒默认值、身份与 token 校验、探测合并、后台取消、超时／迟到回复、重返前台、空根节点及退出／销毁。

`desktop/workspace-recovery-smoke.cjs` 使用实际 Windows Electron、独立 profile、回环页面和真实 preload。连续 12 次 ERP／1688 + 最小化返回保持原进程、路由与未保存输入；注入空根、崩溃、销毁与迟到响应，验证恢复和显式重试；被阻止外部导航保留健康页面。仅该夹具把探测超时缩短为 500ms，生产仍为 8 秒。截图分别捕获工作站 WebContents 与壳层错误提示，避免把壳截图误当子视图画面。
