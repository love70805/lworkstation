# 本地 Beta.14：成本核对闭环与采集中保护

2026-11-13。以本地 Beta.13 提交 `9e72d72` 为基线，沿用 `codex/beta13-erp-cost-delivery`。用户要求保留当前界面和核算口径，只在本机构建、验证，不发布、不安装。

## 本批行为

- 采集按批回传与自动采用继续实时展示。当前月份还有成本读取、送达或本机核验未完成时，提示临时结果，人工更正/撤销、确认原价、异常忽略/恢复和新报告保存暂不可用。保存入口重新读取任务状态，并在写入事务检查本机回执，防止旧弹窗写入。后台自动采用不被这道保护阻断。
- 暂停、失败并不视为完成；显式停止后可处理已稳定的结果。全部成本已送达、采用处理已完成时，价格异常可以核对，不要求先消灭异常。仅剩可选商品资料采集时不锁成本，其他月份不受影响。
- 统一沿用“核对价格异常”入口，窗口内列出待核对、没有成本、已人工更正、已忽略。1 元、价格波动和没有采购记录均可原地输入成本，保存后留在同一窗口更新数量；已补录成本可从已人工更正列表再次更正或撤销。
- 没有成本不能忽略。用户明确保留补录真实单件成本后计算利润的现有口径；没有新增直接输入利润、排除销售收入或自动以 0 成本核算的规则。
- 同月同仓且完整采购证据相同的异常，支持选择一次更正关联店铺 SKU。展示影响范围，保留其他已确认人工成本。保存时重新验证证据、成员和已有人工记录；无映射、身份冲突、不同证据、不同月份不自动合并。整组原子提交，任何一项失败全部回滚，保留逐项审计。
- 批量更正共用一次台账/ERP 读取，提交后统一更新成本覆盖情况；商品投影按批复用已验证 SKC 范围，避免每一行重新构造和扫描整批范围。
- 当前筛选为 0 个 SKU/SKC 时，开始/继续/重试入口禁用，调用逻辑也拒绝空范围，不复用旧请求重新发起。暂停、停止原任务仍可用；主动刷新已有商品成本仍通过单独的重新获取入口和范围确认。
