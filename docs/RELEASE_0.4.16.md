# 0.4.16 ERP 维护恢复与整批采集反馈（候选已验收）

ERP 维护期间，已送达成本仍可能缺少完整目录与平台映射。旧助手继续任务时会清空本地预览；重试失败批次可能沿用旧投递引用，未重新读取；状态栏只看最后一批元数据，可能掩盖前面批次的缺项。

现在明确维护页面/提示会暂停后续读取；HTTP 或网络故障有限重试后仍不可用也暂停，并持久保存原因。服务恢复后点击“继续未完成采集”，保留已有结果并核验原范围。一般目录或映射缺项最多自动复核一次，只刷新相关目标，继续保持原并发和分页上限；持续缺项仍需核对。

“重试失败批次”建立新尝试，重新读取失败范围，拒绝旧尝试回执覆盖新结果；其他批次、旧证据和已有正式成本保留。重试结果替换该批旧预览。整批反馈汇总所有批次，明确区分已送达、已采用及成本证据缺项；缺少本地预览时说明查看和重试路径。状态与月份说明在窄窗口换行。

不增加业务表迁移，不改写真实队列或数据库，ERP 正式成本、人工更正优先、价格异常、定稿保护及最近三笔数量加权口径保持。补图片和链接仍不阻塞正常成本。目录诊断只作说明，不能提升缺证据结果。ERP Assistant 更新为 8.0.40，桌面与前端为 0.4.16。
