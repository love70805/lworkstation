## 主题合同

- 保持现有 appearance 存储键和明暗含义；前端背景、主题色和桌面外壳同一目标状态，避免切换到一半被旧异步状态反转。
- 连续切换以最新用户选择为准，取消或替换旧动画；避免对大表每个单元格启动昂贵过渡或使用 transition: all。
- 遵循 prefers-reduced-motion；不支持动画 API 时直接可靠切换。动画是渐进增强，不能遮挡点击或造成不可恢复覆盖层。
- 首帧使用已保存主题，尽量避免白闪。不得改变外部 ERP/1688 页面主题或截取其内容用于动画。

## 启动与托盘合同

- 启动动画使用现有标识，轻量、跟随保存主题；工作站准备完成即可结束，不设人为最短等待。失败、超时必须有明确反馈及恢复操作，不能无限遮挡。
- 托盘恢复和第二次启动只恢复已有窗口，不重新播放启动动画；保留同 userData 单实例机制。
- 默认关闭主窗口隐藏到托盘；保持 ERP inbox、工作站 renderer 及必要状态存活，不清理用户会话。
- 托盘左键/菜单恢复窗口，菜单提供明确退出；恢复可最小化/隐藏窗口且正确聚焦。
- 第一次关闭可给简短托盘提示；提供简单的关闭行为偏好（隐藏托盘/退出），保持默认隐藏。设置为桌面本机偏好，不新增业务数据库迁移。
- 明确退出、更新安装、系统关机应走实际退出；before-quit 等需正确设置退出意图，不能被 close 处理反复隐藏阻断。
- 托盘创建失败时不得把最后可见窗口隐藏到无法恢复；回退明确退出或保留窗口并提示原因。
- 退出清理托盘及子进程，隐藏不清理；开发/smoke 自动退出路径可靠，不遗留后台测试进程。
- 若新增 IPC，只提供完成此功能必需的窄接口，沿用 sender/来源校验，不开放任意路径、命令或配置写入。
