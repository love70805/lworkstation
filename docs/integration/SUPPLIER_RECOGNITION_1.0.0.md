# 1.0.0 货号识别修复

实际远端核对基线：`8af0f0659466ef9a8a97de7c95a62c8cc0708764`（2026-10-23）。用户授权修复并发布正式版 1.0.0。

## 契约与范围

- 仅保留 `fuzzy` 模糊识别与 `exact` 精准识别，默认模糊识别；旧 `suffix` / `contains` 常用组读取时兼容为模糊识别，不直接改写真实数据。
- 共用无副作用识别函数，供规则选择、预览、列表搜索与粘贴使用；原始货号、前导零、SKU 身份不变。精准识别仅折叠全半角、大小写和两端空白后完整相等。
- 模糊识别支持包含关键词；连续重复英文字母容错（压缩后的关键词至少三个英文字母），例如 `LBY` / `LBYY` 双向命中。数字不压缩，不采用任意字符编辑距离，避免扩大财务身份范围。
- 空关键词和零命中保持空结果；人工选择、逐店例外、当前工作区与月份边界继续生效。筛选只生成原始完整货号集合，正式导入与成本身份仍精准校验。
- 覆盖常用组持久化与备份兼容、导入预览及实际导入路径、利润与 ERP 查询范围；不改成本政策、人工优先、定稿保护或数据库结构。
- 修复已复现的逐店例外跨店泄漏：在兼容 `supplierSelection` 的同时，以可选 `supplierStoreSelection: [{ store, supplierNumber }]` 保存店铺与完整货号的配对限制。缺省 / null 不增加逐店限制，空数组为空范围；两个限制取交集。URL 的既有 session scope 引用、本机筛选保存、利润导出和 ERP 采集共用该契约；损坏或跨工作区 / 账本引用闭锁为空范围。
- 本次发布 1.0.0。现有自动更新要求同通道版本递增，不能覆盖已公开同名版本资产；后续按批次发布修复版，固定显示版本需另立修订号机制，不在本批扩大实现。
