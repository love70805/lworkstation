## 关联与兼容

- 不同平台订单、不同 SKC 可以共用一个 1688 单号，每笔订单及源数量独立保留；1688 单号不是去重键。
- CSV 没有合并元数据，仅在可靠连续登记人/日期/店铺分组中继承最近明确单号。SKC、平台订单变化不清空关联；新明确单号替换当前关联。登记人、日期、店铺变化以及空行、重复表头、汇总和非订单分隔行继续隔断；不跨文件/工作表，不反向补齐或猜测。
- XLSX 仅在明确 1688 纵向合并范围中填锚点单号，允许跨 SKC；范围外真正空白保持缺失。合并来源 `mergedFrom`、CSV 继承锚点 `inheritedIdentifiers` 可追溯。
- 单号按精确文本保留长位数与前导零。空数量行仍先维护关联上下文再跳过核算，真实零保留；数量不继承。
- parser 升至 `monthly-supplement@4`，不增加 schema 迁移。物理 `sourceRow` 去重身份及展示 `recordRow` 不变，旧批次可读；不自动改写历史关联或定稿。
- 既有登记人筛选、自动预览/一次导入、追加/替换、跨文件冲突和定稿保护沿用 0.3.1。修复默认用于新导入；已有错误来源需在允许修改的月份重选本月需保留的完整原来源及相同登记人筛选范围，核对最终数量后显式选择替换全部已有来源，旧采用版本保留，定稿月份按原显式重开流程处理。
