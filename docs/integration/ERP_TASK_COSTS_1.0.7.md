# ERP 任务界面与成本证据复用

基线：实际远端 `ac0a333e3c417ad197d8bf591482cd6beed8a763`。版本 1.0.7，内置 ERP Assistant 8.0.54。

- 桌面 ERP 页面浮窗只读当前后台任务进度，复用现行任务列表接口；取消前台旧采集、复制及导出操作，不改变前台 ERP 查询或翻页。外部浏览器的独立助手保留兼容入口。
- 软件启动从同包资源准备内置助手；构建校验本体版本、扩展版本和下载包全部脚本、样式及弹出页内容，阻止旧包随新本体发布。
- 侧栏点击立即展开或收起。移除工作台的旧 SKC 复制和模板按钮，状态链接定位并聚焦任务卡片。查看其他月份不取消原月份回传关联。
- 完整历史证据供本地核算复用。派生结果按实际来源变化失效，避免操作设置使全部历史重复读取；正式成本、人工优先和原始证据保护保持。单号保留实际文本及其价格来源。

针对真实台账，在独立浏览器实际执行多文件导入、回传采用、结果恢复与数值核对；采购价格、数量、收入和订单来源用独立算式对照。缺少映射或待确认价格保持缺失，不填造成本，不写回用户业务库。来源文件、精确金额、标识和原始日志只保留在忽略归档。

本机最终相关回归 8 文件 / 184 项通过；完整前端回归发现的缓存观察问题已通过定向复核。桌面验证、规范扩展桥接、真实原生扩展任务浮窗和隐藏桌面消息链路通过。隐藏窗口的鼠标注入受一秒限速影响，消息链路使用集中 DOM 点击验证，没有将其表述为可见桌面物理连点验收。侧栏事件与 React 提交响应约 3–9 毫秒；真实数据结果切换约 1–3 秒，不发起重新采集。

发布使用同批 PR 必需 CI 和最终候选 smoke；具体结果由 PR / Release 服务记录确认，不再另开收尾文档 PR。未安装或重启用户当前软件。
