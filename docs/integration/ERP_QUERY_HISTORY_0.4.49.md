# ERP 查询兼容与历史核价流程（0.4.49）

状态：已完成候选验收、代码合并与公开稳定发布。用户要求实际修复采集任务无法保存，并解决仓库历史核价额外按钮的问题。

## 基线、范围与契约

- 2026-10-21 联网确认主线 `2eb3e8bd111c5301f9fe1202d60589a1ea547ef9`，源码 0.4.48；在独立分支 `codex/erp-query-history-fix` 实施。
- 已从用户授权读取的本机 ERP 采购请求缓存确认 `changePrice` 字段缺失于助手白名单，即使值为空也触发 `ERP_CHECKPOINT_QUERY_UNSUPPORTED`。仅字段名、类型及长度用于诊断；私有请求、业务标识及证据留在忽略归档。
- 查询兼容须同时覆盖正常任务保存、检查点恢复与完整采购历史读取：原查询值完整保存和比对；全历史读取取消该筛选；其他未知条件仍明确拒绝，不静默丢弃。
- 历史核价遵守当前精确映射、历史关联和采购证据的区分；不把历史关联冒充当前 ERP 正式映射。人工有效值优先、零值/微小值、工作区/月份/店铺/SKU 范围及定稿保护保持。
- 用户明确确认“并入原流程自动补查、原页确认”。新请求携带同工作区已发布 ERP 成本或已确认历史更正中的可靠关联；遇到当前映射缺失时，只补查唯一、无单位换算冲突的历史仓库。
- 原有批次合同保留无平台映射的仓库证据；允许的仓库须绑定已登记请求，不能扩大平台范围。此类行不参与 ERP 自动采用，原“人工更正”入口展示重算建议，点击保存时再次核对原始收件、当前来源、账本范围和有效成本。
- 独立悬浮按钮及成本页独立历史入口移除；明确仓库的高级证据导出仍在原 ERP 助手内，旧文件经原“手动导入”入口继续使用。
- 本批不扩展至审阅中的 R1/R2/R3 备份缺陷，不操作真实成本、任务、队列或业务数据库；本机安装依用户授权执行。
