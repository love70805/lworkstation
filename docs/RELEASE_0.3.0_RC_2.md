## 根因与行为

现场只读数据库副本确认active-member-context设置缺失。本机统一上下文本来返回默认管理员，自动采用事务却直接读原始设置，因此误判没有财务权限；传输已ACK，最新收件loaded，无adoption或appliedBatchId，成本行/批次均0。请求59SKU/18SKC、79来源行、66仓库证据，工作区、账本月份与草稿关联正常。

事务内改为重新读取统一成员上下文，保留财务角色和工作区检查，未写入成员设置或更改角色。正常回传及旧pending/loaded收件经过原有完整证据、范围与月份校验后自动采用，人工优先、已撤回墓碑和定稿保护保持。无数据迁移，不修改真实库。

采用异常在成本事务回滚后保存可选adoptionFailure，重复错误只记一次本地审计，重试成功清除；诊断不进入同步。轮询仍在收件持久化后ACK，保留采用与恢复错误。页面显示当前失败原因和校验重试入口，旧草稿可提示较新失败；拒绝/撤回终态不显示继续重试，也无重试按钮。
