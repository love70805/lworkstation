# 0.3.4 采集恢复契约

成本采集在原采购证据及映射完成后立即缓存、展示并沿原持久回传路径投递。可选目录不进入正式成本证据，也不延迟成本结果；成本请求在本机登记一个同来源、同月份、同确认身份的独立资料请求，资料回传仍须持久收件确认。

资料阶段复用原映射和完整证据，缺失证据只沿页面已捕获的采购筛选读取一次，禁止猜测仓库筛选字段或逐仓库扫描历史。阶段总预算60秒、采购最多10页/500订单、总请求预算500，超限记录partial/unavailable，不推定完整成本。用户取消立即阻止分页/新请求。首次请求覆盖fetch与JSON读取的20秒硬期限，反馈重试与登录失效。

验收：真实生产代码的悬挂目录、悬挂首请求/JSON、大量历史、共享仓库、缓存复用、取消/重试，以及成本与资料独立持久化和重启幂等；之后全量前端/桌面门禁及隐藏候选验收。
