# 0.4.9 清空本机数据与历史核算残留

2026-10-08：[v0.4.9](https://github.com/love70805/lworkstation/releases/tag/v0.4.9) 已公开为稳定 Latest，标签固定 `ce5047ade12001239b2661e3dfe8d97dde7aa0fa`；[PR #175](https://github.com/love70805/lworkstation/pull/175) 与[主线 CI](https://github.com/love70805/lworkstation/actions/runs/37724384103) 通过，四公开资产匿名完整回读和生产更新入口验证通过。本机未自动安装，真实业务数据未改写。

## 修复

清空本机数据时同步清除桌面收件中的 ERP 请求、历史分批任务、成本及资料回传、1688 收件和任务租约，以及浏览器成本草稿。此前只清理 IndexedDB，同月重导入会复用账本 ID 并重新显示旧任务。

清空会等待正在保存的后台收件结束，阻止清空期间开始新的后台恢复；桌面清理失败时保留 IndexedDB 并明确报错。旧任务续传和迟到 ERP 结果被拒绝，新同月请求可以正常建立。独立宿主能力凭据只允许可信工作站主框架发起清理，扩展和远程页面无此权限。

ERP/1688 登录会话、桌面偏好、更新设置和外部备份保持。没有数据库迁移或核算口径调整，升级本身不会自动清理任何业务数据；需在新版本中明确确认“清空本机数据”才执行。
