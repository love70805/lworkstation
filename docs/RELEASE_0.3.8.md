# 0.3.8 图表与 Windows 图标验收

## 更新内容

- 销售图表改用更鲜明的十色配色，浅色与深色分别适配。每日、月度、圆盘与图例沿用同一店铺颜色，原有筛选和浏览方式保持。
- Windows 应用图标直接从原始 L7 SVG 生成每种尺寸，避免先栅格化大图再缩小。增加 20px、40px，ICO 包含 16/20/24/32/40/48/64/128/256px，对应通知区域和高 DPI 场景。
- 数据库、业务计算、ERP 扩展及导出契约不变，没有迁移。
