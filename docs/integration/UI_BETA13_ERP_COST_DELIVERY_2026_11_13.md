## 模块与数据契约

- 扩展采集负责读取当前 SKU 的采购总价、原采购单价及服务单价；批量与逐单备用路径都保留 `amountBasis: purchase_total`。明确无效的总价不能回退为不含费用的估算。
- 扩展后台负责 HTTP 体积与暂存容量双重预检、保存前再次检查和原回执续接。容量不足不删除历史待送达证据；多商品超限沿原范围分段，暂停原因传至任务与工作台。
- 工作台证据归一化、最近三笔加权成本、最低价证据读取、预览和导出共用采购总价口径；先累计金额和数量，再计算并截断四位单件成本。人工更正、旧证据和历史报告保留。
- 桌面重采协调器确认当前月份和筛选范围后停止旧任务、准备新请求。失败重试复用新请求；范围变动使旧确认失效；任务身份同步前禁止再次重采。
- Beta 原有异常去重、同窗核对、忽略沿用与恢复提醒保持。完整证据比较增加金额口径、原采购单价和服务单价，防止相同合计金额掩盖费用变化；新旧口径也不自动等同。
- 页面合并仅增加重采入口与采购总价说明；保留 Beta 的采集完成状态优先显示、布局、同窗人工处理与防重复提交。
