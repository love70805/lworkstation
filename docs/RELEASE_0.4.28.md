# 0.4.28 ERP 档案来源核对

商品编辑器将重复 ERP 回传合并为每个 SKU 一张来源卡片，保留不同资料与回传明细。采购来源按供应商、仓库、SKU 和采购规格归组，展开查看订单与原始证据，避免相同信息铺满页面。

供应商卡片列出对应的 ERP 商品/店铺链接，可预览、明确选择并保存；切换到店铺链接会清空商品 ID。属性差异在对应规格行处理，人工确认和保存状态明确，不再在来源区重复警告。多链接保持为可选来源，不直接判定为错误。

数据边界：只读展示分组不改原始证据；人工来源选择沿用现有保存和审计，不改报价、ERP 正式成本、人工成本优先级或月度定稿。无数据库迁移。本机不安装。

源码基线 `76692669e8eacbe3cfa5ae5d5456f5a5ff6fc4d1` 已联网核对。194 文件 / 1541 项前端测试、生产 build、完整发布门禁与 17 组 desktop verify 通过；最后调整的 44 项定向补验和 24 组中文浅深色窗口布局、来源选择保存重开、财务数据不变及审计路径通过。
