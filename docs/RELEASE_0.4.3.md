# v0.4.3 大批量 ERP 采集与关键词选货号

2026-10-07。状态：Windows 候选已构建并通过隐藏 smoke，尚未公开发布。沿用本机不自动安装约定，未清理或改写真实业务数据。

ERP Assistant 8.0.35 默认每批 20 个 SKC，采购列表两路、ERP 请求最多八路；逐批回传，先成本后资料。成本 60 分钟、资料 30 分钟按批执行，单请求 120 秒。资料不再受全任务 500 次请求上限限制。暂停、停止、失败重试、重启后显式继续与回执核对均保留已送达结果；“已采集、已送达、已采用”分别展示。

导入页支持多个关键词包含匹配，明确选中或取消匹配货号；按工作区、店铺记忆成功选择与关键词。新增匹配项须手动加入，主动排除项不会再次当作新增推荐。同店成功文件取并集，空选择禁止导入，完整月替换与部分日期保护不变。

任务绑定工作区、店铺、月份、SKU/SKC、查询条件和不可变台账导入版本。页面筛选及采用进度不改变活动任务；台账重导后拒绝采用旧任务。正式成本证据、人工更正、定稿保护与未售 SKU 映射规则不变。无业务数据库迁移。
