# Security Policy

## Supported Versions

Security fixes are provided for the latest published Lworkstation release.
Pre-release builds may change quickly and should not be treated as production
security guarantees.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability.

Use the repository's **Security** tab and choose **Report a vulnerability** to
send a private report. Include:

- the affected version and operating system;
- clear reproduction steps;
- the security impact you observed;
- relevant logs or screenshots with credentials and business data removed;
- whether the issue affects the Electron shell, updater, local ERP inbox,
  embedded ERP/1688 pages, or frontend data handling.

Please do not include passwords, cookies, tokens, ERP account data, business
spreadsheets, local databases, or customer information. Allow the maintainers a
reasonable opportunity to investigate and release a fix before public
disclosure.

Ordinary bugs and feature requests should use GitHub Issues.
