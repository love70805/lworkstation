# v0.4.1 导入前货号筛选与 SKC 图表明细

导入页先按店铺选择供方货号，首次空选，支持搜索、多选、全选、清空及折叠批量粘贴。成功入库后记住本工作区各店上次选择；新货号不自动加入，未匹配历史货号提示。完整月重导默认替换本店本月为此次选择，逐项预览新增、覆盖、移除及金额；部分日期仅按分组追加或替换。最终原子提交，定稿月须显式重开。

来源覆盖 v2 分别记录时间与货号范围，只为实际导入商品证明完整月；日期不足仍不生成销量标签，未导入商品不补零。旧批次不自动提升完整性。移除头像运营方案、我的/全部商品切换及各页面残余过滤。偏好仅用于下次预选，不新增业务表迁移。

首页与利润页共用图表：店铺左图右表，点击后左侧 SKC 构成、右侧 SKU 明细；指标切换、稳定颜色、悬停信息、扇区定位行及翻页、负值/缺失占比说明、浅深色和窄屏适配。正式 ERP 成本、人工更正、定稿保护、同 SKC 未售 SKU 仓库映射与 8.0.33 对象查询修复保留。
