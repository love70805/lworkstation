# 0.2.17 分组销售图

## 范围与兼容
- 每日按日期分组，每店一根柱；新增每月视图，用当前月份和可选对比月份的店铺完整月总额并排比较。
- 固定店铺颜色和槽位；图例开关仅影响图形，悬停或键盘聚焦读取数据。月柱点击定位该月每日图。
- 恢复图表/明细 1:1.15 比例，窗口足够时并排；经营概览右侧信息在 1024px 及以上保留右栏。窄屏正常折叠。
- 月度金额包含缺少有效日期的来源；负数/真实零值/无来源分开表示。派生缓存公式升级为 daily-sales@4-grouped，业务数据库仍为 v15。
