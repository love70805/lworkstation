# 0.2.18 简化首页与堆叠销售图

## 本次改动
每天一根柱、店铺分色，取消月度对比及每日/每月切换；当前月份仍可在账本范围切换。保留销售额/销量、店铺筛选、每日明细与缓存。图例仅控制图形，成本、合计、原始占比分母及定稿口径不变。

选日明细每页6项、最大280px内滚动，少量行自然高度。首页移除空成本观察和健康/云端卡，次要观察与活动默认折叠，账本控件去重收紧。诊断和备份继续从原侧栏进入。
