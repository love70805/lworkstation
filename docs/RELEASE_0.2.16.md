# 0.2.16 更新与验收

2026-09-15 00:25:38（UTC+8）已公开 [GitHub Latest](https://github.com/love70805/lworkstation/releases/tag/v0.2.16)。本机未安装，真实业务数据未改。

## 交付范围

- 每日销售按店铺稳定配色堆叠；支持同轴跨月比较、当日窄柱与宽明细、简写活动、分页定位。保留零基线，缺失/未来日期不补零，负值不计算误导性占比。
- 独立可重建缓存库保存销售和利润派生结果；原始台账共享读取，后台 worker 计算，来源写入和公式版本控制失效，保存后立即读取有有界重试。
- 利润不再重复按两套逻辑计算；折叠商品不挂载表格。刷新保留人工输入草稿，过期结果明确提示并阻止定稿。
- 统一弹窗、表格、中文间距和浅深色动效；商品详情返回恢复搜索、分页、排序与滚动位置，工作区之间隔离。
- 业务数据库仍为 v15，人工成本优先、精确累计及既有 Excel 报告格式保持。正式报告继续验证来源，不依赖派生缓存定稿。不涉及云端迁移。

## 性能边界

真实隔离 Edge，每阶段三次。服务调用涵盖原始快照、利润和销售汇总；重启列为新页面 JS 环境的持久命中，不等同完整软件启动。

| 来源行数 | 冷读取/计算 p50 | 内存命中 p50 | 持久命中 p50 |
