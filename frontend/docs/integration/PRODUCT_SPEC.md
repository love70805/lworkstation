# Shopeers 集成产品规格

版本：Milestone 1  
生效日期：2026-08-06  
状态：已批准开发

本规格取代仓库根目录旧版 `PRD.md` 中“仅本地、不做云端协作”“月度账本和统一工作区属于 P2”的安排。旧文档仍保留作原型阶段历史记录。

## 1. 产品定位

Shopeers 是供内部选品、运营和利润核算人员共同使用的商品经营工作区。它把原选品工作台与 ERP Assistant 的利润流程整合在同一产品内，同时保留两个业务域不同的目的和精度等级。

- 选品工作台：记录商品、平台 SKC/SKU、店铺、规格和 1688 供应商，提供可解释的参考成本与参考利润。
- ERP 成本中心：按平台 SKC 发起查询，取得仓库 SKU 的合格采购记录，再映射到平台 SKU。
- 月度利润核算：导入店铺台账，以平台 SKU 为单位匹配正式成本并完成精确核算、定稿和导出。

## 2. 核心业务事实

1. 平台 SKU 在一个工作区内全局唯一，是成本匹配和利润计算的最小业务标识。
2. 平台 SKC 是平台 SKU 的父级分组，也是用户批量复制到 ERP 的查询单位。
3. 仓库 SKU 是 ERP 采购记录与平台 SKC、平台 SKU 之间的映射桥梁。
4. 默认币种为人民币 `CNY`。
5. ERP 抓取成本是正式成本的权威来源。
6. 1688 落地成本只用于选品参考，不能自动成为正式月度利润成本。
7. ERP 成本缺失时，1688 落地成本只有经过人工确认并留下审批记录后，才可用于该次正式定稿。
8. 精确利润与参考利润必须在数据结构、状态和界面上明确区分。

## 3. 产品边界

### 3.1 商品与供应商中心

负责：

- 接收并校验 `CaptureEnvelope v1`。
- 保存待确认、已确认和已忽略采集记录。
- 维护商品、供应商、店铺分配、平台 SKC、平台 SKU、规格、图片和来源链接。
- 维护 1688 采购价、运费、操作费、每份数量及参考落地成本。
- 展示 ERP 历史成本、已定稿月度利润历史和参考利润。
- 提供筛选、批量操作、导入、导出、备份和审计追踪。

不负责：

- 把 1688 页面价格直接认定为月度正式成本。
- 修改已定稿月度账本中的历史成本事实。

### 3.2 ERP 成本中心

负责：

- 接收一个或多个平台 SKC 作为查询任务输入。
- 在用户已登录的 ERP 页面捕获真实查询上下文。
- 读取完整采购单、采购明细和仓库 SKU 到平台 SKU 的映射。
- 严格按 v8.0 兼容规则选择采购记录并计算数量加权单件成本。
- 生成不可变的成本批次、明细、异常和来源证据。
- 将成本批次写入统一数据库，供利润核算和选品参考共同使用。

不负责：

- 将 ERP 登录凭据上传云端。
- 在发生分页不一致或部分请求失败时发布残缺成本批次。

### 3.3 月度利润中心

负责：

- 按月份和店铺导入 CSV/XLSX 台账。
- 预览字段映射、有效行、忽略行和错误。
- 保留旧利润工具的分组、扣款、盘亏和重复导入替换规则。
- 从台账筛选并批量复制平台 SKC，创建 ERP 成本请求。
- 按平台 SKU 匹配正式成本，计算采购成本、仓储成本、扣款和利润。
- 允许草稿、待补成本、待审批、已定稿和已锁定状态。
- 按筛选结果导出兼容 Excel，并将定稿结果反馈给选品工作台。

## 4. 端到端流程

### 4.1 采集与商品入库

```text
1688 确认订单页
  -> CaptureEnvelope v1
  -> 待确认队列
  -> 补充店铺、平台 SKC、平台 SKU 和业务字段
  -> 重复检测与就绪校验
  -> 商品库
  -> 生成 1688 参考落地成本
```

### 4.2 精确月度利润

```text
创建月度账本
  -> 导入一个或多个店铺台账
  -> 预览并确认字段映射
  -> 按店铺/SKC/供方货号聚合
  -> 筛选销售人员或货号范围
  -> 批量复制平台 SKC
  -> 在 ERP 中查询并生成成本批次
  -> 平台 SKU 级成本核对
  -> 处理缺失成本或人工审批 1688 兜底
  -> 计算并复核利润
  -> 定稿、锁定、导出
  -> 回写商品经营历史
```

### 4.3 选品参考反馈

已定稿利润账本向商品与供应商中心提供：

- 最近一次正式单件成本及来源。
- 最近若干月的销量、销售额、扣款、仓储成本、利润和利润率。
- 成本变化趋势和负利润警告。
- 参考利润假设与实际利润之间的偏差。

这些数据用于选品决策，但不得反向覆盖已经定稿的月度账本。

## 5. 成本状态与优先级

| 状态 | 是否可用于参考利润 | 是否可用于正式利润定稿 | 说明 |
| --- | --- | --- | --- |
| ERP 已验证成本 | 是 | 是 | 默认权威来源 |
| 已定稿账本历史成本 | 是 | 不直接复用 | 用于趋势和参考；新月份仍需明确成本批次 |
| 1688 落地参考成本 | 是 | 否 | 仅选品参考 |
| 已审批 1688 兜底成本 | 是 | 是 | 仅在 ERP 缺失时，必须有审批人、时间和原因 |
| 缺失成本 | 否 | 否 | 利润不可定稿 |

ERP 成本后续补齐时，不静默改写已锁定账本。系统应生成差异提示，由用户决定是否解锁重算或保留原审计结果。

## 6. 月度账本规则

- 一个工作区、自然月和账本类型组合只能有一个活动账本。
- 每次文件导入形成独立导入批次，保留文件名、文件哈希、店铺、字段映射和校验摘要。
- 同一“店铺 + SKC/供方货号 + 供方货号”重复导入时，新批次替换该分组，而不是叠加。
- 台账明细按“平台 SKU + 属性”聚合。
- 变动类型包含盘亏时排除；包含扣款、罚款或违约时只累计扣款。
- 仓储费率默认 `0.70 CNY/件`，账本保存使用时的费率快照。
- 定稿前每条参与计算的 SKU 必须有正式成本决策。
- 定稿后保存输入、公式版本、成本来源、审批、结果和导出版本；锁定后默认只读。

## 7. 计算口径

### 7.1 1688 参考落地成本

```text
参考单件成本 = (采购单价 + 整单运费 / 采购总份数 + 单份操作费) / 每份单品数
```

该结果必须标记为 `reference`。

### 7.2 ERP 正式成本

```text
入选记录总采购价 = Σ(采购数量 × 单价)
入选记录总采购量 = Σ采购数量
ERP 单件成本 = 入选记录总采购价 / 入选记录总采购量
```

记录选择规则见 `LEGACY_COMPATIBILITY.md`。

### 7.3 月度精确利润

```text
采购成本 = 销量 × 正式单件成本
仓储成本 = 销量 × 仓储费率
利润 = 销售金额 - 采购成本 - 仓储成本 - 扣款
利润率 = 利润 / 销售金额
```

金额计算使用十进制定点语义，并在展示和导出边界四舍五入到 2 位小数。

## 8. 数据协作与交换

- 产品内部以云端关系数据库为共享事实来源。
- 浏览器本地 IndexedDB 用于离线缓存、未提交草稿和可靠重试，不作为团队协作的最终事实来源。
- CSV/XLSX 用于外部台账导入、审计导出和人工交换。
- TSV 剪贴板保留为 ERP 成本的兼容降级通道。
- 所有导入、成本计算、审批、定稿、解锁和删除动作进入审计日志。

## 9. 第一阶段验收

- 权威基线和兼容规则已文档化并有哈希。
- 平台 SKU 规范化和工作区唯一性有领域测试。
- 平台 SKC 成本请求能去重、校验并生成稳定输入。
- ERP 成本行能按平台 SKU 核对，重复行遵循兼容规则并保留冲突信息。
- ERP 成本优先、1688 仅参考及人工审批兜底由纯领域逻辑强制执行。
- 精确利润与参考利润不能混用状态。
- 现有测试和生产构建通过。
