# Lworkstation 1.0.5

状态：候选验收与发布中，尚未公开。内置 ERP Assistant 8.0.52。

- 成本齐全后可直接导出，代发可留空；手工代发逐店录入，表格增加店铺号。
- 利润/成本使用一个搜索入口；移除利润页本月趋势，收起采集任务详情。
- 货号匹配或勾选后立即选用，模糊搜索兼容大小写。
- 人工成本输入后确认即可，系统自动记录审计说明，仍支持零值、微小值、撤销及定稿保护。
- 失败原因带 ERP 原返回业务数据，限制体积并隐藏凭据。采购列表缺号时补取同一订单明细中的单号。

单号反馈的现场候选原因是人工更正且无合格采购凭证；已修复的确定问题是扩展列表/明细单号补取缺口。未取得现场原始返回，不能断言唯一根因。既有报告保持冻结；更新后须重新采集受影响 SKU，已定稿结果需显式重开再生成。

完整前端 227 文件 / 1,793 项测试、生产构建、33 项发布门禁及 23 项桌面验证入口通过。隔离浏览器与原生 ERP 路径通过，未安装或操作真实业务数据。候选实包与 CI/上传证据完成后补记。[本批契约与验证](integration/PROFIT_WORKFLOW_1.0.5.md)。
