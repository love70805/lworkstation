# 2.0.1 导入与利润界面小修

2026-11-05 根据用户同批截图反馈，在联网核对的 `main` / `v2.0.0` 基线 `caf95151157ab1ffd5bdf148a176f398c1e39d82` 上修复，统一递增补丁版本。

- 导入月份集中到醒目的固定操作区；一致的来源月份不重复显示，跨月、缺日期和已有账本冲突继续明确提示，保留必要的月份补选。
- 未收到可处理的价格异常时，不提前显示忽略按钮；已有忽略记录保留查看和恢复入口。展示条件不自动忽略、修改采购证据或改变成本采用规则。
- 修复利润明细“展开全部列”无可见反应，切换全部列时展开本页明细，保持分页上限。
- 首页每日/月度改为单按钮往返切换，仍按需读取月度数据。
- 首页金额取消省略号，窄卡片让出图标空间并适应字号，长金额可完整换行。

影响限导入及利润界面和必要的展示契约，不迁移或操作真实业务库。完成信号为同月去重和醒目显示、月份异常保护、无成本/正常成本/异常/已忽略状态，以及列切换在浅深色、桌面和窄屏可用。
