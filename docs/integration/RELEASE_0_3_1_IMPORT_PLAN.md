# 0.3.1 代发与共享来源导入契约

2026-09-29，基线 main `1506dc0e166d180b7c2350133876c68e7baa6168`。独立分支 `codex/release-0-3-1`，复用空闲54cb工作区。本批连续实施、审查、PR/CI、候选验收和稳定公开发布；不安装、不改真实库、不修改用户CSV，不覆盖v0.3.0，不归档聊天或工作区。

## 业务与存储

- 解析版本升级为 `monthly-supplement@3`。只有代发数量 null/undefined/空字符串/空白跳过，零保留，负数、小数、非数值报准确错误。备注不改变数量；扣款空金额仍报错。
- 空数量行先维护登记人、日期、店铺、SKC和1688号的可靠分组上下文，再跳过；缺少归属的空数量行也不阻断，但不能向后猜测登记人。数量从不继承。
- `sourceRow`保留既有CSV物理起始行/工作表行及去重身份。新增`recordRow`和`sourceFormat`用于表格记录行展示，错误附业务单号，CSV物理行仍可追溯。旧行没有新字段时准确说明其原语义。
- 来源元数据保存ignored/skipped（reason=missing_quantity）的定位和归属，随批次审计/备份保留；不写核算明细，不需要数据库迁移。旧批次可读。
- 同文件/工作表/源行不重复计数，跨文件相似业务需就地处理，合法等额分摊不自动删除。事务继续校验预览签名、工作区/月份/账本、角色、批次并发和定稿保护。

## 交互

- 代发正常路径为选文件→统一登记人筛选与即时预览→一次导入。登记人从源识别，可搜索，初始未选；明确“全部登记人”选项不默认选择。
- 自动识别表头和字段，按来源显示识别失败及修复入口；表头/映射放入高级设置，无逐来源启用、手工本人标记、全量复选、预览按钮或普通记录确认。
- 共享扣款保留供方货号完整/包含筛选、实际店铺及有符号金额，使用相同自动预览和一次操作。
- 已有来源默认保留，可明确选择替换。分别显示原采用值、本次筛选新增值和最终整月值；最终按钮附近说明替换修订及旧版本保留。重复来源只反馈拦截，不增加数量。切换筛选/映射/处理冲突立即使旧预览失效，只能提交当前已完成预览。
- 真正存在跨文件冲突时才出现处理控件，排除冲突行或明确保留全部后自动更新，不需要再次点击预览。普通报告保存流程不扩展。
