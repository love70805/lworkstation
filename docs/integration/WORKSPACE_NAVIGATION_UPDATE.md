# 首页账本与导航组合适配

2026-09-13，完整更新的已确认范围。用户要求保留原经营概览，将月度账本融入首页；成本核对融合利润页。此包不是用利润页替换首页。

## 所有权与依赖

- 当前可用专职为桌面化、利润与 ERP，未发现可用全局 UI 任务。明确由桌面化在桌面体验独立提交交付后顺序承接本包，避免同时改写 AppShell。
- 主责文件：App、AppShell、WorkspacePortal、workspaceNavigation、相关共享导航测试及 workspace 样式。不得修改 ProfitPanel/ProfitWorkspacePage/CostMatching、业务 repository 或导入 Worker。必要业务出口缺失时向利润任务请求适配，不复制计算逻辑。
- 依赖利润包 PROFIT_ANALYTICS_UI.md 的 readLedgerSalesAnalytics({workspaceId,ledgerId,store}) 与 /profit 的 view=detail|cost；实施前读取实际提交接口。可提前做导航与经营概览骨架，但不得用假趋势或演示值冒充完成。

## 首页目标

- 保留现有经营概览的主要经营统计、选品入口和经营动态；首页不是完整利润页，也不是完整账本表替换。
- 月度账本管理区成为首页常用区域，提供当前工作区下的核算月份、店铺筛选、实际账本/成本状态、同月多店批量导入、补齐成本、核算利润和全部账本管理入口。
- 账本为空时给导入入口，不自动创建演示账本。状态来自真实 repository，未知不填0，缺成本不能显示已完成利润。
- 原完整月度账本管理功能继续从首页可达，用户能访问全部月份而非仅最近五项；不为侧栏精简删除管理能力。
- 首页“补齐成本”进入 /profit?ledger=...&store=...&view=cost；“核算利润”进入同scope的view=detail。筛选与异步切换必须重新校验当前成员工作区，不根据过期响应选错店。

## 每日趋势

- 替换原跨月销售趋势，按选择账本月份显示每日销售原额/销量，切换店铺同步范围。只消费利润专职统一分析出口，不另写Decimal或另造收入公式。
- 部分日期缺失、异常月份、无数据与确认零分别呈现；不能静默补造日期。页面月合计采用同scope分析月合计，与每日及缺日期项可核对。
- 日趋势共用业务组件如利润专职已有稳定导出则直接复用；否则首页只写展示层。不增加每日利润。

## 导航合同

- 侧栏：工作区首页、选品工作台、利润核算、系统诊断与备份；移除独立月度账本与成本核对项。
- /ledger、/import-preview 归属首页分支且管理入口保留；/cost-matching 兼容跳转 /profit?view=cost，保留有效 ledger/store/q/supplier/missing。
- /erp-assistant 保持设置入口可达，并归属利润成本分支。旧收藏/通知/按钮不能落到不存在的页面。
- workspaceNavigation 白名单添加并验证 view（detail/cost），沿用账本/工作区验证。无效scope由页面安全回退，不泄漏其他工作区，也不能把未验证参数保存为ERP请求。
- 外部ERP/1688桌面标签、桌面主题与版本弹窗保持，不以导航整理扩大到业务写入口。

## 验收

- 实际浏览器覆盖空工作区、多月份、多店铺、部分缺成本、日期不完整、全部商品/账本可达、跨工作区非法参数及快速切换。
- 明暗主题1024×768、1280×800及窄屏：主要操作可点，标签/筛选不溢出；保持经营概览视觉身份，不出现嵌套AppShell。
- 旧/ledger/成本链接与新首页入口均正确，视图/店/月参数刷新保持；ERP正常收件回归。
- frontend test/build、桌面导航相关verify，独立 Conventional Commit 和截图/验收证据。交付主线审查后停止，不自行发布或安装。
