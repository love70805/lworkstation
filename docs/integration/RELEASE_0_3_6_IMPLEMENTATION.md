# 0.3.6 实施与验收记录

批准范围见[完整设计](RELEASE_0_3_6_UPGRADE_DESIGN.md)。未列为通过的门槛不代表已验收。

## 基线与模块契约

- 独立分支 `codex/release-0-3-6`，起点 `873a24f`，软件0.3.6，ERP Assistant8.0.27。历史集成分支只有旧合并节点，实际基线采用最新已发布main。
- 台账保留 `sourceAddedAt`（北京时间ISO）、`sourceAddedTimestamp`、`sourceTimePrecision`，日字段兼容；正常多文件自动识别明细页、全商品校验和一次导入。替换冲突完整分页确认，原子事务取消全部回滚。计算在Worker，128行分块SHA-256绑定输入及目标快照，实际写入每块2000行，完整审计保存真实主键。
- 整月来源使用 `sourceCoverage@1`；旧批次必须显式确认。现存行数须等于原有效行数及整店月份行数，拒绝已知错误行、商品筛选、分组重导残留、跨工作区和定稿修改；标准审计保留。范围确认不会修复缺失日期。
- ERP可信 `previewContext` 增加可选 `requestId/platformSkcs`，读取完整已登记SKC；旧响应按捕获目标查询。现有正式成本/资料envelope及幂等保持，不采用不完整正式成本。
- 采购按目标SKC读完并去重，移除10页/500单上限，保持店铺范围，不扫描全公司。总数漂移、重复页、零声明非空列表、登录失效中止；缺证据不转成缺成本。执行预算5分钟，页面会话缓存10分钟，绑定请求/月/查询条件；已完成目标直接复用，未完成目标须核对首分页后续取。可选资料独立60秒，复用完整仓库证据；新请求或跨月重读。未承诺跨浏览器重启恢复。
- 最新正常销售按完整时刻确定；最新缺价不回退旧价，同刻候选按同店同月净销量处理，不确定待选。人工售价、主动清空及编辑中内容优先。
- 引流排除仅改变选品展示与建档规格，选择和规格可恢复；财务及ERP身份保持。仅明确标记触发，不按低价、1pc、颜色推断。来源店分别取自身最新完整月的月末七天，缺证据不伪造零。
- 首页月总览与店铺对比、3/6/12月范围、三层导航、全商品五行分页、全范围搜索和上下文恢复；显式期间不随新数据跳动，过期异步结果不覆盖当前视图。月汇总只缓存紧凑模型。
