# 桌面扩展入口视觉验收（早期页面记录）

以下清单记录早期成本页、待确认采集页与浏览器开发环境的验收。当前成本核对已并入利润页，商品页保留历史采集资料。验证新改动时按实际页面和用户路径选择范围。[当前使用指南](USER_GUIDE_2.0.md) · [模块和验证入口](DEVELOPMENT_WORKSPACE.md)

## 桌面工作站

1. 直接打开 `/erp-assistant`，应重定向到 `/profit`，不得显示扩展下载或 Chrome 加载步骤。
2. 在 ERP 成本核对页打开“ERP 扩展状态”，应只显示内置扩展状态、复检和系统诊断入口。
3. 在待确认采集页打开“1688 扩展状态”，应只显示内置扩展状态、复检和系统诊断入口。
4. 从状态弹窗进入 `/diagnostics#extensions`，应同时显示 ERP 扩展、本机收件服务和 1688 扩展的详细状态。
5. 桌面状态区域不得出现“下载扩展包”“下载并解压”“加载已解压扩展”或 `chrome://extensions/`。

## 浏览器开发环境

1. `/erp-assistant` 应继续显示 ERP Assistant 下载、解压与 Chrome 扩展加载流程。
2. 待确认采集页的“安装 1688 扩展”应继续提供下载、扩展管理页和安装步骤。
3. 系统诊断只显示连接状态；安装流程仍由对应业务页面承载，避免重复按钮。

## 响应式检查

- 桌面视口：`1440 × 900`。
- 移动视口：`390 × 844`。
- 检查状态卡、徽标、复检按钮和系统诊断入口不重叠，弹窗保持在视口内，页面无横向溢出。
