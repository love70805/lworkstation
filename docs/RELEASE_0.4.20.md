# 0.4.20 货号筛选工作台（候选验收中）

导入步骤增加完整货号表格与应用前预览。支持按店铺查看、搜索、排序、分页、已选/未选/匹配视图、本页与筛选结果选择、完整货号粘贴、按需查看 SKC/SKU 成员及导出所选范围清单。规则编辑、选择草稿、应用文件筛选分别处理；撤销恢复本批最近应用的选择。应用只更新待导入文件，正式导入仍执行月份/变动类型校验、完整替换确认与原子写入。

货号按店铺及完整货号计数，来源行数由实际解析结果计算，SKC/SKU 使用符合业务过滤及月份证据的集合并集。缺映射、标识或日期显式显示待映射/待补。本次新增和取消比较草稿与文件当前应用值。组切换只读取目标组兼容例外，同组重新匹配保留逐店人工加入/排除；搜索与分页不改选择，零命中保持空选。

利润/ERP 使用同一套可搜索选择表格和当前工作区常用组，组只展开当前账本/店铺候选。`null = 全部`、`[] = 空选` 保持。大量选择通过绑定账本/工作区的本机会话引用在两页传递；旧小范围链接继续兼容，引用丢失显示空选和恢复提示。已启动 ERP 任务范围固定，成本、有效人工更正优先、真实零/微小值、已定稿报告和备份保护保持。

基线 `a6a1506` / 0.4.19，实现 `3e6c14c`；[契约](integration/SUPPLIER_FILTER_WORKBENCH.md)。无业务数据库迁移，本机不安装，真实业务数据与收件队列不改写。详细本地计划、原型、生成台账和原始 QA 证据仅本机保存。

182 文件 / 1440 项前端测试、生产构建、完整 ERP/同步/部署门禁和 17 组 desktop verify 通过。隔离无头生产资源完成六店 1,286 店铺货号 / 88,694 来源行、草稿/应用/撤销、组切换与例外、零命中、页面与筛选结果选择、粘贴/清单、按需成员、实际导入与重新替换确认。16 组中文浅深色 × 1600/1280/1024/390 布局通过；1280 窗口首屏应用按钮下缘 763 像素。
