# 0.4.23 常用货号组与筛选流程（候选准备）

常用组直接点名称，保存时默认取货号关键词，不再重复显示组名与相同别名。名称及匹配条件在管理窗口按需修改；管理、取消及保存失败不改变本次勾选。删除组需确认，保留当前选择。

修改关键词或匹配方式后必须先匹配再应用，阻止旧选择及旧预览被误用。清除匹配条件保留勾选，已应用状态明确，不重复执行相同应用。成员明细读取失败可以直接重试；利润/ERP 的常用组提示随实际范围与手工选择刷新。
