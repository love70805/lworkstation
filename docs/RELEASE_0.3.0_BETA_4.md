# 0.3.0-beta.4 · ERP 预览按台账月份

当前状态：Windows 候选验收通过，PR #101 集成中，尚未公开。仅 Beta 通道；稳定版保持 0.2.19。本机不安装，不修改真实业务数据。

## 改动

ERP 助手 8.0.21 读取工作台已登记的台账月份，先保留当月及以前采购，再按时间取最近三笔，数量加权并四位截断。系统日期、采集日期和缓存月份均不作为核算月份。缺少可信月份、请求歧义或通道失败时提示待关联，汇总价格留空；完整证据仍保留并回传。

预览明细、供应商、异常提示、兼容复制和 CSV 同步选样。缓存恢复重新关联月份并复算。原始采购时分秒与时区保留，月末边界按北京时间判断；后续月份记录不从回传证据中删除。正式成本继续由数据库账本独立验证，人工更正、已定稿报告不改。

## 验收

- 113 文件 / 772 项前端测试、生产构建、完整发布检查通过；13 组桌面验证通过。
- 实际 Windows 安装包内置扩展，隔离模拟 ERP 网络，真实页面登记 2026-08 请求、取得可信月份、预览与自动回传一致通过。截图样例的两笔九月采购被排除，六月记录产生 0.1060 预览；三笔完整证据均送达。
- 正式成本候选交互：八月/七月采用、九月排除、加权 8.6666、纯未来记录不能发布通过。1280/1024 浅深色工作台和扩展窗口检查、ERP/1688 切换后草稿保留、packaged smoke 通过。
- 日期/系统月份变更、同日排序、UTC 月界、微小单价、取消状态、旧缓存月份/供应商/异常提示、CSV 注入保护及跨工作区拒绝均覆盖。
- 未连接真实 ERP 账号；真实服务器返回数据差异仍需用户使用反馈。外部 Chrome 扩展需更新到 8.0.21，桌面内置扩展随应用更新。升级后回到相应台账重新查询采集；旧缺月份请求会自动换新登记。
